Image editor

The editor's layout, tools and keys.

✅ View ▸ Dockers; folding and closing the docker groups (2.514.0)

  • ▾ at the start of a docker group's tabs folds the group to its tabs; click a tab to open it again.
  • ✕ closes the group. View ▸ Dockers lists every image editor docker with a tick, plus All Dockers to bring them all back.
  • The app's side dockers fold to a thin title strip with the ▾ in their title bar.
  • 🖌 Edit theme mode: drag an element's handles to resize it, drag inside it to move it, hide it or change its text. Leaving asks to save the theme.

✅ The Pen P (2.421.0)

  • Pen: click = a corner anchor, drag = a smooth anchor (its handles mirror), click the first anchor = close. Alt = a cusp, Shift = 45° steps, Ctrl = Direct Selection for a moment, Enter / Esc leave it open. Over the picked path it adds an anchor on a segment, deletes one on an anchor (Auto Add/Delete).
  • Freeform Pen: draw by hand; Curve Fit (px) says how closely the Béziers follow. Ending near the start closes it.
  • Add / Delete Anchor Point, Convert Point (click: curve ⇄ corner; drag an anchor: new handles; drag a handle: a cusp). Shift+P cycles them. Over the editor P is the Pen; elsewhere it still shows / hides the prompt docker.
  • Mode: Shape draws a shape layer (foreground fill, background + W stroke), Path the Work Path. ▣ ⊕ ⊖ ⊗ ⊘: New Layer, Combine, Subtract Front Shape, Intersect, Exclude.

✅ Path Selection / Direct Selection A (2.421.0)

  • Path Selection: click a component (Shift adds), drag moves, Alt-drag copies, Delete removes; its operation in the options bar; ⧉ Merge Components (the result as plain outlines); ⟳ Transform… (scale, rotate, flip).
  • Direct Selection: anchors and handles - Shift adds, a box picks several, arrows nudge (Shift ×10), Delete removes, Corner / Smooth. Click a shape layer's outline to edit it; a shape layer becomes a path the moment an anchor moves.

✅ Custom shapes U (2.421.0)

  • The Custom Shape tool: heart, star, burst, arrow, chevron, plus, cross, check, lightning, speech bubble, drop, moon, house, cloud, ring, frame - drag (Shift keeps its proportions). Edit ▸ Define Custom Shape… adds the picked path (right-click one of yours in the picker removes it).
  • The Shape tool (rectangle, ellipse, polygon, line) has the same operation buttons: anything but New Layer adds to the active shape layer.

✅ The Paths panel (2.421.0)

  • Beside Layers and History: the Work Path, saved paths, the active layer's Shape Path and Vector Mask. Click = pick; Ctrl-click = load as a selection (Shift adds, Alt subtracts). Double-click the Work Path = save it; a saved path = rename.
  • ● fill with the foreground · ○ stroke with the brush · ⬚ as a selection · ⟲ work path from the selection · ◇ vector mask · ＋ new · ⧉ duplicate · ☰ more (save, SVG, custom shape, shape layer) · 🗑 delete. Alt-click ● ○ ⬚ ⟲ for their options.

✅ Vector masks (2.421.0)

  • Layer ▸ Vector Mask: Reveal All, Hide All, Current Path, Disable / Enable, Rasterize (into the pixel mask), Delete. Its thumbnail sits beside the layer mask's: click = edit its path, Shift-click = off / on.
  • Properties: Density, Feather, Invert, Link. Crop, canvas size, image size and rotate take every path with the picture; a PSD keeps vector masks and path shape layers; File ▸ Export Path as SVG… / Place SVG as Shape Layer….

✅ Smart objects (2.422.0)

  • Layer ▸ Smart Objects: Convert to Smart Object: a layer or a group goes inside (still editable); the smart object (▣) is re-drawn from it, so scaling / turning / warping loses nothing.
  • Edit Contents (double-click the thumbnail): the inside opens with a banner - ✔ Done updates the smart object and every duplicate of it, ✕ Cancel leaves it. New Smart Object via Copy = independent contents. Replace Contents…, Export Contents…, Convert to Layers, Rasterize.

✅ Smart filters (2.422.0)

  • A Filter / Adjustment on a smart object is ADDED under the layer: 👁 on / off, double-click = its settings, right-click = opacity, ▲ order, ✕ delete.
  • The filter mask (on the Smart Filters row): click it and paint - black hides the filters there; Shift-click turns it off.

✅ Skew, Distort, Perspective, Warp (2.422.0)

  • Edit ▸ Transform: Skew / Distort / Perspective / Warp, or Ctrl+T on a smart object; the options bar switches modes. Warp: drag a grid point or anywhere inside; presets with a Bend %. Enter applies, Esc cancels.

✅ Puppet Warp (2.422.0)

  • Edit ▸ Puppet Warp: click to pin, drag a pin to bend, Alt-click / Delete removes; Density, Show Mesh. A smart filter on a smart object.

✅ Content-Aware Scale (2.422.0)

  • Edit ▸ Content-Aware Scale… (Alt+Shift+Ctrl+C): width / height %, the unimportant pixels go (or are doubled); Protect: the selection; a live preview.

✅ Liquify (2.422.0)

  • Filter ▸ Liquify… (Shift+Ctrl+X): W push, R reconstruct, C twirl (Alt reverses), S pucker, B bloat, F / D freeze / thaw; size [ ], pressure, Restore All. A smart filter on a smart object.

✅ Select and Mask (2.423.0)

  • Select ▸ Select and Mask… (Alt+Ctrl+R): Quick Selection W, Refine Edge R (over hair), Brush B (Alt takes away); views; Radius / Smart Radius, Smooth, Feather, Contrast, Shift Edge; Decontaminate Colors; Output To Selection / Layer Mask / New Layer / New Layer with Layer Mask.

✅ Magnetic Lasso, Quick Selection, Sky (2.423.0)

  • Magnetic Lasso (L): move along an edge - it snaps; click sets a point, Backspace takes one back, double-click / Enter closes. Width, Contrast, Frequency.
  • Quick Selection (W): paint - it grows to the edges; Alt takes away; Tolerance, Auto-Enhance. Select ▸ Sky.

✅ Channels and saved selections (2.423.0)

✅ Patch, Content-Aware Move / Fill, Red Eye (2.423.0)

  • Edit ▸ Content-Aware Fill… and Content-Aware in Edit ▸ Fill… - no AI: filled from the picture itself.

✅ Mixer Brush, Background / Magic Eraser (2.423.0)

  • Mixer Brush (B): Wet, Load, Mix, Clean after each stroke. Background Eraser (E): Continuous / Once, Tolerance, Protect Foreground Color. Magic Eraser (E): a click clears that colour (Tolerance, Contiguous).

✅ PDF files: open, edit, save (2.424.0)

  • Save PDF… / Save as New PDF… (2.435.0): the Save dialog's Embed fonts writes each line in its own font, embedded (only the letters used) - from this computer's fonts or the install's fonts folder; any alphabet stays real text.
  • File ▸ Open PDF… (or drop a .pdf), Open PDF from Project…: the Pages strip; a page opens as a Background without its text + a type layer per line (font, size, colour, width matched).
  • Edit with every tool; each page keeps its layers and undo (also over another picture - File ▸ PDF Pages).
  • 💾 Save PDF: the changed pages replaced in the original (the project's copy, also downloaded); Save as New…. Unchanged pages stay vector; type becomes real, selectable PDF text (Helvetica / Times / Courier); what those fonts cannot write goes into the picture.

✅ Vector lines: curve tools, Shape tool, Outline Pen (2.425.0)

  • F5 (again = the next): Bézier (click = cusp node, drag = smooth node, C / S while dragging, Ctrl = 15°, click the first node = close, double-click / Enter / Space = done, Esc = drop it), Freehand, 2-Point Line, Polyline, 3-Point Curve, B-Spline, Node Pen. Start on an open end of the active line to carry it on.
  • F10 Shape tool: pick / drag nodes, handles, segments; double-click = add / delete a node; C S Y = cusp / smooth / symmetrical; join, break, to line / curve, reverse, close, extract, auto-close, reduce nodes.
  • F12 Outline Pen: width, colour, dashes, corners, caps, position, arrowheads, behind fill, scale with object. Ctrl+Q Convert to Curves.
  • Layer ▸ Vector Line: Convert to Path… / Make from Path… (the Paths panel's 〰): a line becomes a path that remembers its outline, and comes back exactly. SVG and PSD keep them.

✅ Curvature Pen, Rubber Band, path align / distribute (2.425.0)

  • Curvature Pen (P): click points - the curve passes through them; double-click a point = corner / smooth; drag to move; Enter ends. The Pen's Rubber Band option. Path Selection (A): align / distribute the picked components (to them or the canvas).

✅ Character and Paragraph panels, paragraph text, styles (2.426.0)

  • Character / Paragraph Styles: ＋ new from the text, click = apply, ⌫ Clear Override, ⟲ Redefine (every text with it follows), 🗑.

✅ Actions and Batch (2.427.0)

✅ Documents, the colour palette, ⊠ transparent, auto-fill (2.430.0)

Drag a window onto the tab strip to dock it, a tab off the strip to float it; Ctrl+W Close, Alt+Ctrl+W Close All, Ctrl+Tab next document; Tile / Cascade / Consolidate All to Tabs.
