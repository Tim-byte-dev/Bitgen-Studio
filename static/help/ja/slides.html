🎞 スライド

bitGen の中のプレゼンテーション - タイトル、要点、画像、図形のあるスライドを全画面で見せます。上部バーの 🎞 ボタンでドッカーを開閉します（⛶ で大きく）。プレゼンテーションはプロジェクトの slides フォルダーに保存されます（.bgk ファイル）。作業中の内容はブラウザーにも保存されるので、ドッカーを閉じても失われません。

スライド

  • 左の一覧にすべてのスライドが表示されます。クリックで編集、上下にドラッグで移動、右クリックで後ろに新しいスライド（レイアウトを選択）、複製、プレゼンテーションで非表示、上へ / 下へ、削除。
  • ＋ スライド ▾（または Ctrl+M）でこのスライドの後に追加 - レイアウトを選びます：タイトル スライド、タイトルとコンテンツ、2 つのコンテンツ、セクション見出し、キャプション付きの図、タイトルのみ、白紙。▤ レイアウト ▾ でこのスライドのレイアウトを変更 - 文字は新しいレイアウトの枠に移ります。
  • 🎨 テーマ ▾ でプレゼンテーション全体の背景・色・フォントを設定します。Bg で 1 枚のスライドだけの背景（↺ = テーマに戻す）。

テキスト、図形、画像

  • 空の枠には何を入れるかが表示されます（「Click to add a title」）。枠をダブルクリック（または選んで Enter）して入力し、Esc か枠の外をクリックで完了。1 行が 1 段落で、箇条書きの枠では各行に記号が付きます。
  • 🅃 テキスト でテキスト ボックスを追加（スライドの空いた所をダブルクリックでも）。⬚ 図形 ▾：四角形、角丸四角形、楕円、三角形、ひし形、矢印、星、線 - 図形をダブルクリックで文字を入力。
  • 🖼 画像、スライドへのドロップ、コピーした画像の Ctrl+V。キャプション付きの図のスライドでは画像の枠に入ります。右クリック ▸ 枠に合わせる / 埋める。
  • クリックで選択、Shift / Ctrl+クリックで追加、空いた所でドラッグして囲んでも選べます。ドラッグで移動 - スライドの中央や端、ほかの項目にそろうとピンクの線が出ます（Alt = スナップなし、Shift = まっすぐ）。白い四角でサイズ変更（Shift で形を保つ。画像は Shift を押さない限り形を保つ）。矢印キーで少し動かす（Shift = 10 px）。
  • バー：フォント、サイズ、B I U、色、左 / 中央 / 右、⇕ 上 / 中 / 下、•≡ 箇条書き、図形の塗り・線・線の太さ、⇡ 最前面へ、⇣ 最背面へ、🗑 削除。Ctrl+D で複製、Ctrl+C / X / V でコピー・切り取り・貼り付け（スライドやプレゼンテーション間でも）、Ctrl+A ですべて選択、Ctrl+Z / Ctrl+Y で元に戻す / やり直し。
  • 発表者ノートはスライドの下の欄に書きます。

発表

  • ▶ 発表（F5）で最初から、▶ ここから（Shift+F5）でこのスライドから全画面で始めます。次へ：→ ↓ Space Enter Page Down かクリック。戻る：← ↑ Backspace Page Up か右クリック。Home / End。番号を入れて Enter でそのスライドへ。B / W で黒 / 白の画面。Esc で終了。非表示のスライドは飛ばします。
  • バーの切り替え：このスライドの現れ方 - なし、フェード、プッシュ、ワイプ、ズーム。

ファイル

  • 📄 新規 ▾ - テーマと 16:9 / 4:3 を選びます。📂 開く ▾ でこのプロジェクトのプレゼンテーション一覧。💾 保存（Ctrl+S）で欄の名前で保存。
  • ⤓ PowerPoint で .pptx を保存 - ダウンロードされ slides フォルダーにも保存されます：各スライドの背景、テキスト（フォント、サイズ、色、箇条書き）、図形、画像、発表者ノート。
