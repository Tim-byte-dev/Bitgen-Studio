✉ メール

bitGen の中で、あなた自身の AI と一緒にメールを読み書きできます。bitGen はメールボックスと直接やり取りします - 読むのは IMAP、送るのは SMTP - ので、登録は不要で、間にクラウドサービスも入りません。プロンプト ドッカーで選んだ LLM が メールを読み、重要なものにフラグを付け、メールを要約し、返信の下書きを書きます。上部バーの ✉ ボタンでドッカーを開閉します。 ボタンには受信トレイの未読数が表示されます。

アカウントの追加（⚙ アカウント）

  • メールアドレスを入力します - Gmail、Outlook.com、Yahoo、iCloud、Fastmail、Zoho、GMX ではサーバーが自動で入ります。ほかのプロバイダーでは推測されます（imap. / smtp. + ドメイン）- プロバイダーで確認してください。
  • パスワード: Gmail、Outlook.com、Yahoo、iCloud はメールソフトからの通常のパスワードを拒否します - アカウントのセキュリティ設定でアプリ パスワードを作り、それを貼り付けてください。パスワードはこのコンピューターに暗号化して保存され（settings/keys.json）、二度と表示されません。
  • SSL にチェック = 最初から暗号化（受信ポート 993、送信 465）。チェックなし = STARTTLS（143 / 587）。
  • ✓ テストは両方のサーバーにログインし、何も送信しません。ログインできたらアカウントは保存されます（2.820.0）。ダイアログを閉じても入力した内容は保存されます。サーバーの証明書を確認するは、自分のサーバーが自作の証明書を使う場合以外はオンのままにします。
  • 送信済みメールのコピーを送信済みに入れる - Gmail は送信メールを自分で保存するので、Gmail ではオフです。
  • 新しいメールには署名が追加されます。複数のアカウント: ドッカーのアカウント一覧から選びます。

読む

  • 左にフォルダー、中央にメール（未読は太字）、右にメール本文。↑ ↓ で一覧を移動し、Delete でメールをゴミ箱へ移します（ゴミ箱の中では削除されます）。
  • ★ はサーバー上でフォローアップのフラグを付け、● は未読 / 既読にします。
  • インターネット上の画像は 画像を表示 を押すまで隠されます - 画像は、あなたがメールを開いたことを送信者に知らせることがあります。ここではメールがスクリプトを実行することはありません。
  • 📎 添付ファイルはクリックでダウンロードします。🔍 は入力に合わせて一覧を絞り込みます（差出人、件名、冒頭の文）。Enter でサーバー上のフォルダー全体を検索します。from: to: subject: body: で絞り込み、引用符で語をまとめます。✕ でフォルダーに戻ります。
  • ⟳ メールを確認で今すぐ確認します。bitGen を開いている間は数分ごとにも確認します（⚙ アカウント ▸ 確認間隔）。

整理（2.820.0）

  • 複数のメール：Ctrl+クリックで追加、Shift+クリックで間のすべて、Ctrl+A ですべて、Esc で解除。🗑、★、●、📁 移動は選んだすべてに一度に効きます。
  • 📁 移動 ▾ で別のフォルダーへ移動します。メールを左のフォルダーにドラッグしても移動できます。
  • アカウント名の横の ＋ でサーバーに新しいフォルダーを作ります（Shift：表示中のフォルダーの中に）。
  • 一覧の最後の ⤓ 古いメールで、フォルダーのメールをサーバーからさらに 200 通読み込みます。
  • 宛先 / Cc / Bcc では、入力に合わせてメールの相手が候補に出ます。↑ ↓ と Enter（またはクリック）で入れます。

✨ AI

  • ✨ AI でフラグ - AI がまだ評価していないメールを読み、それぞれにフラグを付けます: 赤い ⚑ 緊急（すぐ対応が必要）、オレンジの ⚑ 重要（人からのメール、仕事、請求、予定）、青い ⚑ 普通、灰色の ⚑ 低（ニュースレター、広告、自動送信メール）。理由は件名の下に表示されます。Shift+クリックですべてを評価し直します。☐ ✨ 自動 = 新着メールが届いたときにフラグを付けます。
  • あなたにとって大切なこと（⚙ アカウント）を伝えると - 顧客、会計士、学校など - それらは高く評価されます。
  • 表示 ▸ ⚑ 重要は緊急と重要のメールだけを一覧にし、✨ 重要な順はフラグで並べ替えます。
  • ✨ 要約 - 2 文の要約と、あなたがすべきこと。
  • ✨ 返信の下書き / ✨ 全員に返信 - 返信で伝えたいことを入力し（空でもかまいません）、トーンを選ぶと、AI が作成画面に返信を書きます。送信する前に読み直してください - 送信を押すまで何も送られません。

書く（✉ 新規、↩ 返信、↩↩ 全員に返信、↪ 転送）

  • ✨ 書くのを手伝って - 伝えたいことを数語かメモで書き、トーンを選んで ✨ 書く を押すと、メールと件名を書きます（返信では返信を書きます）。
  • ✨ 書いたものを書き直す… - 短く、親しみやすく、よりフォーマルに、スペルと文法の修正、より自信を持って、または自分の指示で。↶ 元に戻すで AI の変更を取り消せます。
  • 太字、斜体、下線、箇条書き、番号付き、リンク。📎 添付するか、作成画面にファイルをドロップします（合計 25 MB まで）。転送では元のメールの添付ファイルも一緒に送られます。
  • ➤ 送信（Ctrl+Enter）または 💾 下書き保存（サーバーの下書きへ）。

保存場所

メールはメールサーバーに残ります。bitGen は表示したもののコピーをアプリの隣の mail フォルダーに保存します （このコンピューターのみ - リポジトリやリリースには入りません）。アカウントを削除すると、そのコピーと保存されたパスワードも 削除されます。AI は LLM が動いている場所で動きます: 🖥 GPU ドッカーで OpenRouter やポッドに設定しない限り、このコンピューターです。
