▦ スプレッドシート

bitGen の中で表・合計・リストを扱えます。ワークブックは複数のシートからなり、数式は入力するたびに自動で計算し直されます。 上部バーの ▦ ボタンでドッカーを開閉します。ワークブックはプロジェクトの sheets フォルダーに保存されます (.bgs ファイル)。入力中の内容はブラウザーにも保存されるので、ドッカーを閉じても失われません。

入力

  • セルをクリックして入力します。Enter で確定して下へ、Tab で右へ、Esc で入力を取り消します。F2 またはダブルクリックでセルの内容を編集します。
  • 矢印キーで移動、Shift + 矢印(またはドラッグ)で範囲を選択、Ctrl + 矢印でデータの端へジャンプ、Home で A 列へ、Page Up / Down で 20 行移動、Ctrl+A ですべて選択、Delete で選択したセルを空にします。
  • 数値は入力した形のまま解釈されます: $1.50 は 1.5 で通貨表示、25% は 0.25 でパーセント表示、17/11/2026(日が先)や 2026-11-17 は日付になります。
  • グリッド上の ƒx バーにはセルの本当の中身(答えではなく数式)が表示されます。ここに入力することもできます。

数式

  • = で始めます: =B2*C2、=SUM(D2:D20)、=IF(D2>100,"big","small")。+ - * / ^、& は文字列の連結、= <> < > <= >= は比較です。
  • 数式の入力中にセルをクリック(または範囲をドラッグ)すると、そのアドレスが入ります。
  • $A$1 は数式をコピーやフィルしても参照が固定されます。A1 は一緒に移動します。
  • 別のシート: =Sheet2!A1 や ='My costs'!B4。列全体・行全体: =SUM(B:B)、=SUM(3:3)。
  • ƒ▾ で関数の一覧を表示します: 合計とカウント(SUM、AVERAGE、MEDIAN、MIN、MAX、COUNT、COUNTA、COUNTBLANK、SUMIF(S)、COUNTIF(S)、AVERAGEIF)、数学(ROUND、ROUNDUP、ROUNDDOWN、INT、ABS、SQRT、POWER、MOD、PRODUCT)、論理(IF、IFS、IFERROR、AND、OR、NOT)、文字列(LEN、TRIM、UPPER、LOWER、LEFT、RIGHT、MID、CONCAT、TEXT、VALUE)、日付(TODAY、NOW、DATE、YEAR、MONTH、DAY)、検索(VLOOKUP、XLOOKUP、INDEX、MATCH)。
  • エラーはセルに表示されます: #DIV/0!(0 で割った)、#REF!(削除されたセル)、#NAME?(知らない関数)、#CYCLE!(自分自身の答えが必要な数式)。

フィル・コピー・移動

  • 選択したセルの角にある小さな四角がフィルハンドルです。下や横にドラッグするとコピーされます。数式は参照が移動し、2 つ以上並んだ数値や日付は連続データとして続きます(1、2 → 3、4、5)。
  • Ctrl+C / Ctrl+X / Ctrl+V でコピー・切り取り・貼り付け。シート内では数式が貼り付け先に合わせて移動します。ほかのプログラムからコピーした表(タブ区切りのテキスト)はセルに貼り付けられます。
  • Ctrl+Z / Ctrl+Y で元に戻す・やり直し。
  • セルを右クリックすると行と列の挿入・削除ができます。どこにある数式も、指していたセルについていきます。列の文字や行番号の境界をドラッグするとサイズを変えられます。

見た目 - ▤ セルの書式設定 (Ctrl+1)

  • ツールバーの ▤ 書式…、Ctrl+1、またはセルの右クリックで セルの書式設定 が開きます。ここで変えた項目だけが選択したすべてのセルに付き(各セルのほかの書式はそのまま)、Ctrl+Z 1 回で元に戻ります。
  • 表示形式:一般、数値(小数点以下の桁数、桁区切り、負の数の表示 - マイナス、赤、かっこ)、通貨($、A$、€、£、¥、฿ …)、会計(記号はセルの端、小数点がそろい、ゼロはダッシュ)、日付、時間、パーセンテージ、分数、指数、テキスト(入力したとおり - 0012 のゼロも残る)、その他(郵便番号、ABN、電話番号)、カスタム - 任意の書式コードを入力:0 # ? 桁、, 桁区切り、%、d m y h s と AM/PM、[h] 24 時間を超える時間、[Red] 色、"文字"、最大 4 つのセクション 正;負;ゼロ;文字列 や [>=1000] のような条件。サンプルには選んでいる間のアクティブセルが表示されます。
  • 配置:左 / 中央 / 右(インデント付き)、繰り返し、両端揃え、選択範囲内で中央(結合せずに複数列にまたがるタイトル)、均等割り付け;上 / 中央 / 下;折り返して全体を表示(行が高くなる)、縮小して全体を表示、セルの結合、文字の方向、方向 - ダイヤルをドラッグするか角度(-90~90)を入力、または文字を縦に積む。
  • フォント:フォント(このコンピューターのフォントも)、標準 / 斜体 / 太字、サイズ(大きい文字は行を高くする)、下線(一重、二重、会計)、色、取り消し線、上付き、下付き。
  • 罫線:線(13 種類)と色を選び、プリセット(なし、外枠、内側)、辺のボタン、またはプレビューの辺をクリック - 斜線も。もう一度クリックすると外れます。
  • 塗りつぶし:パレットの色(または任意の色)、2 色のグラデーション(横、縦、斜め、中心から)、または色付きのパターン。
  • 保護:ロック と 表示しない はシートを保護すると有効になります - このシートを保護する にチェックするか、シートのタブを右クリック ▸ 🔒 シートの保護。するとロックされたセルは変更できず(すべてのセルは最初ロック - 入力してほしいセルはロックを外す)、表示しないセルの数式は表示されません。🔓 シートの保護の解除 で戻ります。
  • ツールバーにはよく使うもの:表示形式 の一覧、.0← / .00→ 小数点以下の桁を減らす / 増やす、B I U、文字と塗りつぶしの色(⊘ = 塗りつぶしなし)、左 / 中央 / 右、折り返し、罫線 ▾、⊞ 結合。列に収まらない数値は ##### と表示されます - 列を広げてください。

Excel ファイル、グラフ、✨ ダッシュボード

  • ⤒ インポート で Excel ブック (.xlsx) や CSV ファイルを開きます:すべてのシート、値、数式、表示形式、フォント、塗りつぶし、罫線、結合セル、列の幅、ウィンドウ枠の固定。bitGen にまだない関数を使う数式は、ファイルに保存されていた結果を表示します。⤓ エクスポート ▾ でブックを .xlsx として保存(ダウンロードし、プロジェクトの sheets フォルダーにも保存)、またはこのシートを CSV として保存します。
  • 📊 グラフ ▾ で選択したセルのグラフ(縦棒、横棒、折れ線、面、円、ドーナツ、散布図)を作ります - 1 行目が系列名、1 列目が項目になります。ドラッグで移動、角のドラッグでサイズ変更、ダブルクリックでタイトル・種類・データを変更、Delete で削除。グラフは上に挿入された行に合わせて動き、ブックに保存されます(.xlsx にはグラフではなくそのデータが入ります)。
  • ✨ ダッシュボード - LLM(プロンプトドッカーのもの)がデータの列 - 名前、値の種類、いくつかの例と合計(すべての行ではありません)- を見てダッシュボードを計画します。見たいものを入力することもできます(「地域別・月別の売上」など)。bitGen は新しい先頭のシートにそれを作ります:タイルの主要な数値、表とグラフ付きの内訳、時間の推移 - すべて生きた数式なのでデータに合わせて変わります - そしてデータを表として書式設定します(見出し、縞模様の行、表示形式、幅、フィルター、見出しの固定)。ファイルから始めるには Excel または CSV ファイル を選びます。LLM を使う を外すと(または LLM が答えないと)、データ自体の形から計画します。Ctrl+Z 1 回ですべて元に戻ります。

✨ セルの中の AI

  • ✨ AI ▾ ▸ ✍ 数式を書く… - 何を求めたいかを書きます(「Region が North の Amount の合計」など)。LLM(プロンプトドッカーのもの)には表の列 - 見出し、値の種類、いくつかの値 - が渡され(すべての行ではありません)、数式で答えます。bitGen は入れる前に計算します:結果を見て、変更でき、入れる を押します。1 行分の数式では 表の行に下へコピー が出ます。
  • 💡 この数式を説明(セルの右クリックメニューにもあります)- 数式が読むすべてのセルと範囲、その今の中身、そして LLM のわかりやすい説明。
  • 🪄 例からフィル(Ctrl+E)- 新しい列の 1 つか 2 つのセルに入れたいものを入力して Ctrl+E:bitGen はできれば自分で規則を見つけ(ほかのセルの単語、@ , - などの記号の前 / 後ろ、つなげる、大文字 / 小文字 / 先頭大文字、頭文字)、空の行を埋めます - LLM は要りません。そのような規則が合わないとき(合計、検索…)は LLM が数式を書き、すべての例を出すときだけ使います。どれも出さないときは LLM が値を埋め、推測だと伝えます。Ctrl+Z 1 回で元に戻ります。
  • ƒ▾ の新しい関数:PROPER、FIND、SEARCH、SUBSTITUTE、REPLACE、REPT、EXACT、TEXTJOIN、AVERAGEIFS、MAXIFS、MINIFS、SUMPRODUCT、LARGE、SMALL、RANK、ROWS、COLUMNS、CEILING、FLOOR、WEEKDAY、HOUR、MINUTE、EDATE、EOMONTH、DATEDIF、CHOOSE、IFNA、ISERROR、ISNA、ISBLANK、ISNUMBER、ISTEXT、SWITCH。

表

  • A→Z / Z→A はアクティブセルの周りの表を、アクティブセルの列で並べ替えます。1 行目の見出しは上に残り、行のセルは(数式も含めて)まとまったまま、空のセルは最後になります。範囲を選択している場合はその範囲だけを並べ替えます。
  • ⏷ フィルターで各見出しに ▾ が付きます。表示する値にチェックを入れると、ほかの行は非表示になります(削除はされません)。もう一度押すとすべての行が表示されます。
  • ❄ 固定はスクロールしても、アクティブセルより上の行と左の列を表示したままにします。
  • Σ はアクティブセルの上(または左)の数値を合計します。

シートとファイル

  • グリッドの下のタブがワークブックのシートです。＋ で追加、ダブルクリックで名前の変更、右クリックで複製・移動・削除。
  • 💾 保存(Ctrl+S)はボックスの名前でワークブックを保存します。📂 開く ▾ でこのプロジェクトのワークブックの一覧、📄 新規で空のワークブックを始めます。
