画像エディター

エディターのレイアウト、ツール、キー操作について説明します。

✅ View ▸ Dockers、ドッカーグループの折りたたみと閉じる操作（2.514.0）

  • ドッカーグループのタブの先頭にある ▾ で、グループをタブだけに折りたたみます。タブをクリックすると再び開きます。
  • ✕ でグループを閉じます。View ▸ Dockers には画像エディターのすべてのドッカーがチェック付きで並び、All Dockers ですべてを元に戻せます。
  • アプリのサイドドッカーは、タイトルバーの ▾ で細いタイトル帯に折りたたまれます。
  • 🖌 Edit theme モード：要素のハンドルをドラッグするとサイズを変更、要素の内側をドラッグすると移動できます。要素を非表示にしたり、テキストを変更したりすることもできます。モードを終了すると、テーマを保存するかどうか確認されます。

✅ Pen P (2.421.0)

  • Pen：クリックでコーナーアンカー、ドラッグでスムーズアンカー（ハンドルは対称に動きます）、最初のアンカーをクリックでパスを閉じます。Alt でカスプ、Shift で 45° 刻み、Ctrl で一時的に Direct Selection、Enter / Esc でパスを開いたまま終了します。選択中のパスの上では、セグメント上でアンカーを追加し、アンカー上でそのアンカーを削除します（Auto Add/Delete）。
  • Freeform Pen：手描きで描画します。Curve Fit (px) で、ベジェ曲線が描いた軌跡にどれだけ忠実に沿うかを指定します。始点の近くで描き終えるとパスが閉じます。
  • Add / Delete Anchor Point、Convert Point（クリック：曲線 ⇄ コーナー、アンカーをドラッグ：新しいハンドル、ハンドルをドラッグ：カスプ）。Shift+P でこれらを順に切り替えます。エディター上では P は Pen ですが、それ以外の場所では従来どおりプロンプトドッカーの表示／非表示を切り替えます。
  • Mode：Shape はシェイプレイヤーを描画し（描画色で塗り、背景色 + W の幅で線）、Path は Work Path を描画します。▣ ⊕ ⊖ ⊗ ⊘：New Layer、Combine、Subtract Front Shape、Intersect、Exclude。

✅ Path Selection / Direct Selection A (2.421.0)

  • Path Selection：コンポーネントをクリックして選択（Shift で追加）、ドラッグで移動、Alt+ドラッグでコピー、Delete で削除します。演算方法はオプションバーで指定します。⧉ Merge Components（結果を単純なアウトラインにします）、⟳ Transform…（拡大縮小、回転、反転）。
  • Direct Selection：アンカーとハンドルを操作します。Shift で追加、矩形で囲んで複数選択、矢印キーで微調整（Shift で ×10）、Delete で削除、Corner / Smooth。シェイプレイヤーのアウトラインをクリックすると編集できます。アンカーを動かした時点で、シェイプレイヤーはパスになります。

✅ カスタムシェイプ U (2.421.0)

  • Custom Shape ツール：ハート、星、バースト、矢印、シェブロン、プラス、クロス、チェック、稲妻、吹き出し、しずく、月、家、雲、リング、フレームをドラッグで描きます（Shift で縦横比を保持）。Edit ▸ Define Custom Shape… で選択中のパスを追加します（ピッカー内の自作シェイプを右クリックすると削除されます）。
  • Shape ツール（長方形、楕円、多角形、直線）にも同じ演算ボタンがあります。New Layer 以外を選ぶと、アクティブなシェイプレイヤーに追加されます。

✅ Paths パネル（2.421.0）

  • Layers と History の隣にあり、Work Path、保存済みのパス、アクティブなレイヤーの Shape Path と Vector Mask を表示します。クリックで選択、Ctrl+クリックで選択範囲として読み込みます（Shift で追加、Alt で除外）。Work Path をダブルクリックすると保存、保存済みのパスをダブルクリックすると名前を変更します。
  • ● 描画色で塗りつぶし · ○ ブラシで境界線を描画 · ⬚ 選択範囲として読み込み · ⟲ 選択範囲から作業用パスを作成 · ◇ ベクトルマスク · ＋ 新規 · ⧉ 複製 · ☰ その他（保存、SVG、カスタムシェイプ、シェイプレイヤー） · 🗑 削除。● ○ ⬚ ⟲ を Alt+クリックすると、それぞれのオプションが開きます。

✅ ベクトルマスク（2.421.0）

  • Layer ▸ Vector Mask：Reveal All、Hide All、Current Path、Disable / Enable、Rasterize（ピクセルマスクに変換）、Delete。サムネイルはレイヤーマスクのサムネイルの隣にあり、クリックでパスを編集、Shift+クリックでオフ／オンを切り替えます。
  • Properties：Density、Feather、Invert、Link。切り抜き、キャンバスサイズ、画像サイズ、回転を行うと、すべてのパスも画像と一緒に変換されます。PSD はベクトルマスクとパスのシェイプレイヤーを保持します。File ▸ Export Path as SVG… / Place SVG as Shape Layer…。

✅ スマートオブジェクト（2.422.0）

  • Layer ▸ Smart Objects: Convert to Smart Object：レイヤーまたはグループが内部に格納されます（引き続き編集可能です）。スマートオブジェクト (▣) はその内容から再描画されるため、拡大縮小・回転・ワープを行っても画質が劣化しません。
  • Edit Contents（サムネイルをダブルクリック）：内部がバナー付きで開きます。✔ Done でスマートオブジェクトとそのすべての複製が更新され、✕ Cancel で変更せずに閉じます。New Smart Object via Copy = 内容が独立した複製を作成します。Replace Contents…、Export Contents…、Convert to Layers、Rasterize。

✅ スマートフィルター（2.422.0）

  • スマートオブジェクトに適用した Filter / Adjustment は、レイヤーの下に「追加」されます。👁 でオン／オフ、ダブルクリックで設定、右クリックで不透明度、▲ で順序、✕ で削除します。
  • filter mask（Smart Filters の行にあります）：クリックしてペイントします。黒く塗った部分ではフィルターが隠れます。Shift+クリックでオフになります。

✅ Skew、Distort、Perspective、Warp (2.422.0)

  • Edit ▸ Transform: Skew / Distort / Perspective / Warp、またはスマートオブジェクト上で Ctrl+T。モードはオプションバーで切り替えます。Warp：グリッドの点、または内側の任意の位置をドラッグします。Bend % 付きのプリセットもあります。Enter で適用、Esc でキャンセルします。

✅ Puppet Warp (2.422.0)

  • Edit ▸ Puppet Warp：クリックでピンを打ち、ピンをドラッグして曲げます。Alt+クリック / Delete でピンを削除します。Density、Show Mesh。スマートオブジェクト上ではスマートフィルターとして適用されます。

✅ Content-Aware Scale (2.422.0)

  • Edit ▸ Content-Aware Scale…（Alt+Shift+Ctrl+C）：幅／高さを % で指定すると、重要でないピクセルが削られます（または複製されます）。Protect: the selection、ライブプレビュー付きです。

✅ Liquify (2.422.0)

  • Filter ▸ Liquify…（Shift+Ctrl+X）：W 押し出し、R 復元、C 渦（Alt で逆回転）、S 縮小、B 膨張、F / D 固定／固定解除。サイズは [ ]、筆圧、Restore All。スマートオブジェクト上ではスマートフィルターとして適用されます。

✅ Select and Mask (2.423.0)

  • Select ▸ Select and Mask…（Alt+Ctrl+R）：Quick Selection W、Refine Edge R（髪の毛の上で使います）、Brush B（Alt で削除）、表示モード、Radius / Smart Radius、Smooth、Feather、Contrast、Shift Edge、Decontaminate Colors、Output To Selection / Layer Mask / New Layer / New Layer with Layer Mask。

✅ Magnetic Lasso、Quick Selection、Sky (2.423.0)

  • Magnetic Lasso（L）：エッジに沿って動かすと、エッジに吸着します。クリックで点を設定、Backspace で 1 点戻し、ダブルクリック / Enter で閉じます。Width、Contrast、Frequency。
  • Quick Selection（W）：ペイントすると、選択範囲がエッジまで広がります。Alt で削除。Tolerance、Auto-Enhance。Select ▸ Sky。

✅ チャンネルと保存した選択範囲（2.423.0）

  • Channels タブ：RGB / Red / Green / Blue（クリックで表示、Ctrl+2 … 5、Ctrl+クリックでその明るさを選択範囲として読み込み）とアルファチャンネル。Select ▸ Save Selection… / Load Selection…、⬚ ◫ ＋ 🗑。

✅ Patch、Content-Aware Move / Fill、Red Eye (2.423.0)

  • J：Spot Healing（Content-Aware / Proximity Match）、Healing Brush（ブレンド：テクスチャはソースから、明るさは適用先から取ります）、Patch（対象を囲み、きれいなテクスチャの上へドラッグ）、Content-Aware Move（選択範囲をドラッグ：Move / Extend）、Red Eye（瞳孔をクリック）。
  • Edit ▸ Content-Aware Fill… と Edit ▸ Fill… の Content-Aware は AI を使いません。画像自体の内容から塗りつぶします。

✅ Mixer Brush、Background / Magic Eraser (2.423.0)

  • Mixer Brush（B）：Wet、Load、Mix、Clean after each stroke。Background Eraser（E）：Continuous / Once、Tolerance、Protect Foreground Color。Magic Eraser（E）：クリックした色を消去します（Tolerance、Contiguous）。

✅ PDF ファイル：開く、編集する、保存する（2.424.0）

  • Save PDF… / Save as New PDF… (2.435.0)：Save ダイアログの Embed fonts を使うと、各行がそれぞれのフォントで書き出され、フォントが埋め込まれます（使用した文字のみ）。フォントはこのコンピューターのフォント、またはインストール先の fonts フォルダーから取得します。どの文字体系でも本物のテキストのまま保持されます。
  • File ▸ Open PDF…（または .pdf をドロップ）、Open PDF from Project…：Pages ストリップが表示されます。ページは、テキストを除いた Background と、行ごとのテキストレイヤー（フォント、サイズ、色、幅を元に合わせたもの）として開きます。
  • すべてのツールで編集できます。各ページは独自のレイヤーと取り消し履歴を保持します（別の画像を開いている場合も同様です：File ▸ PDF Pages）。
  • 💾 Save PDF：変更したページが元の PDF 内で置き換えられます（プロジェクト内のコピーに保存され、ダウンロードもされます）。Save as New…。変更していないページはベクターのまま残り、テキストは選択可能な本物の PDF テキスト（Helvetica / Times / Courier）になります。これらのフォントで表現できない文字は画像に焼き込まれます。

✅ ベクターライン：曲線ツール、Shape ツール、Outline Pen (2.425.0)

  • F5（もう一度押すと次のツール）：Bézier（クリックでカスプノード、ドラッグでスムーズノード、ドラッグ中に C / S、Ctrl で 15° 刻み、最初のノードをクリックで閉じる、ダブルクリック / Enter / Space で完了、Esc で破棄）、Freehand、2-Point Line、Polyline、3-Point Curve、B-Spline、Node Pen。アクティブなラインの開いた端から描き始めると、そのラインを延長できます。
  • F10 Shape tool：ノード、ハンドル、セグメントを選択／ドラッグします。ダブルクリックでノードを追加／削除、C S Y でカスプ／スムーズ／対称。結合、分割、直線化／曲線化、方向の反転、閉じる、抽出、自動で閉じる、ノードの削減。
  • F12 Outline Pen：幅、色、破線、角の形状、線端、位置、矢印、塗りの背面に配置、オブジェクトに合わせて拡大縮小。Ctrl+Q Convert to Curves。
  • Layer ▸ Vector Line: Convert to Path… / Make from Path…（Paths パネルの 〰）：ラインはアウトライン設定を記憶したパスになり、正確に元のラインへ戻せます。SVG と PSD でも保持されます。

✅ Curvature Pen、Rubber Band、パスの整列／分布（2.425.0）

  • Curvature Pen（P）：点をクリックすると、曲線がその点を通ります。点をダブルクリックでコーナー／スムーズを切り替え、ドラッグで移動、Enter で終了します。Pen の Rubber Band オプション。Path Selection（A）：選択したコンポーネントを整列／分布します（コンポーネント同士、またはキャンバス基準）。

✅ Character / Paragraph パネル、段落テキスト、スタイル（2.426.0）

  • Character（Color の隣）：フォント、スタイル、サイズ、行送り、カーニング、トラッキング、垂直／水平比率、ベースラインシフト、色、Faux Bold / Italic、All Caps、Small Caps、Superscript / Subscript、Underline / Strikethrough。
  • Paragraph：揃え、最終行の Justify（左揃え／中央揃え／右揃え／両端揃え）、インデント（左、右、1 行目）、段落前後のスペース、Hyphenate。Paragraph text（段落テキスト）：Type ツール（T）でドラッグすると、テキストがボックス内で折り返されます。Layer ▸ Type: Convert to Paragraph / Point Text。
  • Character / Paragraph Styles：＋ でテキストから新規作成、クリックで適用、⌫ Clear Override、⟲ Redefine（そのスタイルを使うすべてのテキストに反映されます）、🗑。

✅ Actions と Batch (2.427.0)

  • Actions タブ（History の隣、Alt+F9）：● 記録（メニューコマンドとそのダイアログの設定、フィルター、Layers パネルの操作）、■ 停止、▶ 再生。☑ でステップのオン／オフ、▢ でそのダイアログで一時停止、▲ ▼ 🗑。ダブルクリックでステップを再記録／アクション名とファンクションキーを設定します。☰ Insert Stop、Insert Menu Item、Duplicate、Button Mode、Load / Save (.json)、Reset。
  • File ▸ Automate: Batch…：選択したファイルまたはフォルダーに対してアクションを実行します。結果はプロジェクトの batch フォルダー、画像ギャラリーに保存するか、ダウンロードするか、そのままにできます。PNG / JPEG。エラー時は停止するかログに記録します。レポートも作成されます。

✅ 描画ツール（2.428.0）

  • F6（もう一度押すと次のツール）：Rectangle（角の半径。角丸／スカラップ／面取り）、3-Point Rectangle、Ellipse（扇形／円弧）、3-Point Ellipse、Polygon、Star、Complex Star、Spiral、Graph Paper、Common Shapes。Ctrl で正方形／正円、Shift で中心から描画します。F10 でノードを編集するか Ctrl+Q を押すまでは、ライブシェイプのまま編集できます。
  • Artistic Media（F5 のグループ内）：Preset、Calligraphic、Pressure、Sprayer。
  • F8：Parallel、Horizontal / Vertical、Angular Dimensions、3-Point Callout、Connector（直線／直角／角丸。接続したオブジェクトに追従します）。

✅ ドッカー（2.429.0）

  • Window ▸ Dockers：Transform（Alt+F7：位置、回転、拡大縮小と反転、サイズ、傾斜。9 つの基準点を中心に操作でき、コピーも作成できます）、Shaping（結合、トリム、交差、単純化、前面／背面の型抜き、境界）、Align and Distribute（Shift+Ctrl+A）、Object Properties（Alt+Enter：グラデーションを含む塗り、アウトライン、透明度）。Ctrl+クリックでレイヤーを複数選択できます。

✅ ドキュメント、カラーパレット、⊠ 透明、自動塗りつぶし（2.430.0）

  • Documents：New / Open を行うたびに、それぞれ独立したドキュメントになります。最初のドキュメントはタブとしてドッキングされ、以降のドキュメントは個別のウィンドウでフローティング表示されます（Window ▸ Arrange ▸ Open Documents as Tabs ですべてをドッキングします）。ウィンドウをタブストリップにドラッグするとドッキング、タブをストリップの外へドラッグするとフローティングになります。Ctrl+W で Close、Alt+Ctrl+W で Close All、Ctrl+Tab で次のドキュメント。Tile / Cascade / Consolidate All to Tabs。
  • 右側の Colour palette：曲線／シェイプ／テキストの上では、クリックで塗り、右クリックでアウトラインの色を設定します。ピクセルの上では、クリックで描画色、右クリックで背景色を設定します。⊠ = 色なし／透明な描画色（ブラシで透明を塗ります）。
  • Auto-fill：閉じた曲線や新しいシェイプは、最後に選んだ色で塗りつぶされます（曲線ツールのバーにある ▨ でオフにできます）。

✅ 生成した画像をキャンバスへ（2.431.0）

  • エディターを開いている間、プロンプトドッカーは 🖼 Image（→ ▦ キャンバス）を生成し、作成された画像はすべて、前面にあるドキュメントにプロンプト名の付いた新しいレイヤーとして配置されます（ドキュメントがない場合は新しいドキュメントとして開きます）。エディターを閉じると、プロンプトドッカーは元のモードに戻ります。

✅ パネル列はドッカーです（2.454.0）

  • ⇱ で任意のタブグループをフローティングにできます。タイトルをつかんで列の上にドラッグすると、ドッキングする位置がオレンジ色の線で示されます。
  • 列の左端をドラッグすると幅を変更できます。並び順と幅は保持されます。

✅ フレーム：内容をロック、右クリックで編集（2.453.0）

  • 内容はフレームにロックされます。Move ツールとそのハンドルはフレームを操作し、内容はフレームと一緒に移動／拡大縮小／回転します。
  • 右クリック ▸ Edit Frame Contents / Finish Editing Frame / Extract Contents / Lock Contents to Frame。

✅ Move ツールのハンドル（2.452.0）

  • クリックで拡大縮小ハンドル（Shift で縦横比を保持、Alt で中心から）、ダブルクリックで回転ハンドル（角で回転、Shift で 15° 刻み、辺で傾斜）を表示します。
  • オプションバーの変形オプション：角度、⟲90 ⟳90、反転、W % x H %。
  • テキストは回転しても編集可能なまま、シェイプはベクターのままです。

✅ プロンプトドッカーからの Edit / Generate、Del (2.451.0)

  • ✨ AI ▸ Edit：プロンプトドッカーが 🖼 Image + Qwen Image 2.1 edit に切り替わり、ボタンの表示が ✏ Edit になります。Generate：✨ Generate で、選択したレイヤーの選択範囲内に生成します。
  • Del で現在のレイヤーを削除します（選択範囲がある場合は、その範囲を消去します）。

✅ Warp のグリッド + 分割線、Liquify の追加機能（2.450.0）

  • Warp：Grid（Default / 3 x 3 / 4 x 4 / 5 x 5 / Custom の列 x 行）。Split Warp Crosswise / Vertically / Horizontally：分割したい位置をクリックします。分割線を Alt+クリックすると削除されます。
  • Liquify：Smooth (E)、Push Left (O)。
  • Face-Aware Liquify：Face ツール (A) で顔の位置を指定します。目、鼻、口、顔の形を調整する 13 個のスライダーがあります。

✅ 文字単位の書式（2.449.0）

  • 入力中に文字を選択し、オプションバー（フォント、B、I、サイズ、トラッキング、色）または Character パネルで変更すると、選択した文字だけが変わります。
  • 何も選択していない場合はレイヤー全体が対象になります。書式付きの範囲の中で入力すると、その書式が引き継がれます。ベースラインは 1 本で、各行の高さはその行で最も大きい文字に合わせられます。
  • Layer ▸ Type: Clear Character Overrides。

✅ Content-Aware Fill ワークスペース（2.448.0）

  • Edit ▸ Content-Aware Fill…（選択範囲が必要です）：サンプリング領域が緑色で表示されます。Auto、Rectangular、Custom（🖌 Sampling Brush の + / −、Alt）。
  • ライブ Preview。Colour Adaptation は None / Default / High / Very High。
  • Output To Current Layer / New Layer / Duplicate Layer。取り消しは 1 回で済みます。

✅ アートボード（2.447.0）

  • Layer ▸ New ▸ Artboard…（サイズ、背景、選択したレイヤーを含めるかどうか）、Artboard ツール（V をもう一度押す）、Artboard from Group。
  • アートボードのレイヤーはその内側にだけ表示され、アートボードを動かすとレイヤーも一緒に動きます。Properties：X / Y / W / H、背景、⇱ Fit。
  • File ▸ Export ▸ Artboards to Files…：アートボードごとに PNG を 1 枚書き出します。

✅ グリッドボタン、Grids & Guides 設定（2.445.0）

  • 上部バーの ⊞：グリッドのオン／オフ (Ctrl+')。
  • ⚙ ▸ Grids & Guides：グリッド間隔、n 本ごとの主線、線またはドット、グリッドの色 + 濃さ、ガイドラインの色、スナップ距離。

✅ CAD 寸法：正確な点、リアルタイムに追従する端点、縮尺（2.441.0）

  • 寸法ツールは、ノード、中点、角、辺の中点、アウトライン上の最も近い点、ガイドラインの交点にスナップします（点の位置に名前が表示されます。Alt で自由に配置）。
  • 寸法に Move ツールを使い、端をドラッグすると、数値がリアルタイムに追従します。Shift で水平、Ctrl で垂直。
  • プロパティバーの 📏：選択した寸法の実寸 + 単位を入力すると、それが画像の縮尺になり、すべての寸法に適用されます（Layer ▸ Dimension Scale…）。

✅ 定規、ガイドライン、スナップ（2.440.0）

  • Rulers（Ctrl+R）の単位は px、mm、cm、in、pt から選べます（View ▸ Ruler Units）。定規からドラッグするとガイドラインが作成されます。Move ツール（または Ctrl）でガイドラインを移動し、定規の上に戻すと削除されます。View ▸ Guidelines / Lock / New… / Guidelines… / Clear。
  • View ▸ Snap To：Snap（Shift+Ctrl+;）、Grid、Guidelines、Objects、Nodes、Midpoints、Intersections、Page。描画ツールではポインターが、Move ツールではレイヤーのボックスがスナップします。Grid and Snapping… で距離、グリッド間隔、dpi を設定します。

✅ プロパティバー、角の半径、シェイプへの ⊕ / ⊖、線の幅とスタイル（2.439.0）

  • ツールオプションの下にある Object バー：選択したレイヤーの X Y W H。🔒 で縦横比を保持します。
  • 長方形：4 つの角の半径（🔗 = すべて連動）。ベクターシェイプ：アウトラインの幅（プリセット付き）と線のスタイル（画像から選択）。
  • シェイプツール (F6)：◻ New / ⊕ Add / ⊖ Subtract / ⊗ Intersect / ⊘ Exclude。シェイプを選択した状態で描くと、新しいシェイプはその一部として結合されます。元のシェイプはそのまま残ります。

✅ フローティングパネルグループ、名前付きドッカー、中央に開くダイアログ（2.438.0）

  • Layers / Colour グループのタブにある ⇱ で、グループをエディター内でフローティングにします。タイトルでドラッグ、各辺でサイズ変更、⇲ で元の位置に戻します。
  • Window ▸ New Docker…：名前付きの空のドッカーを作成します。フローティンググループをその上にドラッグすると、タブとしてドッキングされます。⚙：メインドッカーにする／ドッカー内に限定する、名前の変更、削除。panel_layout.cfg に保存されます。
  • ダイアログは画面の中央、または最後に移動した位置に開きます（dialog_layout.cfg）。Shift+Del で選択したレイヤーを削除します。

✅ ✨ Generate Fill in Shape / in Mask、パターンライブラリ（2.437.0）

  • Layer ▸ ✨ Generate Fill in Shape…（レイヤーの右クリック、または Properties からも使えます）：レイヤーのアウトラインの内側に生成します。✔ Apply で、シェイプにクリッピングされた新しいレイヤーに配置されます（ライブのまま保持されます）。✨ Generate Fill in Mask…：レイヤーのマスクの内側に生成し、結果にはそのマスクのコピーが付きます。
  • Edit ▸ Define Pattern… / Pattern Library…：インストールフォルダーの patterns/<name>.png に保存されます。New Fill Layer ▸ Pattern…（拡大率、オフセットは Properties で設定）、Edit ▸ Fill ▸ Pattern、Pattern Overlay（user:<name>）。.bgi には使用しているパターンが含まれます。

✅ プロジェクトファイル：.bgi (2.436.0)

  • File ▸ Save Project (.bgi) Alt+Ctrl+S / Save Project As (.bgi)…：ドキュメントをそのままの状態で保存します。レイヤー、グループ、マスク、テキスト／シェイプ／塗りつぶし／調整レイヤー、スタイル、内容とスマートフィルターを含むスマートオブジェクト、パス、チャンネル、選択範囲、レイヤーカンプが、プロジェクトの bgi フォルダーに保存されます（指定した場合はダウンロードもされます）。
  • Open Project (.bgi)…、Open Project from Project…、Open…（Ctrl+O）、または .bgi をエディターにドロップ：新しいドキュメントとして開き、すべて編集可能で、履歴は新しく始まります。
  • zip 形式です：doc.xml（XML 形式のドキュメント）+ preview.png + 各レイヤー／マスクの PNG。

✅ Gradient Editor、Layer Comps、スマートフィルターの描画モード（2.434.0）

  • Gradient Editor（Edit ▸ Gradient Editor…、Gradient ツールのグラデーションボタン、塗りつぶしレイヤーやシェイプのグラデーション）：プリセット + 自作のグラデーション。バーの下をクリックで新しい分岐点、ドラッグで移動、下へドラッグで削除します。各分岐点の色（または描画色／背景色）、不透明度、位置。Reverse、Distribute。
  • Layer Comps（Window ▸ Layer Comps）：レイヤーの表示／位置／外観を保存して切り替えます（▶、◀ ▶）。↻ で更新、Last Document State。
  • Smart filter Blending Options（スマートフィルターを右クリック）：描画モード + 不透明度。
