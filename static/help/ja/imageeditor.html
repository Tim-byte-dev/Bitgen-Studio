🟧 Blender スキル：✨ AI でモデリングと 🧰 Blender ツール（2.855.0）

  • 🟧 ▾ メニュー（とファイル ▸ 🟧）に ✨ AI でモデリング… があります：作るもの（例：「取っ手付きの陶器のコーヒーマグ」）を書き、スキルを選ぶか自動のままにして ✍ スクリプトを書く - プロンプトドッカーの LLM が、合う Blender スキルシートを使って Blender スクリプトを書きます。実行前にスクリプトが表示され、読んで変更できます。bitGen が確認します：Blender 自身のモジュールのみ、ファイルなし、ネットワークなし、プログラムなし。
  • ▶ コピーで実行 は、開いているシーン（または空のシーン）のコピー上で、あなたの Blender をウィンドウなしで動かします - 結果はプロジェクトの blender/scenes フォルダーの新しいシーンで、元のファイルは変更されません。Blender がエラーを出すと LLM がそれを受け取り、スクリプトを修正します（最大 3 回）。プレビュー、作られたもの、QA チェックの警告が表示され、🟧 Blender レイヤーとして開く で開けます。
  • 🧰 Blender ツール… はスキル自身のツールを開いているシーンのコピーで実行します：📉 LOD、🗺 UV パック、🔥 マップのベイク、📤 ゲームエンジン向けエクスポート（Unreal、Unity、Godot、Roblox、Web）、🎨 トゥーン、🌇 時間帯、🌧 天候、🔄 ターンテーブル、✅ QA チェック - それぞれ独自の設定付き。
  • スキルには Blender 5.2 以降 が必要です。古い場合（またはない場合）はその旨と ⬇ ダウンロード（blender.org）が表示されます。スキルシートとスクリプトは EL4CTEO の blender-skills（MIT）で、設定 ▸ 情報 に記載しています。

🛒 ウェブサイトのショップ：カタログ・カート・購入手続き（2.850.0）

  • 🌐 ウェブサイトを作成 ▸ 🛒 ショップで、PHP + MySQL のウェブサイトにショップが付きます。チェックすると PHP + MySQL と 🔐 管理エリアも選ばれます。商品・注文・顧客は管理データベース（myadmin）にあるためです。ヘッダーにショップとカート（入っている数付き）が付きます。
  • shop.php（カタログ）：有効な商品を画像と価格付きで表示（セール価格は元の価格の横に表示）。カテゴリーと、名前・説明・SKU での検索。おすすめ商品が先に並びます。
  • product.php：画像、説明、オプション（独自価格のバリエーション。在庫切れのものは選べません）、数量。取り寄せを許可した商品以外は、在庫より多くカートに入れることはできません。
  • cart.php：数量の変更、削除、コードの入力（割引率、割引額、送料無料。期間・利用回数・最低購入額付き）、配送方法の選択（一定額以上で無料）。税は設定に従い、価格に含まれるか上乗せされます。
  • checkout.php：名前、メール、電話、住所（配送がある場合）、支払い方法：銀行振込 および / または 受け取り時払い。オンラインのカード決済には決済事業者でのショップ自身のアカウントが必要なため、組み込まれていません。
  • 注文の確定はすべて一度に行われるか、まったく行われません：在庫を再確認して差し引き（変更はすべて stock_movements に記録）、顧客をメールで検索または追加して住所を保存、注文に番号（ORD-00001）、明細、状態の履歴、保留中の支払いを付け、コードの利用回数を数えます。購入者とショップにメールが届きます。
  • order.php：注文ごとのページ。購入者のメールにある専用リンクでのみ開けます。明細、合計、状態、支払い方法を表示します。
  • /admin/ ▸ 設定：currency、tax_rate、prices_include_tax、pay_bank + bank_details、pay_pickup + pickup_note、order_email（新しい注文の通知先）、order_prefix。商品、カテゴリー、クーポン、配送方法、注文も /admin/ にあります。古い myadmin データベースには新しい列が自動で追加されます。
