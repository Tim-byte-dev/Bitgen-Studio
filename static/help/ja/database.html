🗄 データベース

プロジェクト用、全プロジェクト用、またはあなたのサーバーの MySQL / MariaDB データベース - 説明すると AI がテーブル、フィールド、ビューを設計します。上部バーの 🗄 ボタンでドッカーを開閉します。

置き場所

  • 📁 このプロジェクト - bitGen がプロジェクト用に自前の MariaDB サーバーを動かし、データはプロジェクトの db フォルダーに入ります。プロジェクトと一緒に移ります。
  • 🌐 グローバル - すべてのプロジェクト用の MariaDB サーバー 1 つ、データはアプリの db フォルダー。
  • 🖧 あなたのサーバー - どの MySQL / MariaDB サーバーでも（⚙ あなたのサーバー…：ホスト、ポート、ユーザー、パスワード、データベース）。パスワードはこのコンピューターに暗号化して保存されます。

bitGen 自前のサーバーはこのコンピューターだけ（127.0.0.1）で待ち受け、必要なときに自動で起動し（手動で ▶ / ⏹ も）、bitGen を閉じると止まります。初回は MariaDB 本体が必要です：このコンピューターにない場合はダウンロード / キャンセルのボックスが出ます（MariaDB、GPL-2.0、archive.mariadb.org から、アプリの mariadb フォルダーへ）。Mac では Homebrew で入れてください（brew install mariadb）- bitGen が見つけます。

✨ 設計 - AI がテーブルを作る

  • 用途を説明します：「小さな店：顧客、在庫のある商品、明細付きの注文、月別売上と上位顧客のビュー」。
  • ✨ テーブルを設計：プロンプトドッカーの LLM が SQL を書きます - フィールドと型を持つテーブル、キー、テーブル間のリンク、インデックス、ビュー。既にあるテーブルを見ているので、後から追加を頼めます（「仕入先を追加」）。
  • SQL は先に表示されます。読んで、必要なら直してから ▶ 実行。1 文ずつ実行し、最初のエラーで止まります。設計でテーブルやデータが消されることはありません。
  • プロンプトドッカーで言っても：「顧客と注文のある店のデータベースを作って」- 設計の入ったドッカーが開きます。

テーブル、データ、SQL

  • 左：テーブル（▦）とビュー（👁）とそのフィールド - 🔑 キー、🔗 他のテーブルへのリンク。
  • クリックすると 📋 データ - 最初の 200 行。
  • ⌨ SQL は入力した SQL を実行し（複数の文、それぞれ ; で終わる）、結果を表示します。
  • ＋ 新規でデータベースを作り、🗑 で表示中のものを削除します（確認あり）。
