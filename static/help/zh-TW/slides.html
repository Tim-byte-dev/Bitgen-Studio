🎞 幻燈片

bitGen 中的簡報——帶有標題、要點、圖片和形狀的幻燈片，全螢幕放映。頂部欄的 🎞 按鈕開啟和關閉停靠窗（⛶ 將其放大）。簡報儲存在專案的 slides 資料夾中（.bgk 檔案）；正在做的內容也會儲存在瀏覽器中，所以關閉停靠窗不會丟失任何內容。

幻燈片

  • 左側清單顯示每張幻燈片。點選一張進行編輯；上下拖曳以移動；右鍵點選可在其後新建幻燈片（選擇版式）、複製、在演示中隱藏、上移 / 下移、刪除。
  • ＋ 幻燈片 ▾（或 Ctrl+M）在這一張之後新增幻燈片——選擇其版式：標題幻燈片、標題和內容、兩欄內容、節標題、帶標題的圖片、僅標題、空白。▤ 版式 ▾ 更改這張幻燈片的版式——文字會移入新版式的框中。
  • 🎨 主題 ▾ 為整個簡報設定背景、顏色和字型。Bg 為一張幻燈片設定自己的背景（↺ = 恢復主題背景）。

文字、形狀和圖片

  • 空框會說明要放什麼（“Click to add a title”）。雙擊一個框（或選取後按 Enter）並輸入；按 Esc 或在框外點選即完成。每一行是一個段落；在帶專案符號的框中每行都有一個符號。
  • 🅃 文字 新增文字框（雙擊幻燈片空白處也可以）。⬚ 形狀 ▾：矩形、圓角矩形、橢圓、三角形、菱形、箭頭、星形、線條——雙擊形狀可在其中輸入文字。
  • 🖼 圖片、拖放到幻燈片上的圖片，或複製的圖片 Ctrl+V。在“帶標題的圖片”幻燈片上會填入圖片框。右鍵 ▸ 適應 / 填滿框。
  • 點選選取，Shift / Ctrl+點選加選，或在空白處拖一個框框選。拖曳以移動——與幻燈片中心、邊緣或其他專案對齊時會顯示粉色線（Alt = 不吸附，Shift = 直線）。白色方塊調整大小（Shift 保持形狀；圖片除非按住 Shift 否則保持形狀）。方向鍵微移（Shift = 10 px）。
  • 工具列：字型、字號、B I U、顏色、左 / 中 / 右、⇕ 上 / 中 / 下、•≡ 專案符號；形狀的填充、線條及其粗細；⇡ 置於頂層，⇣ 置於底層；🗑 刪除。Ctrl+D 複製一份，Ctrl+C / X / V 複製、剪下和貼上（也可在幻燈片和簡報之間），Ctrl+A 全選，Ctrl+Z / Ctrl+Y 復原 / 重做。
  • 演講者備註寫在幻燈片下方的框中。

✨ AI 製作幻燈片

  • ✨ AI ▾ 製作幻燈片…：寫下幻燈片的主題，和 / 或貼上文字、筆記或大綱（或 📄 選擇 .txt / .md 檔案）——提示詞停靠欄的 LLM 會規劃幻燈片：一張標題幻燈片，然後是要點簡短的幻燈片、兩欄和章節幻燈片，以及演講者備註。選擇幻燈片數量，新的簡報或在這張幻燈片之後。
  • 🖼 帶圖片：部分幻燈片會成為圖片幻燈片，每個圖片框會得到一張用提示詞停靠欄中選擇的影像風格生成的圖片——一次一張，完成一張就放進它的框裡（期間可以繼續工作；Ctrl+Z 可撤回圖片）。生成期間同一選單中有 ■ 停止生成圖片。
  • 按原樣使用大綱：不用 LLM——# 標題是簡報的標題，其他標題或普通行各成一張幻燈片，- 或 1. 行是它的要點，> 行是演講者備註。
  • 對目前顯示的幻燈片：✍ 重寫這張幻燈片、✂ 縮短、✓ 修正文字（只改拼寫和語法）和🎤 根據幻燈片寫演講者備註——每個都可一步復原。
  • 🖼 為空框生成圖片：每個空的圖片框都會得到一張根據其幻燈片文字生成的圖片。
  • 在提示詞停靠欄中：“make slides about bees”、“create a 6 slide presentation on solar power with pictures”——第一行之後的各行就是用來製作的文字。

放映

  • ▶ 放映（F5）從第一張開始，▶ 從此處（Shift+F5）從這一張開始——全螢幕。下一張：→ ↓ 空格 Enter Page Down 或點選；上一張：← ↑ Backspace Page Up 或右鍵；Home / End；輸入數字後按 Enter 跳到該張；B / W 黑屏 / 白屏；Esc 結束。隱藏的幻燈片會跳過。
  • 工具列上的切換：這張幻燈片的出現方式——無、淡入、推入、擦除、縮放。

演講者檢視

  • 🎤 演講者檢視（Alt+F5）：這個螢幕顯示目前幻燈片、下一張、你的演講者備註（A− / A+ 調整大小）、計時器（⏸ 暫停，↺ 從 0 重新開始）、時間和幻燈片編號；第二個視窗——觀眾視窗——只顯示幻燈片。把它移到投影儀或第二個螢幕上，雙擊（或按 F11）即可全螢幕。
  • 兩個視窗中可用相同的按鍵：→ / 空格 / 點選 = 下一張，← = 上一張，數字 + Enter，B = 給觀眾黑屏，Esc 結束並關閉觀眾視窗。工具列上有 ⬛ 和 🖥 觀眾（再次開啟）。

旋轉、專案中的圖片

  • 選取的專案上方有一個圓形控點：拖曳它即可旋轉專案（Shift = 每次 15°；會吸附到 0°、90°、180°、270°）。旋轉後的專案，其控點沿專案自身的邊調整大小。
  • 🖼 圖片 ▾：來自這臺電腦…、來自相簿…或來自素材…——從專案的圖片中挑選（帶搜尋）。

檔案

  • 📄 新建 ▾——選擇主題以及 16:9 或 4:3。📂 開啟 ▾ 列出本專案的簡報。💾 儲存（Ctrl+S）以框中的名稱儲存。
  • ⤓ PowerPoint 儲存為 .pptx——會下載並儲存在 slides 資料夾中：每張幻燈片的背景、文字（字型、字號、顏色、專案符號）、形狀、圖片和演講者備註。
  • ⤒ 開啟 PowerPoint（或把 .pptx 拖到幻燈片上）把 PowerPoint 檔案作為簡報開啟：幻燈片、文字（字型、字號、顏色、專案符號）、形狀、圖片、組合、背景、演講者備註、隱藏的幻燈片和切換效果；PowerPoint 存在版式中的位置也會從那裡讀取。表格、圖表和 SmartArt 會被省略（工具列會說明數量）。💾 儲存會把它儲存在這裡。
  • ⤓ PDF ▾：幻燈片（每張一頁）或幻燈片 + 演講者備註（備註在每張幻燈片下方）——下載並儲存在 slides 資料夾中。隱藏的幻燈片會被省略。
