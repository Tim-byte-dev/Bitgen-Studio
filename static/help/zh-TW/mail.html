✉ 郵件

在 bitGen 裡用你自己的 AI 讀寫電子郵件。bitGen 直接與你的郵箱通訊 - 用 IMAP 讀取，用 SMTP 傳送 - 所以無需註冊，中間也沒有任何雲服務。你在提示詞停靠窗中選擇的 LLM 會閱讀你的郵件、標記重要郵件、總結郵件並起草回覆。 頂端列上的 ✉ 按鈕用來開啟和關閉該停靠窗；它會顯示收件箱中的未讀郵件數。

新增帳戶（⚙ 帳戶）

  • 輸入你的郵箱地址 - Gmail、Outlook.com、Yahoo、iCloud、Fastmail、Zoho 和 GMX 的伺服器會自動填好；其他服務商的伺服器是推測的（imap. / smtp. + 你的域名）- 請向服務商核對。
  • 密碼：Gmail、Outlook.com、Yahoo 和 iCloud 會拒絕郵件程式使用你的普通密碼 - 請在帳戶的安全設定中生成一個應用專用密碼並貼上進來。密碼會加密儲存在這臺電腦上（settings/keys.json），之後不會再顯示。
  • 勾選 SSL = 從一開始就加密（收信埠 993，發信 465）；不勾選 = STARTTLS（143 / 587）。
  • ✓ 測試會登入兩臺伺服器，不傳送任何內容。檢查伺服器的證書請保持開啟，除非你自己的伺服器使用自簽名證書。
  • 在“已傳送”中儲存一份已發郵件 - Gmail 會自己儲存已發郵件，所以 Gmail 預設關閉此項。
  • 新郵件會自動加上簽名。有多個帳戶時：在停靠窗的帳戶清單中選擇。

閱讀

  • 左邊是資料夾，中間是郵件清單（未讀為粗體），右邊是郵件內容。↑ ↓ 在清單中移動，Delete 把郵件移到廢紙簍（在廢紙簍中則直接刪除）。
  • ★ 在伺服器上把郵件標記為待跟進，● 標記為未讀 / 已讀。
  • 來自網際網路的圖片會被隱藏，直到你按下顯示圖片 - 它們可能會告訴發件人你打開了郵件。郵件在這裡永遠不會執行腳本。
  • 點選 📎 附件即可下載。🔍 搜尋目前顯示的資料夾（發件人、主題、開頭的文字）。
  • ⟳ 檢查郵件立即檢查；bitGen 開啟期間也會每隔幾分鐘檢查一次（⚙ 帳戶 ▸ 檢查間隔）。

✨ AI

  • ✨ 用 AI 標記 - AI 閱讀尚未評級的郵件，並給每封郵件打上旗標：紅色 ⚑ 緊急（需要你儘快處理）、橙色 ⚑ 重要（真人來信、你的工作、帳單、預約）、藍色 ⚑ 普通、灰色 ⚑ 低（新聞通訊、促銷、自動郵件），理由顯示在主題下方。Shift+點選重新評級全部郵件。☐ ✨ 自動 = 新郵件一到就自動標記。
  • 告訴它對你重要的是什麼（⚙ 帳戶）- 你的客戶、你的會計、學校 - 這些郵件會被評得更高。
  • 顯示 ▸ ⚑ 重要只列出緊急和重要的郵件；✨ 最重要的在前按旗標排序。
  • ✨ 總結 - 兩句話的總結，以及你需要做什麼。
  • ✨ 起草回覆 / ✨ 全部回覆 - 輸入回覆要說的內容（也可以留空），選擇語氣，AI 就會在寫信視窗中寫好回覆。傳送前請通讀一遍 - 不按“傳送”什麼都不會發出去。

寫信（✉ 新建、↩ 回覆、↩↩ 全部回覆、↪ 轉發）

  • ✨ 幫我寫 - 用幾個詞或幾條筆記說明要寫什麼並選擇語氣；✨ 寫出來會寫好郵件和主題（在回覆中則寫回復）。
  • ✨ 改寫我寫的內容… - 更簡短、更友好、更正式、修正拼寫和語法、更有自信，或你自己的指示。↶ 復原可以撤回 AI 的修改。
  • 粗體、斜體、下劃線、專案符號、編號和連結；📎 附件或把檔案拖放到寫信視窗（總共最多 25 MB）。轉發時會帶上原郵件的附件。
  • ➤ 傳送（Ctrl+Enter）或 💾 儲存草稿（儲存到伺服器上的草稿箱）。

內容儲存在哪裡

你的郵件保留在郵件伺服器上。bitGen 會把顯示過的內容複製一份儲存在應用旁邊的 mail 資料夾中 （僅限這臺電腦 - 絕不會進入程式碼倉庫或釋出包）。刪除帳戶會同時刪除這份副本和儲存的密碼。AI 在你的 LLM 執行的地方執行：除非你在 🖥 GPU 停靠窗中把它設為 OpenRouter 或某個 Pod，否則就在這臺電腦上。
