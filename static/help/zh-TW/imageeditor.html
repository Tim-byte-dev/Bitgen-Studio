影像編輯器

編輯器的佈局、工具和快捷鍵。

✅ View ▸ Dockers；摺疊和關閉面板組（2.514.0）

  • 面板組標籤列開頭的 ▾ 可將該組摺疊為只顯示標籤；點選某個標籤即可重新展開。
  • ✕ 關閉該組。View ▸ Dockers 列出影像編輯器的所有面板（已顯示的帶勾選標記），另有 All Dockers 可將它們全部恢復。
  • 應用程式的側邊面板可透過其標題列中的 ▾ 摺疊為一條細窄的標題條。
  • 🖌 Edit theme mode（編輯主題模式）：拖曳元素的控制柄可調整其大小，在元素內部拖曳可移動它，也可以隱藏它或修改其文字。離開時會詢問是否儲存主題。

✅ Pen 鋼筆工具 P（2.421.0）

  • Pen：點選 = 角點錨點，拖曳 = 平滑錨點（兩側控制柄對稱），點選第一個錨點 = 閉合路徑。Alt = 尖角點，Shift = 以 45° 為步進，Ctrl = 臨時切換為 Direct Selection，Enter / Esc = 保持路徑開放。在已選路徑上，指向線段時新增錨點，指向錨點時刪除錨點（Auto Add/Delete）。
  • Freeform Pen：徒手繪製；Curve Fit（px）決定貝塞爾曲線貼合筆跡的緊密程度。在起點附近結束即閉合路徑。
  • Add / Delete Anchor Point、Convert Point（點選：曲線 ⇄ 角點；拖曳錨點：拉出新的控制柄；拖曳控制柄：轉為尖角點）。Shift+P 在這些工具之間循環切換。指標在編輯器上方時 P 是 Pen；在其他位置它仍用於顯示 / 隱藏提示詞面板。
  • Mode：Shape 繪製形狀圖層（用前景色填充，用背景色按 W 寬度描邊），Path 繪製 Work Path（工作路徑）。▣ ⊕ ⊖ ⊗ ⊘：New Layer、Combine、Subtract Front Shape、Intersect、Exclude。

✅ Path Selection / Direct Selection A（2.421.0）

  • Path Selection：點選一個元件（按 Shift 加選），拖曳可移動，Alt-拖曳可複製，Delete 刪除；其運算方式在選項列中設定；⧉ Merge Components（結果為普通輪廓）；⟳ Transform…（縮放、旋轉、翻轉）。
  • Direct Selection：操作錨點和控制柄——Shift 加選，框選可選取多個，方向鍵微移（Shift ×10），Delete 刪除，Corner / Smooth。點選形狀圖層的輪廓即可編輯它；一旦移動錨點，形狀圖層就會變為路徑。

✅ 自訂形狀 U（2.421.0）

  • Custom Shape 工具：心形、星形、爆炸形、箭頭、V 形、加號、叉號、對勾、閃電、對話氣泡、水滴、月亮、房子、雲朵、圓環、邊框——拖曳繪製（Shift 保持比例）。Edit ▸ Define Custom Shape… 將所選路徑新增為自訂形狀（在選取器中右鍵點選你自己新增的形狀即可將其刪除）。
  • Shape 工具（矩形、橢圓、多邊形、直線）具有相同的運算按鈕：除 New Layer 外，其他選項都會新增到目前的形狀圖層中。

✅ Paths 面板（2.421.0）

  • 位於 Layers 和 History 旁邊：顯示 Work Path、已儲存的路徑，以及目前圖層的 Shape Path 和 Vector Mask。點選 = 選取；Ctrl-點選 = 載入為選取範圍（Shift 新增，Alt 減去）。雙擊 Work Path = 儲存它；雙擊已儲存的路徑 = 重新命名。
  • ● 用前景色填充 · ○ 用畫筆描邊 · ⬚ 載入為選取範圍 · ⟲ 從選取範圍生成工作路徑 · ◇ 向量遮罩 · ＋ 新增 · ⧉ 複製 · ☰ 更多（儲存、SVG、自訂形狀、形狀圖層）· 🗑 刪除。Alt-點選 ● ○ ⬚ ⟲ 可開啟它們的選項。

✅ 向量遮罩（2.421.0）

  • Layer ▸ Vector Mask：Reveal All、Hide All、Current Path、Disable / Enable、Rasterize（柵格化到像素遮罩中）、Delete。其縮圖位於圖層遮罩縮圖旁邊：點選 = 編輯其路徑，Shift-點選 = 關閉 / 開啟。
  • 屬性：Density、Feather、Invert、Link。裁切、畫布大小、影像大小和旋轉會讓所有路徑隨圖片一起變換；PSD 會保留向量遮罩和路徑形狀圖層；File ▸ Export Path as SVG… / Place SVG as Shape Layer…。

✅ 智慧型物件（2.422.0）

  • Layer ▸ Smart Objects: Convert to Smart Object：將圖層或圖層組放入其中（仍可編輯）；智慧型物件（▣）根據其內容重新繪製，因此縮放 / 旋轉 / 變形都不會損失畫質。
  • Edit Contents（雙擊縮圖）：開啟其內部內容並顯示一條橫幅——✔ Done 更新該智慧型物件及其所有副本，✕ Cancel 則保持原樣。New Smart Object via Copy = 內容相互獨立的副本。Replace Contents…、Export Contents…、Convert to Layers、Rasterize。

✅ 智慧型濾鏡（2.422.0）

  • 對智慧型物件使用的 Filter / Adjustment 會以條目形式「新增」到圖層下方：👁 開 / 關，雙擊 = 開啟其設定，右鍵點選 = 不透明度，▲ 調整順序，✕ 刪除。
  • filter mask（濾鏡遮罩，位於 Smart Filters 行上）：點選它後進行塗抹——塗黑的地方會隱藏濾鏡效果；Shift-點選可將其關閉。

✅ Skew、Distort、Perspective、Warp（2.422.0）

  • Edit ▸ Transform: Skew / Distort / Perspective / Warp（斜切 / 扭曲 / 透視 / 變形），或在智慧型物件上按 Ctrl+T；可在選項列中切換模式。Warp：拖曳網格點或內部任意位置；預設可設定 Bend %。Enter 套用，Esc 取消。

✅ Puppet Warp 操控變形（2.422.0）

  • Edit ▸ Puppet Warp：點選放置圖釘，拖曳圖釘使畫面彎曲，Alt-點選 / Delete 刪除圖釘；Density、Show Mesh。在智慧型物件上會作為智慧型濾鏡套用。

✅ Content-Aware Scale 內容感知比例（2.422.0）

  • Edit ▸ Content-Aware Scale…（Alt+Shift+Ctrl+C）：設定寬度 / 高度 %，不重要的像素會被去除（或加倍）；Protect: the selection（保護選取範圍）；帶即時預覽。

✅ Liquify 液化（2.422.0）

  • Filter ▸ Liquify…（Shift+Ctrl+X）：W 推移，R 重建，C 旋轉扭曲（Alt 反向），S 褶皺，B 膨脹，F / D 凍結 / 解凍；用 [ ] 調整大小，壓力，Restore All。在智慧型物件上會作為智慧型濾鏡套用。

✅ Select and Mask 選擇並遮住（2.423.0）

  • Select ▸ Select and Mask…（Alt+Ctrl+R）：Quick Selection W、Refine Edge R（用於頭髮等區域）、Brush B（Alt 減去）；多種檢視；Radius / Smart Radius、Smooth、Feather、Contrast、Shift Edge；Decontaminate Colors；Output To 可選 Selection / Layer Mask / New Layer / New Layer with Layer Mask。

✅ Magnetic Lasso、Quick Selection、Sky（2.423.0）

  • Magnetic Lasso（L）：沿邊緣移動——它會自動吸附；點選設定一個點，Backspace 撤回一個點，雙擊 / Enter 閉合。Width、Contrast、Frequency。
  • Quick Selection（W）：塗抹——選取範圍會擴展到邊緣；Alt 減去；Tolerance、Auto-Enhance。Select ▸ Sky。

✅ 通道和儲存的選取範圍（2.423.0）

  • Channels 分頁：RGB / Red / Green / Blue（點選 = 檢視該通道，Ctrl+2 … 5；Ctrl-點選 = 將其明度載入為選取範圍）以及 Alpha 通道——Select ▸ Save Selection… / Load Selection…；⬚ ◫ ＋ 🗑。

✅ Patch、Content-Aware Move / Fill、Red Eye（2.423.0）

  • J：Spot Healing（Content-Aware / Proximity Match）、Healing Brush（融合：紋理取自源點，光影取自目前位置）、Patch（圈出區域，拖到乾淨的紋理上）、Content-Aware Move（拖曳選取範圍：Move / Extend）、Red Eye（點選瞳孔）。
  • Edit ▸ Content-Aware Fill… 以及 Edit ▸ Fill… 中的 Content-Aware——不使用 AI：完全根據圖片自身的內容進行填充。

✅ Mixer Brush、Background / Magic Eraser（2.423.0）

  • Mixer Brush（B）：Wet、Load、Mix，每次描邊後 Clean。Background Eraser（E）：Continuous / Once、Tolerance、Protect Foreground Color。Magic Eraser（E）：點選即清除該顏色（Tolerance、Contiguous）。

✅ PDF 檔案：開啟、編輯、儲存（2.424.0）

  • Save PDF… / Save as New PDF…（2.435.0）：儲存對話方塊中的 Embed fonts 會讓每一行以各自的字型寫入並嵌入（只嵌入用到的字元）——字型取自本機已安裝的字型或安裝目錄下的 fonts 資料夾；任何文字系統都保持為真實文字。
  • File ▸ Open PDF…（或直接拖入 .pdf 檔案）、Open PDF from Project…：顯示 Pages 頁面列；每一頁開啟後為一個不含文字的 Background 圖層 + 每行一個文字圖層（字型、字號、顏色、寬度均已匹配）。
  • 可使用所有工具進行編輯；每一頁都保留各自的圖層和復原記錄（在另一張圖片上也可以——File ▸ PDF Pages）。
  • 💾 Save PDF：在原檔案中替換已修改的頁面（儲存到專案中的副本，同時也會下載一份）；Save as New…。未修改的頁面保持向量；文字會成為真實、可選取的 PDF 文字（Helvetica / Times / Courier）；這些字型無法書寫的內容會合併到圖片中。

✅ 向量線條：曲線工具、Shape tool、Outline Pen（2.425.0）

  • F5（再按一次 = 下一個工具）：Bézier（點選 = 尖突節點，拖曳 = 平滑節點，拖曳時按 C / S，Ctrl = 15°，點選第一個節點 = 閉合，雙擊 / Enter / Space = 完成，Esc = 放棄），Freehand、2-Point Line、Polyline、3-Point Curve、B-Spline、Node Pen。從目前線條的開放端點開始繪製即可接續該線條。
  • F10 Shape tool：選取 / 拖曳節點、控制柄、線段；雙擊 = 新增 / 刪除節點；C S Y = 尖突 / 平滑 / 對稱；連線、斷開、轉為直線 / 曲線、反轉方向、閉合、提取、自動閉合、減少節點。
  • F12 Outline Pen：寬度、顏色、虛線、轉角、線端、位置、箭頭、置於填充之後、隨物件縮放。Ctrl+Q Convert to Curves。
  • Layer ▸ Vector Line: Convert to Path… / Make from Path…（Paths 面板中的 〰）：線條會變為一條記住其輪廓設定的路徑，並可原樣還原。SVG 和 PSD 都會保留它們。

✅ Curvature Pen、Rubber Band、路徑對齊 / 分佈（2.425.0）

  • Curvature Pen（P）：點選放置點——曲線會穿過這些點；雙擊某個點 = 在角點 / 平滑點之間切換；拖曳可移動；Enter 結束。Pen 的 Rubber Band 選項。Path Selection（A）：對齊 / 分佈所選元件（相對於彼此或相對於畫布）。

✅ Character 與 Paragraph 面板、段落文字、樣式（2.426.0）

  • Character（位於 Color 旁邊）：字型、字形樣式、字號、行距、字距微調、字距、垂直 / 水平縮放、基線偏移、顏色、Faux Bold / Italic、All Caps、Small Caps、Superscript / Subscript、Underline / Strikethrough。
  • Paragraph：對齊方式，兩端對齊時末行左對齊 / 居中 / 右對齊 / 全部對齊，縮排（左、右、首行），段前 / 段後間距，Hyphenate。Paragraph text：用 Type 工具（T）拖出文字方塊——文字會在框內自動換行；Layer ▸ Type: Convert to Paragraph / Point Text。
  • Character / Paragraph Styles：＋ 根據目前文字新增，點選 = 套用，⌫ Clear Override，⟲ Redefine（所有使用該樣式的文字隨之更新），🗑。

✅ Actions 與 Batch（2.427.0）

  • Actions 分頁（位於 History 旁邊，Alt+F9）：● 錄製（選單命令及其對話方塊中的設定、濾鏡、Layers 面板中的操作），■ 停止，▶ 播放；☑ 開啟 / 關閉某個步驟，▢ 在該步驟的對話方塊處暫停；▲ ▼ 🗑；雙擊 = 重新錄製某個步驟 / 修改動作的名稱和功能鍵；☰ Insert Stop、Insert Menu Item、Duplicate、Button Mode、Load / Save（.json）、Reset。
  • File ▸ Automate: Batch…：對選定的檔案或資料夾執行某個動作——結果可儲存到專案的 batch 資料夾、影像相簿、下載或保留原樣；PNG / JPEG；遇到錯誤時停止或記錄到日誌；生成一份報告。

✅ 繪圖工具（2.428.0）

  • F6（再按一次 = 下一個工具）：Rectangle（圓角半徑；圓角 / 扇形角 / 倒角）、3-Point Rectangle、Ellipse（餅形 / 弧形）、3-Point Ellipse、Polygon、Star、Complex Star、Spiral、Graph Paper、Common Shapes。Ctrl = 正方形 / 正圓，Shift = 從中心繪製。形狀一直保持可調，直到用 F10 編輯節點或按 Ctrl+Q。
  • Artistic Media（位於 F5 中）：Preset、Calligraphic、Pressure、Sprayer。
  • F8：Parallel、Horizontal / Vertical 和 Angular Dimensions、3-Point Callout、Connector（直線 / 直角 / 圓角——會跟隨所連接的物件移動）。

✅ 面板（2.429.0）

  • Window ▸ Dockers：Transform（Alt+F7：位置、旋轉、縮放與鏡像、大小、傾斜——可圍繞 9 個錨點之一，可生成副本），Shaping（焊接、修剪、相交、簡化、前減後 / 後減前、邊界），Align and Distribute（Shift+Ctrl+A），Object Properties（Alt+Enter：填充（含漸層）、輪廓、透明度）。按住 Ctrl 點選圖層可選取多個。

✅ 文件、調色盤、⊠ 透明、自動填充（2.430.0）

  • Documents：每次 New / Open 都會建立一個獨立的文件——第一個以分頁形式停靠，之後的文件在各自的視窗中浮動（Window ▸ Arrange ▸ Open Documents as Tabs 可將它們全部停靠）。將視窗拖到標籤列上即可停靠，將標籤拖離標籤列即可浮動；Ctrl+W Close，Alt+Ctrl+W Close All，Ctrl+Tab 切換到下一個文件；Tile / Cascade / Consolidate All to Tabs。
  • 右側的 Colour palette（調色盤）：對於曲線 / 形狀 / 文字，點選 = 填充，右鍵點選 = 輪廓；對於像素，點選 = 前景色，右鍵點選 = 背景色。⊠ = 無顏色 / 透明前景色（畫筆會畫出透明效果）。
  • Auto-fill：閉合的曲線或新增的形狀會用最後選取的顏色填充（曲線工具列上的 ▨ 可將其關閉）。

✅ 生成的圖片直接放到畫布上（2.431.0）

  • 編輯器開啟時，提示詞面板會生成 🖼 Image（→ ▦ canvas），它生成的每張圖片都會作為新圖層放到最前面的文件上，圖層以提示詞命名（若沒有開啟的文件，則作為新文件開啟）。關閉編輯器後，提示詞面板會恢復到之前的模式。

✅ 面板欄本身就是一個可停靠面板（2.454.0）

  • ⇱ 可讓任意標籤組浮動；按住其標題拖到面板欄上方——一條橙色線會顯示它將停靠的位置。
  • 拖曳面板欄的左邊緣可調整其寬度；順序和寬度都會被儲存。

✅ 框架：內容已鎖定，右鍵點選進行編輯（2.453.0）

  • 內容鎖定在其框架中：Move 工具及其控制柄作用於框架；內容會隨框架一起移動 / 縮放 / 旋轉。
  • 右鍵點選 ▸ Edit Frame Contents / Finish Editing Frame / Extract Contents / Lock Contents to Frame。

✅ Move 工具的控制柄（2.452.0）

  • 點選 = 縮放控制柄（Shift = 等比例，Alt = 從中心縮放）；雙擊 = 旋轉控制柄（拖曳角點進行旋轉，Shift 以 15° 為步進；拖曳邊進行傾斜）。
  • 選項列中的變換選項：角度、⟲90 ⟳90、翻轉、W % x H %。
  • 旋轉後文字仍可編輯；形狀仍保持向量。

✅ 從提示詞面板進行 Edit / Generate，Del（2.451.0）

  • ✨ AI ▸ Edit：提示詞面板切換到 🖼 Image + Qwen Image 2.1 edit，其按鈕顯示為 ✏ Edit。Generate：✨ Generate 會生成到所選圖層的選取範圍中。
  • Del 刪除目前圖層（有選取範圍時：清除選取範圍內的內容）。

✅ Warp 網格 + 分割線、Liquify 新增功能（2.450.0）

  • Warp：Grid（Default / 3 x 3 / 4 x 4 / 5 x 5 / Custom 欄 x 列）；Split Warp Crosswise / Vertically / Horizontally——點選要分割的位置；Alt-點選分割線可將其刪除。
  • Liquify：Smooth（E）、Push Left（O）。
  • Face-Aware Liquify：用 Face 工具（A）定位面部；13 個滑桿可調整眼睛、鼻子、嘴巴和臉型。

✅ 逐字元設定文字樣式（2.449.0）

  • 輸入文字時：先選取若干字元，然後使用選項列（字型、B、I、字號、字距、顏色）或 Character 面板——只有這些字元會改變。
  • 未選取任何字元 = 作用於整個圖層。在已設定樣式的一段文字中輸入，會沿用該段的樣式。所有字元共用一條基線，每行的高度取決於該行中最大的字元。
  • Layer ▸ Type: Clear Character Overrides。

✅ Content-Aware Fill 工作區（2.448.0）

  • Edit ▸ Content-Aware Fill…（需要有選取範圍）：取樣區域以綠色顯示——Auto、Rectangular 或 Custom（🖌 Sampling Brush + / −，Alt）。
  • 即時 Preview；Colour Adaptation 可選 None / Default / High / Very High。
  • Output To 可選 Current Layer / New Layer / Duplicate Layer；只佔一步復原。

✅ 畫板（2.447.0）

  • Layer ▸ New ▸ Artboard…（尺寸、背景、將所選圖層放入其中）、Artboard 工具（再按一次 V）、Artboard from Group。
  • 畫板中的圖層只在畫板內部顯示；移動畫板會帶動這些圖層；Properties：X / Y / W / H、背景、⇱ Fit。
  • File ▸ Export ▸ Artboards to Files…：每個畫板匯出一個 PNG。

✅ 網格按鈕、Grids & Guides 設定（2.445.0）

  • 頂部列上的 ⊞：開啟 / 關閉網格（Ctrl+'）。

✅ CAD 尺寸標註：精確的點、即時端點、比例（2.441.0）

  • 尺寸工具會吸附到節點、中點、角點、邊的中點、輪廓上的最近點、參考線交點（在該點處顯示名稱；Alt = 自由放置）。
  • 用 Move 工具操作尺寸標註：拖曳一端——數值即時跟隨變化；Shift = 水平，Ctrl = 豎直。
  • 屬性列上的 📏：為所選尺寸標註輸入實際尺寸 + 單位 = 作為該圖片所有尺寸標註的比例（Layer ▸ Dimension Scale…）。

✅ 標尺、參考線和吸附（2.440.0）

  • Rulers（Ctrl+R），單位為 px、mm、cm、in 或 pt（View ▸ Ruler Units）。從標尺中拖出 = 一條 guideline（參考線）；用 Move 工具（或按住 Ctrl）可移動參考線，拖回標尺上即可刪除。View ▸ Guidelines / Lock / New… / Guidelines… / Clear。
  • View ▸ Snap To：Snap（Shift+Ctrl+;）、Grid、Guidelines、Objects、Nodes、Midpoints、Intersections、Page。繪圖工具吸附的是指標，Move 工具吸附的是圖層的邊界框。Grid and Snapping… 用於設定吸附距離、網格間距、dpi。

✅ 屬性列、圓角半徑、⊕ / ⊖ 合併到形狀、線寬和線型（2.439.0）

  • 工具選項下方的 Object 欄：所選圖層的 X Y W H，🔒 保持比例。
  • 矩形：四個圓角半徑（🔗 = 同時調整全部）。向量形狀：輪廓寬度（帶預設）和線型（從圖示中選取）。
  • 形狀工具（F6）：◻ New / ⊕ Add / ⊖ Subtract / ⊗ Intersect / ⊘ Exclude——選取一個形狀時，新繪製的形狀會作為其一部分合併進來；原有形狀本身保持不變。

✅ 浮動面板組、命名面板、對話方塊居中顯示（2.438.0）

  • Layers / Colour 組標籤上的 ⇱ 可讓該組在編輯器內浮動——拖曳標題可移動它，拖曳任意邊緣可調整大小，⇲ 將其放回原處。
  • Window ▸ New Docker…：建立一個空的命名面板——將浮動組拖到上面即可作為分頁停靠；⚙：設為主面板或限制在某個面板內、重新命名、刪除。儲存在 panel_layout.cfg 中。
  • 對話方塊會在螢幕中央開啟，或在你上次移動到的位置開啟（dialog_layout.cfg）。Shift+Del 刪除所選圖層。

✅ ✨ Generate Fill in Shape / in Mask、圖案庫（2.437.0）

  • Layer ▸ ✨ Generate Fill in Shape…（也可右鍵點選圖層，或在 Properties 中使用）：在圖層的輪廓內生成內容；✔ Apply 將結果放到一個剪下到該形狀的新圖層上（形狀仍保持可編輯）。✨ Generate Fill in Mask…：在圖層的遮罩範圍內生成，結果附帶一份該遮罩的副本。
  • Edit ▸ Define Pattern… / Pattern Library…：安裝資料夾中的 patterns/<name>.png——New Fill Layer ▸ Pattern…（在 Properties 中設定縮放、偏移）、Edit ▸ Fill ▸ Pattern、Pattern Overlay（user:<name>）。.bgi 檔案會攜帶其使用的圖案。

✅ 專案檔案：.bgi（2.436.0）

  • File ▸ Save Project (.bgi) Alt+Ctrl+S / Save Project As (.bgi)…：原樣儲存文件——圖層、組、遮罩、文字 / 形狀 / 填充 / 調整圖層、樣式、包含其內容和智慧型濾鏡的智慧型物件、路徑、通道、選取範圍、圖層複合——儲存在專案的 bgi 資料夾中（需要時還會下載一份）。
  • Open Project (.bgi)…、Open Project from Project…、Open…（Ctrl+O）或將 .bgi 拖放到編輯器上：作為新文件開啟，所有內容均可編輯，歷史記錄重新開始。
  • 它是一個 zip 檔案：doc.xml（XML 格式的文件）+ preview.png + 每個圖層 / 遮罩各一個 PNG。

✅ Gradient Editor、Layer Comps、智慧型濾鏡混合模式（2.434.0）

  • Gradient Editor（Edit ▸ Gradient Editor…、Gradient 工具的漸層按鈕、填充圖層或形狀的漸層）：預設 + 你自己的漸層，在漸層條下方點選 = 新增色標，拖曳 = 移動，向下拖出 = 刪除；每個色標的顏色（或前景色 / 背景色）、不透明度、位置；Reverse、Distribute。
  • Layer Comps（Window ▸ Layer Comps）：儲存圖層的可見性 / 位置 / 外觀，並在它們之間切換（▶、◀ ▶），↻ 更新，Last Document State。
  • Smart filter Blending Options（右鍵點選智慧型濾鏡）：混合模式 + 不透明度。
