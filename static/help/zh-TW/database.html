🗄 資料庫

用於一個專案、所有專案或你自己伺服器上的 MySQL / MariaDB 資料庫——根據你的描述，由 AI 設計表、欄位和檢視。頂部欄的 🗄 按鈕可開啟和關閉此停靠欄。

存放位置

  • 📁 此專案——bitGen 為專案執行自己的 MariaDB 伺服器，資料位於專案的 db 資料夾中，隨專案一起移動。
  • 🌐 全域——所有專案共用一個 MariaDB 伺服器，資料位於應用的 db 資料夾中。
  • 🖧 你的伺服器——任何 MySQL 或 MariaDB 伺服器（⚙ 你的伺服器…：主機、埠、使用者、密碼、資料庫）。密碼在本機加密儲存。

bitGen 自己的伺服器只在本機（127.0.0.1）監聽，需要時自動啟動（也可手動 ▶ / ⏹），bitGen 關閉時停止。首次需要 MariaDB 本身：本機沒有時會彈出下載 / 取消框（MariaDB，GPL-2.0，來自 archive.mariadb.org，放入應用的 mariadb 資料夾）。在 Mac 上請用 Homebrew 安裝（brew install mariadb）——bitGen 會找到它。

✨ 設計——由 AI 建表

  • 描述用途：“一家小店：客戶、有庫存的商品、帶明細的訂單，以及按月銷售額和最佳客戶的檢視”。
  • ✨ 設計表：提示詞停靠欄的 LLM 編寫 SQL——帶欄位和類型的表、鍵、表之間的關聯、索引和檢視。它能看到已有的表，所以之後可以繼續要求（“新增供應商”）。
  • 先顯示 SQL。閱讀、按需修改，然後 ▶ 執行。逐條執行，遇到第一個錯誤即停止。設計永遠不會刪除表或資料。
  • 也可以在提示詞停靠欄說：“為我的店建立一個包含客戶和訂單的資料庫”——停靠欄會開啟並帶有設計。

表、資料和 SQL

  • 左側：表（▦）和檢視（👁）及其欄位——🔑 主鍵，🔗 關聯到其他表。
  • 點選一個即可檢視 📋 資料——前 200 行。
  • ⌨ SQL 執行你輸入的任何 SQL（多條語句，每條以 ; 結尾）並顯示結果。
  • ＋ 新建建立資料庫，🗑 刪除目前顯示的資料庫（會先詢問）。
