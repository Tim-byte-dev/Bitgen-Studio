▦ 試算表

在 bitGen 中處理表格、求和與清單——一個由多張工作表組成的工作簿,公式會在你輸入時自動重新計算。頂部欄的 ▦ 按鈕用於開啟和關閉停靠窗。 工作簿儲存在專案的 sheets 資料夾中(.bgs 檔案);正在輸入的內容也會儲存在瀏覽器中,所以關閉停靠窗不會丟失任何內容。

輸入

  • 點選儲存格並輸入。Enter 確認並向下移動,Tab 向右移動,Esc 復原輸入。F2 或雙擊可修改儲存格中的內容。
  • 方向鍵移動;Shift + 方向鍵(或拖曳)選擇區域;Ctrl + 方向鍵跳到資料末端;Home 回到 A 列,Page Up / Down 移動 20 行;Ctrl+A 全選;Delete 清空所選儲存格。
  • 數字按你輸入的方式被識別:$1.50 是 1.5,顯示為貨幣;25% 是 0.25,顯示為百分比;17/11/2026(日在前)或 2026-11-17 是日期。
  • 網格上方的 ƒx 欄顯示儲存格中真正的內容(公式,而不是結果)——也可以在那裡輸入。

公式

  • 以 = 開頭:=B2*C2、=SUM(D2:D20)、=IF(D2>100,"big","small")。+ - * / ^,& 連線文字,= <> < > <= >= 用於比較。
  • 輸入公式時點選儲存格(或拖過一個區域)即可插入其地址。
  • 複製或填充公式時,$A$1 保持引用不變;A1 會隨之移動。
  • 其他工作表:=Sheet2!A1 或 ='My costs'!B4。整列和整行:=SUM(B:B)、=SUM(3:3)。
  • ƒ▾ 列出函式:求和與計數(SUM、AVERAGE、MEDIAN、MIN、MAX、COUNT、COUNTA、COUNTBLANK、SUMIF(S)、COUNTIF(S)、AVERAGEIF)、數學(ROUND、ROUNDUP、ROUNDDOWN、INT、ABS、SQRT、POWER、MOD、PRODUCT)、邏輯(IF、IFS、IFERROR、AND、OR、NOT)、文字(LEN、TRIM、UPPER、LOWER、LEFT、RIGHT、MID、CONCAT、TEXT、VALUE)、日期(TODAY、NOW、DATE、YEAR、MONTH、DAY)和查詢(VLOOKUP、XLOOKUP、INDEX、MATCH)。
  • 錯誤會顯示在儲存格中:#DIV/0!(除以 0)、#REF!(已刪除的儲存格)、#NAME?(不認識的函式)、#CYCLE!(需要自身結果的公式)。

填充、複製、移動

  • 所選儲存格角上的小方塊是填充柄:向下或橫向拖曳即可複製——公式會移動其引用,兩個及以上相連的數字或日期會延續序列(1、2 → 3、4、5)。
  • Ctrl+C / Ctrl+X / Ctrl+V 複製、剪下和貼上——在表內,公式隨貼上位置移動;從其他程式複製的表格(以製表符分隔的文字)會貼上到儲存格中。
  • Ctrl+Z / Ctrl+Y 復原和重做。
  • 右鍵點選儲存格可插入 / 刪除行和列——所有公式都會跟隨它們所指向的儲存格。拖曳列字母或行號的邊緣可調整大小。

外觀 - ▤ 設定儲存格格式 (Ctrl+1)

  • 工具列的 ▤ 格式…、Ctrl+1 或右鍵點選儲存格可開啟 設定儲存格格式。在這裡更改的專案會應用到所有所選儲存格(各儲存格的其他格式保持不變);按一次 Ctrl+Z 即可復原。
  • 數字:常規、數值(小數位數、千位分隔符、負數的顯示方式 - 負號、紅色、括號)、貨幣($、A$、€、£、¥、฿ …)、會計專用(符號在儲存格邊緣、小數點對齊、零顯示為短橫線)、日期、時間、百分比、分數、科學記數、文字(按輸入原樣顯示 - 0012 保留前導零)、特殊(郵編、ABN、電話號碼)以及 自訂 - 輸入任意格式程式碼:0 # ? 數字位、, 千位分隔、%、d m y h s 和 AM/PM、[h] 超過 24 的小時數、[Red] 顏色、"文字",以及最多四節 正數;負數;零;文字 或 [>=1000] 之類的條件。範例會在你選擇時顯示活動儲存格。
  • 對齊:左 / 置中 / 右(帶縮排)、填充、兩端對齊、跨列置中(不合併即可讓標題跨多列)、分散對齊;靠上 / 置中 / 靠下;自動換行(行會變高以容納內容)、縮小字型填充、合併儲存格、文字方向,以及 方向 - 拖曳刻度盤或輸入角度(-90 到 90),或讓文字豎排。
  • 字型:字型(包括此電腦上的字型)、常規 / 傾斜 / 加粗、字號(字號變大時行會變高)、下劃線(單、雙、會計用)、顏色、刪除線、上標、下標。
  • 邊框:選擇線條(13 種樣式)和顏色,然後點預置(無、外邊框、內部)、邊框按鈕,或點選預覽中的邊 - 對角線也可以。再點一次即可去掉。
  • 填充:調色盤中的顏色(或任意顏色)、雙色漸層(橫向、縱向、斜向、從中心)或帶顏色的圖案。
  • 保護:鎖定 和 隱藏 在工作表受保護後才生效 - 勾選 按確定時保護此工作表,或右鍵點選工作表標籤 ▸ 🔒 保護工作表。之後鎖定的儲存格不能更改(所有儲存格預設鎖定 - 對需要他人填寫的儲存格取消鎖定),隱藏儲存格的公式不會顯示;🔓 復原工作表保護 可解除。
  • 工具列上有常用項:數字格式 清單、.0← / .00→ 減少 / 增加一位小數、B I U、文字和填充顏色(⊘ = 無填充)、左 / 置中 / 右、自動換行、邊框 ▾ 和 ⊞ 合併。數字太寬放不下時顯示 ##### - 請加寬該列。

Excel 檔案、圖表和 ✨ 儀表板

  • ⤒ 匯入 可開啟 Excel 工作簿 (.xlsx) 或 CSV 檔案:所有工作表、值、公式、數字格式、字型、填充、邊框、合併儲存格、列寬和凍結窗格。使用 bitGen 尚不支援的函式的公式會顯示檔案儲存時的結果。⤓ 匯出 ▾ 可將工作簿儲存為 .xlsx(下載,並儲存在專案的 sheets 資料夾中),或將此工作表儲存為 CSV。
  • 📊 圖表 ▾ 為所選儲存格建立圖表(柱形、條形、折線、面積、餅圖、圓環、散點)——第一行為系列名稱,第一列為類別。拖曳可移動,拖曳角可調整大小,雙擊可更改標題、類型或資料,Delete 刪除。圖表會隨上方插入的行移動,並儲存在工作簿中(.xlsx 中儲存的是資料,而不是圖表)。
  • ✨ 儀表板——LLM(提示詞停靠窗的)檢視資料的列——名稱、值的類型、幾個範例和合計,而不是每一行——並規劃一個儀表板;也可以輸入你想看的內容(如"按地區和月份的銷售額")。bitGen 會在新的第一張工作表上搭建它:磁貼中的關鍵數字、帶表格和圖表的細分、隨時間的趨勢——全部是即時公式,會隨資料更新——並把資料格式化為表格(標題、隔行底紋、數字格式、列寬、篩選、標題凍結)。選擇 Excel 或 CSV 檔案 可從檔案開始。取消勾選 使用 LLM(或 LLM 沒有回應時),會根據資料本身的形態來規劃。按一次 Ctrl+Z 即可全部復原。

✨ 儲存格中的 AI

  • ✨ AI ▾ ▸ ✍ 編寫公式…——說出要計算什麼(如"Region 為 North 的 Amount 合計")。LLM(提示詞停靠窗的)會得到表格的列——標題、值的類型、幾個值——而不是每一行,並以公式作答。bitGen 在填入前先計算:你能看到結果,可以修改,然後按 填入。針對單行的公式會提供 向下填充表格各行。
  • 💡 解釋此公式(儲存格的右鍵選單中也有)——公式讀取的每個儲存格和範圍及其目前內容,然後是 LLM 的通俗解釋。
  • 🪄 按範例填充(Ctrl+E)——在新列的一兩個儲存格中輸入應有的內容,然後按 Ctrl+E:bitGen 會盡量自己找出規則(其他儲存格中的詞、@ , - 等符號之前 / 之後的部分、拼接、大寫 / 小寫 / 首字母大寫、首字母縮寫)並填充空行——無需 LLM。沒有這類規則適用時(求和、查詢…),由 LLM 編寫公式,只有當它能得出每一個範例時才使用;都不行時,由 LLM 填入值並說明這是它的推測。按一次 Ctrl+Z 即可復原填充。
  • ƒ▾ 中的新函式:PROPER、FIND、SEARCH、SUBSTITUTE、REPLACE、REPT、EXACT、TEXTJOIN、AVERAGEIFS、MAXIFS、MINIFS、SUMPRODUCT、LARGE、SMALL、RANK、ROWS、COLUMNS、CEILING、FLOOR、WEEKDAY、HOUR、MINUTE、EDATE、EOMONTH、DATEDIF、CHOOSE、IFNA、ISERROR、ISNA、ISBLANK、ISNUMBER、ISTEXT、SWITCH。

📌 常量——重複出現的金額

  • 📌 常量 記錄一次又一次收入或支出的金額——房租、工資、話費、貸款:類型(名稱)、金額、週期(天、周、兩週、月、季度、年)、開始日期、描述、支出(付款) 或 收入(收款),如會停止則填 結束 日期。
  • 金額變化時,用同一名稱新增新金額及其開始日期(點選清單中的常量即可填入表單)。之前的日期保留原金額——每週 540 的房租持續一年後變為 580,會得到 52 筆 540,以及從新日期開始的 580。清單顯示今天的金額;點選可看到它所有的金額。
  • ⟳ 更新到最新 計算到所選日期為止的每一筆應記錄,並先顯示將要做的事:新記錄、金額已變化的記錄(往前追加的金額——勾選後更正)以及不再由任何常量產生的記錄(僅在勾選時刪除)。✔ 應用 會按日期順序寫入帳本——日期、說明、類別、收入或支出、餘額和 Ref(📌 Rent · 2026-01-13),因此不會重複記錄。按一次 Ctrl+Z 即可復原。
  • 帳本是帶有 Date 和 Income / Expense(或 Amount)標題的工作表——你自己的,或 ＋ 建立帳本工作表。你自己輸入的行會保留,並與其他行一起按日期排序。
  • 公式可以讀取它們:=Rent 是今天的金額,=CONST("Rent", A5) 是某一天的金額(名稱中有空格:=Car_loan)。它們隨工作簿一起儲存。
  • Paid to——為常量支付的金額從第一個開始日期起逐日抵扣,一天的金額 = 每週金額 ÷ 7(兩週 ÷ 14,每月 × 12 ÷ 365,每年 ÷ 365)。清單顯示 已付到 24/01/2026 · 落後 3 天 · 欠 $157.14(或提前的天數),帳本的 Paid to 列在常量的每一行顯示到該行為止的付款付到哪一天——即時公式 =PAIDTO("Rent", 已付金額)。付款按 Category(常量名稱)或 Ref 識別。由你自己記入付款的(如租客的房租)取消勾選 ⟳ 自動記入——這時 ⟳ 只填寫 Paid to。
  • 匯出 ▸ Excel 會加入一個 Constants 工作表——每個金額一行：Type、Income / Expense、Amount、Every、From、To、Description、Entered by ⟳——以及帳本的名稱。在這裡再次開啟該檔案即可恢復常量。

從提示詞停靠窗

  • 提示詞停靠窗的 ＋(或拖放)也接受 Excel 或 CSV 檔案:它會在試算表中開啟,然後說出要做什麼。
  • 在提示詞中說:create a dashboard(按地區的銷售額)——✨ 儀表板;format it——格式化表格;received a payment of 540 for rent / paid 80 for power yesterday——帳本記錄(received = 收入,paid 或 payment = 支出;所說的日期或今天;提到的常量或類別即其 Category),會先顯示供你修改,然後 ✔ 新增 按日期順序記入帳本(按一次 Ctrl+Z 即可復原);rent went up to 580 from 12/01/2027——在 📌 常量中填好新金額;bring the ledger up to date;explain this formula;fill the rest from the examples;a formula for the total of column D。
  • 當試算表在螢幕上、剛附加了工作簿、訊息提到試算表 / 工作表 / 帳本,或(付款)工作簿有帳本時,訊息會交給試算表。其他的都是普通聊天。

表格

  • A→Z / Z→A 按活動儲存格所在的列對其周圍的表格排序。第一行標題保持在頂部,同一行的儲存格(包括其公式)保持在一起,空儲存格排在最後。若已選擇區域,則只對該區域排序。
  • ⏷ 篩選在每個標題上加一個 ▾——勾選要顯示的值;其餘的行會被隱藏(不會被刪除)。再按一次顯示所有行。
  • ❄ 凍結在滾動時保持活動儲存格上方的行和左側的列可見。
  • Σ 對活動儲存格上方(或左側)的數字求和。
