📏 Sketcher

用最快捷的方式進行 3D 建模：在地面或某個面上畫一個形狀，然後把它推或拉成實體。尺寸可以隨時輸入到 Measurements（測量）框（右下角）——無需點選該框，直接輸入並按 Enter 即可。

工具（字母即快捷鍵，指標需位於面板上方）

  • 雙擊空白處（沒有進行中的操作時）——取消所有選擇，工具切換為 🔄 Orbit（環繞）；按 Space 返回 Select。
  • Space ➤ Select（指標）——已選取的物件以強調色著色，指標下方的物件顯示為藍色（2.650.0——平面圖中同樣如此）；點選只選取一個物件（一個面、一條線、一個房間、一扇門、一件家具……）；Ctrl+點選可新增更多物件（Ctrl+點選已選取的部分則將其移出選擇）——拖曳其中任意一個，它們會一起移動，按 Delete 則全部刪除；Shift+點選可新增/移出面和線，Ctrl+A 全選。點選組中的一個面會選取整個組；雙擊組可進入組內編輯（其餘部分變暗），按 Esc 離開。按 Delete 刪除所選內容。
  • 用 Select 編輯（2.625.0）：
    • 面：面板顯示 Extrude（擠出；+ 為向外，− 為向內 = 在物體上切割）和 Twist（扭轉）。拖曳該面即可用指標擠出它，與 Blender 類似；Ctrl+拖曳使其繞法線旋轉——剛擠出的面會相應扭轉其擠出部分。輸入距離（Measurements）可修改上一次擠出。
    • 邊：拖曳即可移動（Shift：沿單一軸向）。Shift+點選可選擇更多邊；Ctrl+點選可選擇其所在面一圈的所有邊（邊環）。面板：Length（長度）、Extrude edge（擠出邊；由它生成一個新面——向上、從其所在面向外、沿紅軸或綠軸）和 Fillet（圓角；半徑和分段數——將兩個面之間的邊倒圓）。
    • 角點（頂點）：點選並拖曳（Shift：沿單一軸向；會吸附到另一個角點上），或輸入其 X / Y / Z 座標。被彎折而不再平整的面會被拆分為三角形。
  • L ╱ Line（直線）——點選、點選……閉合的平面環會成為一個面。從面的一條邊界畫到另一條邊界的直線會將該面分割為兩半（然後可推/拉其中一半）。
  • R ▭ Rectangle（矩形）——兩個對角點。在某個面上開始繪製時，矩形位於該面內。輸入 3,2 表示 3 m × 2 m。
  • C ◯ Circle（圓）/ N ⬠ Polygon（多邊形）——先定圓心，再定半徑。可輸入半徑，或輸入 36s 表示 36 條邊。
  • P ⇧ Push/Pull（推/拉）——點選一個面，移動，再點選（或直接拖曳）。可輸入距離。單獨的面會變成實體；拉動盒子頂面會讓盒子變高；在面上畫出的形狀可向內推成凹槽，或向外拉成凸臺；把凹槽底面推到另一側即可形成通孔。推/拉剛結束時，輸入新的距離即可修改。雙擊一個面 = 再次使用上一次的距離。
  • M ✥ Move（移動）——選取物件（或在其上按下），點選一個基點，再點選目標位置。按住 Ctrl = 複製。可輸入距離，或輸入 x,y,z。
  • Q ⟳ Rotate（旋轉）——先選取，然後依次點選中心、起點和終點（繞豎直軸，步長 15°）。可輸入角度。
  • S ⤡ Scale（縮放）——選取後點選一個點，然後遠離/靠近中心移動。可輸入縮放係數。
  • F ⧈ Offset（偏移）——點選一個面並在面內移動：得到一個向內偏移相應距離的環。偏移地板後把這個環向上拉 = 牆。
  • T 📏 Tape（捲尺）——兩個點：顯示它們之間的距離（以及在各軸向上的距離）。
  • B 🪣 Paint（油漆桶）——點選面進行上色（若為組：整個組）。Alt+點選可吸取某個面的顏色。顏色位於底部。
  • E ⌫ Eraser（橡皮擦）——點選或拖過線和面。刪除與面相鄰的線時，這些面會一併刪除。
  • O 🔄 Orbit（環繞；指標為環繞游標）、H ✋ Pan（平移）——在任何工具下，中鍵環繞，右鍵平移，滾輪縮放（朝向指標位置）。Shift+Z = 全部顯示。

建築——房間、牆、門、窗、屋頂、燈光

建模工具下方的 Build（建築）工具用於繪製始終可編輯的建築：房間保留各自的牆、地板和天花板，房間移動時，門、窗和燈光會保持在房間中的原有位置。

  • U ⌂ Room（房間）——兩個對角點（或輸入 4,3——寬度、長度）：生成牆、地板和天花板。設定面板中的 Width（寬度）和 Length（長度）後，點選一次即可放置該尺寸的房間（0 = 用兩個角點繪製）。選取房間的面板中同樣有 Width 和 Length。房間角點會吸附到其他房間的角點和牆的中點。右側面板用於設定下一個房間的牆高、牆厚、地板標高和天花板，以及 Offset from floor edge（距地板邊緣的偏移）：沿地板（J）邊緣繪製的房間或牆，其牆外側面會從邊緣內縮該距離（0 = 正好在邊緣上）。
  • W ▮ Wall（牆）——點選、點選……繪製獨立牆體。再次點選起點即可閉合成一個房間。雙擊或按 Esc 結束。可輸入下一段的長度。
  • D 🚪 Door（門）——在牆上點選：單開門、雙開門、玻璃推拉門、玻璃門或無門洞口。門的中點會吸附到牆的中點。輸入 0.9,2.1 設定寬度和高度。
  • I 🪟 Window（窗）——在牆上點選：單扇、雙扇或推拉窗，並設定 Elevation (height from floor)（離地高度）。輸入 1.2,1.2。
  • J ▦ Floor（地板）——兩個角點：一塊沒有牆的地板（木平臺、庭院、某一樓層的樓板），高度和厚度按面板中的設定。
  • K ⌓ Ceiling（天花板）——點選一個房間：開啟或關閉其天花板。房間面板中有 Ceiling：None、Flat（平頂，高度取牆頂的最低處）或 Follows the walls' slope（隨牆坡度，在雙坡山牆或單坡頂下向上傾斜）。
  • Y △ Roof（屋頂）——點選一個房間：為其加蓋屋頂（雙坡、四坡、單坡、平頂或 Follows the walls' slope——屋頂坐落在牆的傾斜頂部上；坡度和挑簷，或 Eaves width（簷口寬度），在面板中設定）。Shift+點選更多房間可將它們置於同一屋頂下，或使用 Roof the whole storey（為整層加蓋屋頂）。可輸入以度為單位的坡度。
  • X 💡 Light（燈光）——在面板中選擇類型：downlight（嵌入式筒燈）、ceiling-mounted（吸頂燈）、pendant（吊燈）、chandelier（枝形吊燈）、spot（射燈）、wall light（壁燈）、floor lamp（落地燈）、table lamp（檯燈）；以及顏色（暖白到冷白）和以流明為單位的亮度。點選會將燈放在指標下方房間的天花板上（會吸附到房間中心）；壁燈則安裝在指標所指的牆上。
  • Photo style（照片風格，2.696.0）——✨ Photo 左側的下拉式清單：Sketcher 生成照片時使用的影像編輯風格（獨立設定——提示詞面板保持其自身的風格）；會保留上次使用的選項。
  • 屋面材料（2.695.0）——屋頂的 Covering（屋面）：預塗彩鋼板（波紋板、肋形板、直立鎖邊板）、混凝土/陶土瓦、石板瓦、瀝青瓦或聚碳酸酯板——在屋頂上顯示其顏色和紋理；坡度低於其常規最小值時顯示 ⚠（請以廠商資料為準）；其重量計入框架校核。
  • 🪵 Roof framing（屋頂框架，2.694.0）——選取屋頂 ▸ Roof framing：Rafters（椽子：截面尺寸、等級、間距、下檁條規則、天花擱柵及其支撐間隔；✔ / ✗ + ✔ Size them）或 Trusses（桁架：按間距佈置）。用 🪵 Show framing（顯示框架）繪製（屋頂變為透視顯示）。
  • 🪵 Wall framing（牆體框架，2.693.0）——選取房間 ▸ Wall framing：Timber（木材）或 Light-gauge steel（輕鋼），立柱尺寸/等級/間距、頂梁板、橫撐排數、拉帶斜撐、Frame this room's walls。立柱、梁板、門窗邊立柱 + 短立柱、窗臺橫梁、橫撐和角柱用 🪵 Show framing 繪製；房間的合計數量顯示在面板中。立柱尺寸不做校核（AS 1684 的立柱表）。
  • 🏗 Floor systems + 🪵 lintels（樓地面系統 + 過梁，2.692.0）——選取一個房間：Floor system = 地基板、華夫格模殼板、加勁筏板、墩柱支撐懸空樓板或架空木地板（短樁、托梁、擱柵——尺寸、等級、間距；✔ / ✗ 校核，✔ Size them）。外牆上的門/窗：其 Lintel（過梁；Auto 或手動選擇）。🪵 Show framing = 牆體透視顯示。僅供參考——請核對 AS 1684 / 跨度表；樓板須由你的結構工程師負責（AS 2870）。
  • ⊣ Walls butt up（牆體對接，2.691.0）——新牆的端部會止於它所碰到的牆：端對端相接時，舊牆的端部會被修整以繞過轉角（形成一個乾淨的轉角）；落在某面牆的軸線上時（橫穿房間的牆），新牆會被截到該牆的牆面處。Wall thickness（牆厚）會記住你上次設定的值（在工具、選取的牆或房間中設定）；大於 2 = 毫米（200 = 0.2 m）。
  • ⊕ Joined walls（相連的牆，2.690.0）——使用 ▮ Wall 時，靠近另一面牆端部/轉角的點會被吸附到其上（提示顯示 ⊕ joined；按住 Shift = 自由放置）。在此相連的牆會保持相連：拖曳其中一面，另一面的端部會跟隨——牆隨之伸長或縮短。
  • 🗄 Cupboards & shelving（櫥櫃與擱架，2.689.0）——🛋 Furniture ▸ Category Cupboards & shelving：嵌入式衣櫃、步入式衣帽間（L 形/U 形）、布草櫃/食品儲藏櫃/雜物櫃、書架、擱架。🗄 Design / change… 開啟其對話方塊（佈局、尺寸、分格——掛衣、雙層掛衣、層板、抽屜、鞋架——、櫃門、拉手、顏色；即時正檢視 + 平面圖）；💾 Save as template 將你的設計儲存下來，供所有專案使用（在清單中標為 ★）。在房間內點選 = 櫃體背面靠向最近的牆，正面朝內；選取後：✎ Design…、↔ Fit the wall。
  • A 🛋 Furniture（家具，2.628.0）——家具庫：選擇 Category（類別：Living、Dining、Kitchen、Bedroom、Bathroom、Lights、Outside）和一件家具，在地板上點選即可放置（它會立在房間地板上）。R 將下一件旋轉 90°，也可輸入角度。使用 Select 時：可拖曳它，按 R 旋轉；其面板包含尺寸、轉角、離地高度、顏色、⧉ Duplicate 和 🗑 Delete。3D models 類別列出專案中的 3D 模型（.glb / .obj——SolidCraft 生成的或匯入的）：點選一次即可將其作為組匯入。
  • Z 📷 Camera（攝影機，2.629.0）——點選攝影機所在位置，再點選它的朝向（視點高度和鏡頭在面板中設定）。選取後：👁 Look through（透過攝影機觀察）、📷 Shot + depth + normal（三張圖片存入專案的 Image 素材，其中拍攝圖帶照片效果）和 📍 360° location（從該處生成的全景圖成為一個 Location——帶有其 @tag，即提示詞中的地點）。Select 可拖曳它；其面板可設定轉向、俯仰和名稱。
  • V ▟ Stairs（樓梯）——點選樓梯底部，然後確定方向和長度（或直接輸入）。高度和寬度在面板中設定。

材質（2.629.0）：顏色旁的 ▦ Materials ▾ 中有各種材質——磚、石材、混凝土、橡木和胡桃木地板、瓷磚、大理石、地毯、草地……均帶紋理。選擇一種後，用它為面、牆和地板上色（B）。房間面板中的 🪄 Furnish（佈置家具）會為房間擺滿家具（若有 LLM 在執行，則由 LLM 從家具庫中挑選，否則使用該類房間的常規家具組合；輸入 "a reading corner" 之類的描述會有幫助）；Ctrl+Z 可復原。

房間共用牆。使用 Select 時，在一個房間上按下並拖曳：當它的某面牆靠近另一房間的牆時，會吸附上去，兩個房間之間便只有一面牆。這面牆上的門或窗會貫穿整面牆。角點也會對齊。按住 Shift 可保持直線拖曳。

地板上的牆。使用 Select 時，在房間的某一面牆上按下並拖曳：牆會沿垂直於自身的方向移動，房間隨之拉伸。拖曳過程中，地板邊緣的吸附區域以橙色顯示；在其中鬆開，牆的外側面就會落在邊緣上（並計入 Offset from floor edge）。拖曳的房間也會以同樣方式吸附到地板邊緣。Shift = 不吸附。

斜牆。雙擊牆的頂部 = 在該處新增一個斷點。上下拖曳斷點：牆頂會從兩端角點向它傾斜（形成山牆端）。點選一條頂邊（位於斷點或角點之間）並拖曳——或在面板中輸入其兩端的高度——即可使牆傾斜；移動一個角點時，相鄰的牆會隨之一起變化。選取斷點或邊後按 Delete 即可將其刪除（牆恢復為水平/平直）。從正上方（Top 檢視）按下則改為移動該牆。

手動調整門窗。點選已放置的門或窗：其兩側、頂部和底部（門除外）會顯示小方塊（夾點）。拖曳側邊夾點調整寬度，拖曳頂部夾點調整高度，拖曳底部夾點調整離地高度。也可將窗戶本身沿牆拖曳或上下拖曳。

開啟門窗（2.631.0）：選取的門或窗有 Open (%)（開啟百分比）——門扇向室內轉動（勾選 Opens outward 則向外開），窗扇向外推開（勾選 Opens inward 則向內開），推拉窗則滑動一扇玻璃（The other pane slides 改為另一扇滑動）。Auto roof 和 Auto floor（Room 工具的面板中）會為每個新房間自動加上屋頂，以及牆下方一塊 20 cm 的樓板；房間面板中有 Floor slab under the walls 和 Roof，可為該房間單獨開關。View ▾ 列出所有攝影機（📷）——選擇一個即可從該攝影機視角檢視（環繞即可離開）。

攝影機（2.632.0）繪製在所有物件之上，因此房間內的攝影機可直接點選選取（而不會選取房間）。拖曳即可移動；R 將其旋轉 15°（Shift+R 反向旋轉）。按 Esc 或雙擊空白處可取消所有選擇——Esc 同時會離開目前工具，切換到 🔄 Orbit（2.647.0）。

🗂 Outline（大綱，2.639.0，工具列上的 🗂 Outline 可顯示/隱藏它，位於檢視左側）：建築中的每個物件——Room groups（房間組）、Rooms ▸ Room 1 ▸ Wall 1 … Wall n、Floor 1、Ceiling 1、Skirting 1、Cornice 1、Floor slab 1、Door 1、Window 1 ……，然後是獨立的 Walls、Roofs、Floors、Stairs、Lights、Furniture 和 Cameras。點選某一行即可選取；👁 隱藏/顯示該物件（Ctrl+Z 可復原，狀態隨模型一起儲存）。＋ 新增房間組，房間上的 ⊞ 將其放入（或移出）組，組的 👁 隱藏/顯示其所有房間，✎ 重新命名，✕ 刪除該組（其中的房間保留）。新房間內建踢腳線和頂角線（房間面板：Skirting / 高度、Cornice / 尺寸，以及它們的顏色）。拖曳牆：牆沿垂直於自身軸線的方向移動——相鄰的牆隨之拉長或縮短，地板、天花板、踢腳線和頂角線也會跟隨；Alt+拖曳可自由移動；Shift+點選選取整個房間（隨後拖曳即可移動房間）。

各部件的獨立面板（2.640.0）：點選牆、地板、天花板、踢腳線或頂角線（在檢視中或其 🗂 Outline 行中），面板就只顯示該部件——牆：Length（長度；矩形房間會保持其形狀）、Height（高度，僅此牆）、Thickness（厚度）、其獨立的 Inside 顏色、👁；地板：On、Colour、Level、樓板；天花板：None / Flat / Follows the walls、Colour、Height；踢腳線 / 頂角線：On、Profile、Height / Size、Colour。⌂ 返回房間設定；對部件按 Delete 會將其關閉（牆被隱藏）——房間保留。

輪廓（2.640.0）：踢腳線、頂角線、門框、窗框和窗臺都從一個圖片下拉式清單中選取輪廓（每項以其截面圖顯示）：先是內建輪廓，然後是專案自有的輪廓。踢腳線沿房間四周佈置，轉角處斜接，並在門框處斷開；門框（門套線）環繞門的兩面，窗框環繞窗的室內一側，窗臺位於窗下。✎ Profiles… 用於繪製你自己的輪廓：點選 = 在最近的邊上新增一個點，拖曳 = 移動該點，Delete / 右鍵點選 = 刪除該點（1 mm 網格，Shift = 自由），Width / Height 可縮放輪廓，＋ New 複製目前顯示的輪廓，💾 Save 將其儲存在專案中。

旋轉環（2.633.0）：選取的攝影機或家具會顯示三個環——藍色環使其轉向（偏航），紅色環使其俯仰，綠色環使其翻滾。沿環拖曳即可按 5° 步長旋轉（按住 Shift 可自由旋轉）；Ctrl+Z 可復原。也可在面板中輸入相應數值：攝影機的 Turn (yaw)、Tilt (pitch) 和 Roll；家具的 Turn (yaw)、Pitch 和 Roll。攝影機的 Lens（鏡頭）可選擇預設——Fisheye (8 mm)、Ultra wide (14 mm)、Wide angle (24 mm)、35 mm、50 mm (normal)、85 mm (portrait)、135 mm、200 mm (telephoto)——或輸入 Focal length（焦距，mm，全畫幅）或 Field of view（視野，°）：兩者相互聯動。魚眼提供最寬的視野，但不會繪製魚眼畸變曲線本身。Zoom extents（縮放至全部）也會把攝影機納入視野。

選取攝影機（2.641.0）：點選攝影機即可選取——它會醒目顯示（周圍沒有選框）並顯示移動箭頭（紅色 X、綠色 Y、藍色 Z）。拖曳攝影機可在其目前高度上移動，拖曳某個箭頭則只沿該軸移動（藍色 = 上/下；步長 1 cm，Shift = 自由）。雙擊攝影機顯示旋轉環（轉向/俯仰/翻滾），再次雙擊切換回箭頭（或使用其面板中的 ✥ Move / ⟳ Rotate）。點選任何其他物件則改為選取該物件。透過攝影機觀察（2.643.0，👁 Look through）：其面板中的 ✥ Move / ⟳ Rotate 會在你面前顯示控制項——拖曳它，攝影機和檢視會一起移動或旋轉。Esc 取消選擇攝影機。

可將門或窗沿其所在牆拖曳（或拖到另一面牆上）；也可拖曳燈、樓梯或地板。點選任何建築構件，面板就會顯示其設定——房間的尺寸、牆高和牆厚、內牆面、地板和天花板的顏色，以及所有外牆的顏色；⟳ 90°、⧉ Duplicate（在旁邊生成一個共用牆的副本）、△ Roof。Delete 刪除所選內容；E Eraser 點選即可刪除；B Paint 可為房間的牆、地板、天花板、門或屋頂上色。

🌙 Night（夜間）會調暗太陽和天空，讓燈光照亮房間（白天燈光是關閉的——這裡的燈光會穿透牆壁，因此白天它也會照亮室外）。⌂ Cut-away（剖切）隱藏所有屋頂和天花板，以便從上方檢視室內。

推斷——指標吸附的位置

  • 標記及其文字表示該點所在的位置：Endpoint（端點）、Midpoint（中點）、Origin（原點）、On Edge（在邊上）、On Face（在面上）、On Ground（在地面上）。
  • 從上一個點起，當你處於紅/綠/藍軸上時會顯示一條虛線。按住 Shift 可鎖定該軸，或按 → 鎖定紅軸、← 鎖定綠軸、↑ 鎖定藍軸（↓ 解除鎖定）。
  • 推/拉會吸附到指標所在的角點、邊或另一個面的高度。
  • 長度可輸入為 1.5（m）、150cm、1500mm、5'、10"。

工具列

  • ☰ File ▾（檔案）——New、Open、Save（Ctrl+S）、Save as、Rename，匯入專案中的 3D 模型或本機檔案（.pp3d、.glb、.gltf、.obj），Export，傳送到影像編輯器/時間軸/其他位置，Delete、Maximize、Close。
  • 名稱和 💾——模型儲存在專案中，每次更改後片刻即自動儲存。↶ ↷（Ctrl+Z / Ctrl+Y）。
  • 📐 Plan（平面圖；或 View ▾ 📐 Floorplan）——平面圖：以應用程式的主題色垂直俯視顯示（2.649.0），一次顯示一層（用清單選擇樓層）。牆以實心剖切顯示，門帶門扇和開啟弧線，窗帶玻璃和窗臺，樓梯顯示每級踏步和 UP 標記，家具顯示輪廓和名稱，燈光顯示為圓圈加十字，並標註每個房間的名稱、寬 × 長和面積。所有工具都可以像在 3D 中一樣在平面圖上繪製；點選可選取符號；Orbit 會旋轉平面圖（保持平面）。再次點選 📐 或切換到其他檢視：返回 3D 檢視。
  • 材質（2.651.0）：牆的面板有 Inside（內側）和 Outside（外側），窗有 Frame（窗框）和 Glass（玻璃），地板、天花板、踢腳線、頂角線、屋頂和樓梯也各有自己的選項——每一項都會開啟材質選擇器：一種顏色、一種內建材質，或一張圖片（來自 🖼 Refs 面板、專案圖片或檔案；儲存在專案中；Size = 一張圖覆蓋的米數，Turn ° = 旋轉角度）。油漆桶只為你點選的那一側牆面上色（Shift+點選：該側的所有牆）。
  • ⛰ Terrain（地形，2.653.0，Alt+G——G 是 Group）：地面。第一次點選會在建築周圍生成一塊地面（略低於其最低樓層）。在其面板中選擇按下時執行的操作：⬆ Raise（抬高）/ ⬇ Lower（降低）（拖曳；按住 Shift 反向）、≈ Smooth（平滑）、▬ Flatten（壓平；Alt+點選吸取高度）——Brush size（筆刷大小）、Strength（強度）、[ / ]；〰 Contour（等高線）：輸入或設定 Elevation（高程），點選、點選……（回到起點即閉合，雙擊/Enter 結束）——地面會按這些線塑形（每條線保持其高度，線之間平滑過渡）；點選一條線即可選取（其高程、是否閉合、Delete）。此外還有 🖼 Heightmap picture…（高度圖；黑 = Lowest，白 = Highest，圖片上方 = 北）、⌂ Level under the rooms（在房間下方找平，在邊距範圍內平滑過渡）、⊙ Centre on the building（以建築為中心）、Width / Length / Detail、Material、等高線間距、土方側面、▬ Flatten all（全部壓平）、🗑 Remove the ground（移除地面）。📐 平面圖會繪製其等高線。
  • ✂ Cut / fill（挖填方，2.656.0，位於 ⛰ Terrain 中）：在地面上點選場地平臺的各個角點，回到第一個點（或雙擊/Enter）結束——平臺內部在其標高處找平（取地面平均標高，或手動輸入），以 1 : n 的放坡回接到原地面，可選挖填方/僅挖方/僅填方；挖方和填方量以 m³ 顯示。點選平臺即可選取（標高、放坡、⟳ Apply again、🗑 Forget / Delete = 刪除其輪廓，保留地面）。
  • 🏊 Pool（泳池，2.657.0，位於 Ground 下）：兩個角點（或輸入 8,4）——或選擇 Shape: Free shape，點出其各個角點。可設定淺水端/深水端、池邊瓷磚、木平臺或兩者兼有、標高；在 ⛰ 地面上時會切入地面，並將周圍地面找平。➤ Select 選取它：尺寸、深度、⇄ 深水端、池邊、材質、內襯、水、Delete。
  • 🛣 Driveway（車道，2.659.0，位於 Ground 下）：沿路線點選各點，雙擊/Enter 結束。其節點（□）和控制柄（○）會顯示出來：拖曳控制柄可彎曲曲線（Alt：僅一側），拖曳節點可移動它，Delete 刪除所點選的節點。➤ Select 選取它：寬度、路面、路緣石、貼地/位於某一標高、〰 Smooth、Delete。
  • 移除單面牆 / 內牆或外牆（2.660.0）：在牆上使用 ⌫ Eraser（或按 Delete，或在其面板中點選 🗑 Take this wall out）只移除這一面牆——地板和天花板保留；共用牆會從兩個房間中同時移除。Shift+Eraser = 整個房間；房間的 ↺ Put back 可將其恢復。牆的面板：Interior / exterior（Auto：兩側都有房間 = 內牆）——內牆的外側面使用其內側顏色；平面圖中內牆的填充色較淺。
  • 🧱 Wall types（牆體類型，2.661.0，位於工具列中）：模型的牆體類型及其由外到內的構造層（磚、空氣層、框架 + 保溫棉、保溫層、石膏板、抹灰、外掛板……）——可修改某層的種類/厚度，↑ ↓ ✕，＋ Add a layer；各層總厚度即牆厚。Use it for（套用於）選取的牆、房間的牆、所有外牆/內牆。牆體按該厚度構建，並以最外層著色；各層接縫顯示在牆頂和平面圖上。牆的面板：Wall type。
  • 方形牆端 + 從轉角拉出牆（2.662.0）：每面牆的端部都是方正的；其轉角和自由端是獨立的構件。➤ Select：將指標指向外轉角或牆端——它會亮起——然後從它的某一側向外拖曳：即朝該方向生成一面新牆（從頂部拖曳、從上方看時：任意方向），高度/厚度與原牆相同，並沿用其牆體類型。
  • 分割牆 + 草圖平面（2.663.0）：雙擊牆（從上方、在平面圖中或在 3D 中雙擊其牆面）即可將其分割；每一段都可以單獨選取、刪除或向外拖出（新牆會將其與房間連接）。Wall 工具可在房間牆體的任意位置捕捉到它。點選轉角/牆端：設定其 Width（墩柱）和超出端部的 Length。用 Select 點選的面即為草圖平面（Line / Rectangle / Circle / Polygon 在其中繪製；✕ / Esc 結束；2.687.0：不再在其上繪製網格）；⊥ Look at 使檢視正對它。2.688.0：點選牆的端部構件 = 選取整面牆；雙擊它 = 沿牆推/拉牆的端部；Ctrl+拖曳 = 保持水平/豎直；✨ Photo 只會提及模型中實際包含的內容。
  • 🛤 Road（道路，2.673.0）：Ground ▸ 🛤 Road——選擇 Dirt road、Street、Road、One-way、Avenue 或 Highway，沿路線點選，雙擊/Enter 結束。道路會貼合地面；若對該道路類型而言過陡：在面板中使用 ⛏ Cut the ground 或 🚇 Tunnel / bridge。路口會自動生成紅綠燈、停車/讓行標誌、人行橫道和路名牌。Alt+點選道路可拖曳其節點。
  • 天溝輪廓（2.671.0）：選取屋頂——Gutters 列出 Quad、Half round、OG 和 Square line；Gutter profile 以圖片形式顯示它們（以及你自己的輪廓）；✎ Gutter profiles… 開啟天溝的輪廓編輯器（左側為封簷板）——像踢腳線一樣用節點和曲線繪製，💾 Save 後屋頂的天溝就會使用它。
  • 貝塞爾輪廓（2.670.0）：在 ✎ New / edit profiles… 中，弧線是帶兩個節點的曲線；點選節點或線段即可選取，可拖曳節點和曲線的控制柄，雙擊線段可新增節點，右鍵點選可選擇 Convert to curve / Convert to line / Delete node。
  • 簷口、封簷板、天溝（2.668.0）：Roof 面板中的簷口圖片——Simple（簡單）、Open（外露椽尾）、Boxed（平底簷口板）、Closed（沿坡面封板）；Fascia + barge boards（封簷板 + 山牆封簷板，可設高度）；Gutters quad / half round，帶 Downpipes（落水管）；選取屋頂的封簷板/簷底板和天溝顏色。
  • 🗂 Objects panel（物件面板，2.667.0）：Shapes（形狀）——你繪製的每個形狀（點選即可選取，拖曳某個面可推/拉它——組的面也可以）；Construction（輔助）——Planes（平面：📌 保留草圖平面，＋ ground / front / side；點選某個平面可再次在其中繪製，⊥ 使檢視正對它）和 Construction lines（輔助線：使用 📏 Tape measure 時在第二次點選時按住 Ctrl——各工具會吸附到輔助線上）；雙擊任意行的名稱（或按 F2）可重新命名。
  • △ Roof types（屋頂類型，2.666.0）：Roof 面板以圖片顯示每種類型——雙坡、四坡、單坡（skillion）、荷蘭式山牆（Dutch gable）、截角山牆、複折式（gambrel）、孟莎式（mansard）、鹽盒式（saltbox）、金字塔式、蝶形、平頂、隨牆——每種都有各自的設定（坡度、下段坡度、折點、屋脊位置、用 Flip 切換高側）。
  • 📄 Building plans（建築圖紙，2.665.0）：工具列上的 📄 Plans——每層一張平面圖、四個立面圖以及屋頂/總平面圖，按比例輸出到 A4 - A1，可全部放在一張圖紙上，或每頁一個檢視；尺寸以 mm 標註，並含標高、房間名稱/面積和圖籤。💾 Save PDF 會將其儲存到專案的 pdf 資料夾（以及你的下載資料夾）。
  • 🧍 Mannequin model（人臺模型，2.664.0）：🛋 Furniture ▸ People ▸ mannequin (model)——一個經過建模的女性人臺，高度與人物相同（作者 dimasalcalde 和 zahers，來自 CGTrader——見 Settings ▸ About）。其檔案以單獨的 zip 提供；沒有該檔案時會繪製站立的人形。
  • ✨ Photo（照片，2.652.0）：生成目前檢視的真實照片——編輯模型會收到乾淨的渲染圖、其深度圖，以及一張標註了你的材質圖片和背景圖片的拼板（並附加提示詞框中的文字）；照片會存入專案圖片，若影像編輯器已開啟也會發送到其中。能接收兩張圖片的模型則會收到不含拼板的輸入。
  • 🖼 Background（背景）：模型後面的一張背景圖（填滿檢視，不會被拉伸），或圍繞場景的一張 360° 天空全景圖（可旋轉）——或者不使用（採用主題背景）。
  • Esc——無工具、無選擇、🔄 Orbit——適用於 3D 檢視、平面圖和攝影機檢視（正在繪製的牆會保留）。在 Orbit 中，Esc = ➤ Select。Esc 永遠不會讓最大化的 Sketcher 停靠回去（⇲ Dock 才會）。
  • 縮放：Shift + 右鍵拖曳——向前（向上）放大，向後（向下）縮小，以按下的點為中心（平面圖中同樣適用；滾輪用法不變）。⊡（位於 ⤢ 旁邊）縮放到所選內容——面、房間、牆、門、家具、攝影機……；未選取任何內容 = 顯示全部。
  • View ▾ Iso / Top / Front / Right / Back / Left、Persp / Parallel（透視/平行）、⤢ 全部顯示、面樣式（著色 + 邊線、著色、單色、X 光、線框）、☀ 陰影。
  • ▣ Group（G）將所選內容編組；選取組時則將其炸開（解組）。
  • 🌙 Night 和 ⌂ Cut-away（見「建築」部分）。
  • 🖼 → Image editor——按你所見（白天或夜間）生成檢視圖片。🎞 → Timeline——將模型作為 3D 圖層傳送。
  • ➜ Send ▾：將檢視圖片傳送到影像編輯器（可帶或不帶背景），作為時間軸上的 3D 圖層傳送（再次傳送時其圖層會更新），或傳送到 Blender、Unreal。
  • ⤓ Export ▾：匯出 .glb（可帶或不帶燈光——glTF 燈光，Blender 和 Unreal 可匯入）或 .obj 到專案的 3D 模型中；匯出 .glb、.obj 或 .stl（毫米單位，用於 3D 列印）到本機。⤒ Import ▾：將專案中的 3D 模型作為組匯入。

⛶ Maximize（最大化，位於其標題列）會讓面板填滿整個 bitGen 視窗中標題列與狀態列之間的區域（兩者均保留）；此時按鈕變為 ⇲ Dock（停靠）——點選它或按 Esc（沒有其他進行中的操作時）即可恢復。旁邊的 ✕ 關閉面板。最大化期間其他所有面板都會關閉；⇲ Dock 會重新開啟原先那些面板（2.628.0）。面板使用 bitGen 的主題色（其 3D 檢視的背景、網格和選取範圍也是如此）。

Sketcher 取代了 House builder（舊版本中的房屋生成器，2.630.0）——其家具（🛋 A）、材質（▦）、攝影機 + 360° 地點（📷 Z）、🪄 Furnish 和人物（🛋 ▸ People）都已移到這裡。☰ File ▸ 🏠 A house from the House builder… 可將舊版 House builder 儲存的房屋作為 Sketcher 模型匯入（房間、門、窗、家具、人物、攝影機、燈光、樓梯）。
