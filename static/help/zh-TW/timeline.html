時間軸

✅ 任意設定均可設關鍵幀（2.516.0）

  • 片段某項設定旁的 ◇ = 在播放頭處為它設一個關鍵幀（◆ = 此處已有關鍵幀；點選可刪除，Alt+點選 = 刪除全部）。設過關鍵幀後，在任意位置修改它都會在該處自動設關鍵幀。
  • 顏色（曝光……色相、LUT 混合、色輪亮度、HSL 範圍）、鏡頭、變形、去背工具、✒ 遮罩羽化 / 擴展 / 不透明度、文字大小 / 描邊、⏱ 時間效果。
  • 📈 Graph Editor（圖表編輯器）會列出所有設了關鍵幀的設定。⚙ Compile（編譯）的繪製結果與之相同。

✅ 主體去背、移除主體、解算攝影機（2.515.0）

  • 🧍 Cut out（去背；位於影片片段的 Properties 中）：用 ✚ 點選主體，用 ✖ 點選非主體部分，或用 ▭ 拖出一個框，然後點 ▶ Cut out。主體會在整個片段中被追蹤（SAM 2、AI 去背或內建方式）。邊緣最佳化：吸附、羽化、收縮、平滑。在影片圖層上，use it（使用）= 主體周圍變為透明（畫布和編譯均生效）。
  • 🩹 Remove（移除）：將去背後的內容（或該圖層的 ✒ 遮罩）從每一幀中去除。背景取自前後的幀，始終看不到的部分則自動補畫。先在影像編輯器中補好一張參考幀會有幫助。↺ Original 可復原。
  • 📷 3D camera track（3D 攝影機追蹤）：先 ▶ Solve，再用 📷 Pick points 選點，然後用 📌 Place 將圖層平貼在這些點上、立在上面或朝向攝影機。🧊 3D camera 會跟隨解算結果。
  • Ctrl+Shift+Alt+E：帶對話方塊的主題編輯模式（Settings 保持開啟，以便設定樣式）。Ctrl+S 儲存主題並離開。

✅ 時間軸的畫幅尺寸欄；Load UE project（2.513.0）

  • Frame（畫幅；Timeline 頂部的欄）：寬 × 高、一個 Preset（預設：Auto = V1 影片的尺寸，4K、Full HD、HD、直式、方形、4:5、21:9、電影……）以及輸入時保持不變的 Aspect（長寬比）。V1 會被適配到畫幅內並居中；編譯結果與之一致。
  • 同一欄上的 ☐ CAD toolbar 用於顯示 CAD 工具列（其 ⌬ 按鈕被隱藏）。
  • 🎮 Load UE project（應用程式的選單列）：選擇專案資料夾，按 Select。bitGen Bridge 外掛會被裝入，所需的外掛會被啟用，Unreal 會隨該專案重新啟動。

✅ Lottie（JSON）匯出（2.512.0）

  • 📤 Export → ⤓ Lottie (JSON)：將圖片圖層和文字圖層匯出為 <project>_lottie.json，與影片放在一起。
  • 移動、縮放、旋轉和淡入淡出保留為動畫圖層（緩動和定格會保留，混合模式也會保留）。帶效果、遮罩、3D、父級或表示式的圖層以逐幀方式匯出。
  • 影片圖層和軌道遮罩不會匯出，並會列出其名稱。

✅ 可變羽化、資料、範本欄位（2.511.0）

  • ✒ Variable mask feather（可變遮罩羽化）：用 Mask Pen 按 Shift+拖曳某個遮罩點 = 為該點單獨設羽化值（以一個圓環顯示）；邊緣在各點的羽化值之間平滑過渡。
  • 📋 Data（資料）：將 CSV / JSON 匯入為一個帶「目前列」的資料集；在文字中使用 {{set.column}}，在 ƒx 中使用 data("set", "column", row)，還可用 📋 Data → keys（每隔若干秒切換一列）。
  • 📋 Template fields（範本欄位）：帶標籤公開文字顏色、不透明度、縮放、x、y、旋轉；在同一個清單中統一編輯；🧩 範本在拖入時會提供這些欄位。

✅ 3D 空間中的 2D 圖層（2.510.0）

  • Properties 中的 🧊 3D layer（3D 圖層）：一張帶深度 z、x / y 旋轉、可投射 / 接收陰影的卡片（均可設關鍵幀）。
  • 🎥 3D camera（3D 攝影機）：位置、目標點、縮放，均可設關鍵幀；🧊 Orbit（Shift+O）拖曳 = 環繞，按住 Shift = 推拉，按住 Alt = 平移。
  • Depth of field（景深：焦點、光圈），以及一盞 light（燈光），其陰影會從卡片投射到後方的卡片上。
  • 卡片按圖層順序堆疊。編譯結果與畫布一致，包括 3D 影片圖層。

✅ 運動草圖、擺動器、平滑器（2.509.0）

  • ✍ Motion sketch（運動草圖；Shift+K，或 〰 Motion → ✍ Sketch）：按下並移動。時間軸開始播放，圖層跟隨指標移動；鬆開即停止。可設速度 %、平滑 px。
  • ≈ Wiggler（擺動器）：為某個屬性新增隨機運動。可設每秒次數、幅度、平滑或鋸齒、位置 x / y 分開處理、種子。
  • ⌇ Smoother（平滑器）：將某個屬性的關鍵幀在 ± 若干幀範圍內取平均，再在容差範圍內精簡。
  • 結果都是普通關鍵幀，可在圖表編輯器中編輯，編譯時也會按它們播放。

✅ 音訊 → 關鍵幀、波形和頻譜圖層（2.508.0）

  • 任意圖層 Properties 中的 ♪ Audio → keys：選擇單個片段的聲音或全部聲音；響度、低音、中音或高音；一個屬性（不透明度、縮放、x、y、旋轉、生成器 / 光線的數值）從安靜到響亮的取值範圍；平滑；然後點 ♪ Make keys。
  • 🌫 Waveform（波形）：使用 🌫 工具按 Alt+點選。波浪 / 線條 / 柱狀、跨度、增益、顏色。
  • 🌫 Spectrum（頻譜）：Alt+Shift+點選。柱狀 / 線條 / 圓形、頻段數、增益、間隙、底限、從低到高的顏色。
  • ƒx audio()、audio("bass")、audio("mid")、audio("treble")：該時刻的混音電平，0..1。編譯結果與畫布一致。

✅ 操控釘點和網格變形（2.507.0）

  • 在選取的圖層上使用 📌 Puppet（操控；Shift+W）：點選 = 新增一個釘點，拖曳釘點 = 圖層彎曲而其他釘點保持不動，Alt+點選 = 刪除釘點。
  • 📌 Warp 中的 ◇ key here 會為每個釘點設關鍵幀；此後每次拖曳都會在播放頭處設關鍵幀，釘點在關鍵幀之間平滑過渡。
  • ⌗ Mesh warp（網格變形）：由欄 × 列個點組成的網格，用 📌 工具拖曳這些點；平滑曲線會穿過它們。
  • 衰減（釘點的影響範圍）、細節；編譯結果與畫布一致，包括影片圖層。

✅ 粒子和光線（2.506.0）

  • ✨ Particles（粒子）：使用 🌫 Generator 工具按 Shift+點選。點 / 線 / 盒形發射器；發射速率、壽命、預捲；速度、方向、擴散、重力、風；圓點 / 圓形 / 方形 / 星形 / 火花；隨粒子壽命變化的大小、顏色和不透明度。
  • 任意圖層上的 ☀ Light rays（光線）：圖層的明亮部分從一個光源點向外拖出光束（長度、強度、閾值、色調、僅顯示光線），並可超出圖層邊緣。
  • 每項設定都可設關鍵幀（◇）並可用於 ƒx。編譯結果與畫布一致。帶光線的影片圖層會由頁面整體烘焙，並保留其聲音。

✅ 生成器和扭曲（2.505.0）

  • 🌫 Generator tool（生成器工具）：點選 = 一個 Fractal Noise（分形噪波）圖層（基本 / 湍流；縮放、複雜度、會自行變化的演化、顏色），拖曳 = 一個 Gradient Ramp（漸層：線性 / 徑向）。
  • 任意圖層上的 〰 Distort（扭曲）：Turbulent displace（湍流置換：數量、大小、演化），或來自另一個圖層的 Displacement map（置換貼圖：按亮度，或紅色 ↔ / 綠色 ↕）。
  • 每項設定都可設關鍵幀（◇）並可用於 ƒx；編譯結果與畫布一致，包括影片圖層。

✅ 曲線時間重對應（2.501.0）

  • 影片片段 🎬 Speed 中的 ⏱ Time remap（時間重對應）：一條片段時間對源時間的曲線。拖曳關鍵幀，雙擊可新增或刪除關鍵幀。
  • 在播放頭處 ◇ Key，用 ❄ Freeze 將播放頭處的幀定格幾秒，另有一行關鍵幀數值，可輸入精確值。
  • 同一個片段內可正放、倒放、定格、加速或減速；聲音隨之變化；編譯結果與畫布一致。

✅ 運動模糊、Posterize Time、Echo（2.500.0）

  • ⏱ Time（時間；圖層的 Properties）：運動模糊（快門角度、取樣數）、色調分離時間（fps）、回聲（副本數、間隔、首個副本強度、衰減）。
  • 適用於圖片、文字、形狀和影片圖層；編譯結果與畫布一致。

✅ 追蹤 + 邊角定位（2.499.0）

  • 🎯 Track（追蹤；影片片段的 Properties）：單點、兩點（+ 縮放 / 旋轉）、邊角定位、平面（一個平坦表面）——◎ Place，▶ Track（逐幀、亞像素精度），然後 Apply（套用）到某個圖層。
  • ▢ Corner pin（邊角定位；任意圖層）：將圖層繪製到 4 個角點中——角點來自追蹤，或用 ✥ Edit corners 手動拖曳。
  • 編譯：定位後的圖片會被烘焙，定位後的影片由編譯進行變形——與畫布相同。

✅ 貝塞爾遮罩（2.498.0）

  • ✒ Mask Pen（遮罩鋼筆；Shift+M）：點選建立角點，拖曳建立曲線，在第一個點上閉合 / 按 Enter；拖曳點和手柄進行編輯（Alt = 只動一個手柄）。
  • ✒ Masks（遮罩；Properties）：每個圖層可有多個——相加 / 相減 / 交集 / 差值、羽化、擴展、不透明度、反轉；◇ 為路徑設關鍵幀（動畫遮罩）。
  • 適用於圖片、文字、形狀和影片圖層；編譯結果與畫布一致（影片的遮罩以遮罩影片的形式處理）。

✅ 表示式（2.497.0）

  • ƒx Expressions（表示式；圖層的 Properties）：作用於 x / y / 縮放 / 旋轉 / 不透明度 / 錨點（以及形狀 / 文字動畫器數值）的小公式——帶預設和即時檢查。
  • value、time、wiggle(f, a)、loopOut("cycle" | "pingpong" | "offset" | "continue")、valueAtTime、linear / ease、random、layer("name", "x") 連結。
  • 不是 JavaScript——不會執行任何其他程式碼。編譯使用由表示式計算出的關鍵幀。

✅ 手繪形狀、Merge Paths、路徑文字、漂移關鍵幀（2.496.0）

  • ✎ Freehand（手繪；Shift+Q）：繪製封閉形狀或開放線條（Alt = 繪入選取的形狀圖層）。
  • ⧉ ＋ Path + ⊕ Merge Paths：在一個形狀圖層中放多條路徑，以相加 / 相減 / 交集 / 排除方式合併（也可形成孔洞）。
  • 〰 On a path（沿路徑）：文字沿圓弧、圓形、波浪或形狀圖層的輪廓排列；起點 % 可設關鍵幀。
  • Rove（漂移；Graph Editor）：重新安排位置關鍵幀的時間，使沿路徑的速度保持均勻。

✅ 顏色混合模式 + 跟隨父級的影片圖層（2.495.0）

  • ◐ Blend（混合）：新增 Hue、Saturation、Color、Luminosity——亮度取自一方，顏色取自另一方；編譯結果與畫布一致。
  • 影片圖層上的 ⛓ Parent（父級）：它隨父級（空物件、圖片或另一個影片）一起移動、旋轉和縮放；編譯時同樣跟隨。

✅ 文字動畫器（2.493.0）

  • 對其範圍所選取的字母改變 x / y、縮放、旋轉、不透明度、字距、模糊、顏色：起點 / 終點 / 偏移 / 數量，按字母 / 單詞 / 行，方形 / 斜坡 / 三角 / 圓形 / 平滑。
  • 每個數值都可用 ◇ 設關鍵幀（也可在 📈 Graph Editor 中編輯）；編譯時會烘焙。

✅ 形狀圖層 + 操作器（2.492.0）

  • 填充（顏色或漸層）、描邊（寬度、端點）；Trim Paths、Repeater、Offset Paths、Pucker & Bloat、Twist、Zig Zag、Wiggle Paths、Round Corners。

✅ 混合模式和軌道遮罩（2.491.0）

  • ▣ Matte（遮罩）：Alpha、Alpha Inverted、Luma、Luma Inverted——圖層只在緊鄰其上方的圖層所在（或不在）的地方顯示；那個上方圖層本身不會被繪製。

✅ 父子關係和空物件（2.490.0）

  • ＋ Null（空物件）：一個空的控制圖層（畫布上顯示為紅色虛線方框，從不參與編譯），用於設關鍵幀並作為其他圖層的父級。

✅ Graph Editor、Easy Ease、錨點、曲線運動路徑（2.489.0）

  • ⊕ Anchor X / Y：位置的定位點，也是縮放 / 旋轉的軸心（可設關鍵幀）。
  • ↝ Smooth path（平滑路徑）以及畫布上的運動路徑：拖曳 ■ 關鍵幀，Alt+拖曳可拉出手柄，拖曳 ● 手柄可使路徑彎曲。編譯的繪製結果相同。

  • 選擇或用遮罩圈出一個區域，寫下那裡應有的內容，然後選擇 Image 或 Video，再點 ✨ Generate。
  • Image（圖片）根據位置標記處的幀重繪該區域（使用影像編輯器的 inpaint 風格），並將結果放到一個新的圖片圖層上，透過羽化遮罩融入場景。持續時間為標尺選取範圍的長度，沒有選取範圍則為 3 s。
  • Video（影片）先做同樣的處理，再用影片模型將這張圖片按你設定的秒數做成動畫，並放到一個帶相同柔邊遮罩的新影片圖層上。

關鍵幀

  • 選取一個圖層，將位置標記放在動畫開始處，點選 ◇ Key：位置、縮放、旋轉、不透明度（以及文字圖層的顏色）會儲存在該處，在片段上顯示為 ◆。
  • 移動標記並修改圖層：會在該處生成第二個關鍵幀。畫布和 Compile 會在兩者之間補間。
  • ◀ ▶ 在關鍵幀之間跳轉；關鍵幀上的選單用於設定它如何過渡到下一個關鍵幀：linear、ease in、ease out、ease in+out、hold。✕◆ 刪除關鍵幀。點選時間軸上的 ◆ 可編輯它。

紅色位置標記

  • 拖曳它——拖曳其頭部或沿其豎線的任意位置均可，有無標尺選取範圍都行。預覽播放期間，播放會持續到你鬆開為止，然後從該處繼續；停止狀態下，預覽會顯示你鬆開處的幀。
  • 點選軌道的空白處：標記跳到該處（正在播放的預覽從該處繼續）。在標尺或軌道上雙擊某個時間：標記移到該處，預覽從該處開始播放。
  • 播放 / 暫停 / 停止按鈕位於預覽畫布下方（或在畫布上按 Space）；點選標記本身會暫停正在播放的預覽。

時間軸上的圖層

  • 每個圖層都有自己的顏色：圖層頭上的一條色帶、所在行的底色，以及該顏色的片段。選取的圖層帶有勾邊，其圖層頭會亮起。
  • F/L 和 REF 標記行會隨縮放變大（最小不小於一行文字的高度）。

標尺選取範圍

  • 在標尺上拖曳，或在位置標記處使用 ⟦ In / Out ⟧；＋1s 選取一秒。欄中顯示 start:end - frames。
  • ⇥ Keep 只保留選取範圍，✂ Cut 刪除選取範圍——作用於反白的圖層（範圍 layer），或僅作用於其下方的片段（範圍 clip）。ripple 會閉合空隙。▦ Frames 顯示選取範圍中的每一幀。
  • ⇤ Head / Tail ⇥ 在標記處修剪位置標記下方的片段。

🎤 卡拉 OK

  • 🎤 Karaoke style（卡拉 OK 樣式；在此處的 ⚙ 和影片面板的 ⚙ 中）：字型、字號、顏色、背景條、跳動小球。新的疊加層會使用這些樣式。

⚙ Timeline settings（時間軸設定）

  • Nudge（微移）：點選一個片段，然後按 ← / →，按此處設定的幀數移動它（Shift：較大步長）。V1 會將其片段依次連續播放。
  • Place each rendered scene at its song time（將每個渲染好的場景放在其歌曲時間處）：影片面板的分鏡腳本上有歌曲時，鏡次會落在歌曲中其對應段落開始的那一秒。

H3 尺寸（影片面板的 ⚙）

面板尺寸、📌 固定與最大化

  • 狀態列為每個面板都提供一個按鈕（Preview、Timeline、Video、Music、Stems、SFX、Editor、ComfyUI、Chat、Prompt、Console，以及 ⟨ Refs Assets Queue ⟩）。面板顯示在螢幕上時（無論是展開還是摺疊到標題列），按鈕會亮起；點選可隱藏該面板或重新顯示。
  • 每個面板的開啟 / 關閉 / 隱藏狀態、高度、寬度、📌 最大高度 / 最大寬度以及最大化狀態都儲存在應用程式旁的 docker_status.json 中（所有專案使用同一佈局）。它會在其他任何內容繪製之前載入。
  • 📌（面板標題列中的第一個按鈕）：固定後，面板目前的高度成為其最大高度——拖曳可以縮小，但不能拉高。再次點選即取消固定（最大高度 0：任意高度）。在側邊面板上，固定會保持其寬度。
  • 開啟一個面板時，其他已開啟的固定面板會恢復到固定高度；所需空間從未固定的面板中騰出。
  • ⛶ Maximize（最大化）：該面板佔據其他已開啟面板剩下的全部空間；其他面板保持開啟，維持自身高度（或固定高度，取較小者）。面板最大化時，所有分隔條仍然可用。Esc 或 🗗 可恢復。

🧊 3D 圖層：3D 文字和 3D 模型

  • 🧊（畫布工具列中 T 的下方）：3D text，或 3D model file…（.fbx、.obj、.glb 或 .gltf——選擇時把 OBJ 的 .mtl / glTF 的 .bin 以及紋理圖片一併選上）。專案中已有的模型也會列出。將 .fbx / .obj 檔案拖放到畫布上效果相同。
  • 3D 圖層的擺放方式與影片相同：拖曳它，拖曳角點縮放，拖曳頂部手柄做平面旋轉；X / Y / Scale / Rotation / Opacity 和 ◆ 關鍵幀與其他圖層一樣可用。
  • 它自身的設定：文字、字型（本機字型）、粗體 / 斜體、厚度和倒角；或者模型、其內建材質或單一顏色、其動畫；Rot X / Y / Z（俯仰、轉向、翻滾——用 ◇ Key 為其設關鍵幀）和 Spin（每秒旋轉的度數）；3D 畫面的 W × H；時長。
  • 畫布會即時繪製它。對於 ⚙ Compile，它會在每次更改後片刻被烘焙為一個透明影片（video/m3d_<id>.webm）；Compile 會等待所有尚未完成的烘焙。狀態行會顯示烘焙情況；🧊 Bake 可立即烘焙。
  • 模型檔案儲存在專案的 models3d 資料夾中。

🧰 Tools & Properties（浮動面板）

  • 2.438.0：它始終保持在時間軸面板內部（無論是拖曳、調整大小，還是面板尺寸改變時），時間軸面板摺疊時它會隱藏。
  • 畫布工具（Move、Text、🧊 3D、Select、Mask、Hand、Zoom、Fit、顏色）以及選取圖層的 Properties 位於一個獨立的浮動面板中。鍵盤上的 1 可顯示 / 隱藏它（輸入文字時無效）；時間軸選單列中的 🧰 和其標題列上的 ✕ 也可以。
  • 拖曳標題列可移動它，拖曳任意邊緣可調整大小——位置和大小都會被記住。
  • 停靠在預覽畫布旁（2.410.0）：將它拖到畫布的左邊緣或右邊緣——該側會亮起——然後鬆開；或點選其標題列中的 ◧ / ◨。停靠後，它與畫布等高，畫布會讓出空間；拖曳該欄的內側邊緣可調整寬度。將標題列拖開（或再次點選反白的 ◧ / ◨）即恢復浮動。🎤 Karaoke 也可用同樣方式停靠，同一側的兩個面板會上下排列。

🎥 攝影機路徑（2.399.0）

  • 🎥 Camera（時間軸欄）會開啟 Camera 面板，這是一個獨立的面板。Preset ▸ Apply 提供一種運鏡：推近、拉遠、橫移、升降、搖攝、俯仰、翻滾、環繞、搖臂、變焦、飛入。
  • Camera / Top / Side：攝影機看到的畫面，以及從上方和側面看到的路徑（拖曳一個點，或點選空白處新增一個點）。Pan, Tilt, Roll, Height, Dolly, Lens 會在該時刻寫入一個 ◆ 關鍵幀。
  • 🎥 工具（Shift+C）在畫面上繪製攝影機的取景框。拖曳 = 搖攝 / 俯仰，Alt+拖曳 = 翻滾，Shift+拖曳 = 高度，滾輪 = 推拉，Shift+滾輪 = 變焦。
  • Use in Generate（在生成中使用）：MiniMax H3 獲得其攝影機描述句（每個鏡頭一種運鏡），Wan 獲得其 Fun Camera 運鏡，LTX 獲得其攝影機控制 LoRA，此外還會附上用文字描述的運鏡。Exact path + 🎬 Make guide 還會發送一段引導影片（畫面沿路徑飛行，並帶有深度資訊）。

⤳ 路徑圖層：沿你繪製的路徑移動的主體

  • ＋ Path layer（時間軸欄）會建立一個路徑圖層並選取 ⤳ Path 工具（P）：點選畫布放置路徑的點，拖曳點可移動它，Alt-點選某個點可刪除它（Esc / Enter = 完成）。綠點是起點，紅點是終點；虛線框顯示主體在位置標記處的位置和大小。
  • 該圖層的面板（在 🧰 Tools & Properties 中）：沿路徑移動的是什麼（一隻金毛尋回犬、一輛紅色老爺車、一位穿黃色雨衣的女士……），它是動物、人還是車輛，Start 和 Length，它在起點和終點處的 Size（佔畫面高度的 %，越小 = 越遠），步調，朝向，圖片和影片風格，以及綠幕的去除方式。
  • ✨ Generate——In place + follow path（原地 + 沿路徑；任意影片模型）：先生成它在綠幕前的圖片，再生成它原地行走 / 行駛的影片，去除綠幕，然後圖層的片段用 ◆ 關鍵幀使其沿路徑移動——在路徑折返處鏡像翻轉（側視），或隨路徑轉向（俯視），路徑比影片長時循環播放。移動點或修改尺寸後，⟲ Place again 會重建片段。Along the path (Wan ATI)（一種 Wan 2.1 風格 + Wan2_1-I2V-ATI-14B 模型）：主體被放在路徑起點，由模型讓它自己沿路徑行進——生成一個全畫幅片段。
  • Cut out（去背）：AI 去背（BiRefNet——適合毛髮、頭髮和柔和邊緣；需點一次 ⬇ Install AI matte，約 1.5 GB）或色度鍵（無需安裝）。每個路徑圖層都是獨立的透明影片，場景由它們組合而成——編譯也會保留其透明度。

🧊 3D 工具列

  • 選取一個 3D 圖層後，預覽畫布頂部會出現一條工具列（未選取任何 3D 內容時消失）：圖層名稱；控制項 ✥ 移動 / ⟲ 旋轉 / ⤡ 縮放 / ○ 無（對應 G / R / S）；🧲 將旋轉吸附到 15°；檢視 ⬛ 前、◧ 左、◨ 右、⬒ 頂、⬓ 底、↺ 後，以及 ⟲0 無旋轉；⟳ 繞 Y 軸自轉；⤢ 深度歸 0 並縮放為 100%；🎨 材質預設；☀ 開 / 關攝影棚燈光及其亮度；＋💡 新增燈光；◇ Key 在位置標記處設關鍵幀；🟧 用 Blender 渲染，⚙ 其設定，🧊 Bake。

移動和刪除 ◆ 關鍵幀

  • 沿片段拖曳 ◆（以整幀為單位；拖曳時顯示其時間）。它永遠不會越過相鄰關鍵幀：第一個可從片段開頭移到下一個 ◆ − 1 幀處，最後一個可從前一個 ◆ + 1 幀處移到片段結尾。
  • 刪除關鍵幀：右鍵點選它、Alt-點選它，或選取它後按 Delete / Backspace（開啟其編輯器時也可以）——或在其編輯器中點 ✕ Delete keyframe。

🧊 3D 控制項、材質和燈光

  • 控制項（Move 工具，選取一個 3D 圖層）：G ✥ 移動——紅色 X / 綠色 Y 使其在畫面上移動，藍色 Z 箭頭使其靠近 / 遠離攝影機，方塊為自由移動；R ⟲ 旋轉——在球內拖曳可自由翻轉，紅 / 綠圓環僅繞 X / Y 軸旋轉，藍色外環使其翻滾（Shift = 15° 步長）；S ⤡ 縮放——彩色手柄沿其自身的 X / Y / Z 軸拉伸，中心圓環等比縮放。再按一次同一個鍵可隱藏控制項（也可用 Properties 中的 ○）。深度和 Scale X / Y / Z 在 Properties 中也有對應數值，◆ 關鍵幀會記錄它們。
  • 🎨 Material（材質）：一個預設（金、銀、鉻、銅、拉絲鋼、光面塑膠、啞光黏土、橡膠、玻璃、磨砂玻璃、車漆、霓虹輝光、線框），或你自己設定的顏色、金屬度、粗糙度、自發光、不透明度、清漆層、玻璃 + IOR、線框、平面著色和一張紋理圖片（＋ 新增一張；× = 重複次數）。模型的每個部件都可以保留檔案中的材質、使用此材質或採用某個預設。
  • 💡 Lights（燈光）：攝影棚燈光（開 / 關及其亮度），加上你自己新增的燈光——＋ Point、Spot、Sun、Ambient、Sky——每盞都有開 / 關、顏色、brightness（亮度）滑桿以及位置（X 向右，Y 向上，Z 朝向攝影機；物件寬 1 個單位）。

🟧 Blender 橋接

  • 附加元件（bitgen-blender-addon zip）：在 Blender 中依次進入 Edit → Preferences → Add-ons → Install from Disk，勾選 bitGen Bridge。3D 檢視的側邊欄（N）會出現一個 bitGen 分頁：位址（bitGen 的位址，例如 http://127.0.0.1:8311）、🔌 Test、Send to bitGen（傳送帶材質、紋理和動畫的 glTF——選取的物件或整個場景；"Add as 3D layer" 會將其放到時間軸上的位置標記處）、Live link（在 Blender 中每次 Save 都會重新發送；bitGen 會重新載入並重新烘焙其圖層）以及 Get from bitGen（將專案中的某個 3D 模型匯入 Blender）。

片段上的 🎬 Speed、🎨 Colour 和 🎧 Sound（2.406.0）

  • 選取一個影片片段（V1 或某個影片圖層上的片段）：其 Properties 中會出現三個摺疊欄。🎬 Speed（速度）：速度百分比（50 = 半速，200 = 兩倍速），⇄ reverse（倒放），ramp（變速：慢 → 快、快 → 慢、中間慢、中間快——速度沿片段變化），以及慢放幀的生成方式（repeat——清晰；blend——混合相鄰幀；optical flow——平滑，但編譯較慢）。片段在時間軸上的長度會隨之變化；修剪邊緣仍然修剪源素材。
  • 🎨 Colour（顏色）：一種 look（預設調色：青橙、暖色膠片、冷色夜景、漂白效果、鮮豔、褪色、單色），或你自己調節的滑桿——曝光、對比度、飽和度、色溫、色調、色相——以及一個 LUT（3D .cube；＋ LUT 將其匯入專案的 luts/ 資料夾；LUT mix 控制混合程度）。畫布顯示的調色與影片最終得到的完全一致（使用同一張查詢表）。
  • 🎧 Sound（聲音；聲音片段上也有）：voice clarity（人聲清晰度：切除低頻隆隆聲、略微提升臨場感、溫和的壓縮器）、denoise（降噪）和 gain（增益）；🎧 before / after 從位置標記處播放幾秒，先播原樣，再播處理後的效果。role（角色：🗣 voice、🎵 music、💥 sfx）是該圖層在混音中承擔的部分。
  • 倒放或變速的片段在畫布預覽中是靜音的（瀏覽器無法倒放聲音）；編譯會渲染其聲音。

🎚 Mix：自動閃避和響度

  • 時間軸的 🎚：每個圖層的角色、ducking（自動閃避：有人說話時音樂降低所選的 dB，之後恢復）和 loudness（響度：將整部影片統一到 -14 LUFS 用於 YouTube / Spotify，-16 用於播客，-23 / -24 用於廣播電視）。

💬 字幕

  • ✨ From speech（從語音生成）會在本機上識別時間軸上所有說話的內容（V1、影片圖層以及設為 🗣 voice 的任何聲音圖層）（使用 faster-whisper——在 Settings → Audio 中安裝）並生成字幕，按每個片段所在的位置放置（也考慮其修剪和速度）。每個檔案只轉錄一次，結果會被記住。
  • 編輯時間和文字，＋ 在位置標記處新增一條，✕ 刪除一條；▶ 跳到該處。樣式：字型、字號（佔畫面高度的 %）、顏色、描邊或文字後的底框、底部 / 中間 / 頂部以及邊距。
  • 畫布會在編譯燒錄字幕的相同位置繪製它們。burn into the movie（燒錄進影片）和 / 或 .srt beside it（在影片旁生成 .srt——檔名為影片名加 .srt，播放器和 YouTube 會將其作為字幕軌讀取）；⬇ .srt 可立即下載字幕。

▸ ⇤ ⇹ ⇆ ↔ 編輯工具（2.407.0）

  • 時間軸的工具按鈕：▸ Select（與以前相同）、⇤ Ripple（波紋：拖曳邊緣，修剪它並移動其後的所有內容）、⇹ Roll（滾動：拖曳兩個相鄰片段之間的邊緣，剪下點移動，總長度不變）、⇆ Slip（滑移：拖曳片段，換用其源素材的其他幀，位置和長度不變）以及 ↔ Slide（滑動：在相鄰片段之間拖曳片段，相鄰片段相應伸縮）。提示會顯示拖曳的效果。請放大時間軸，使每條邊緣都有自己的手柄。
  • ▯ Frame（幀；F）：點選某個圖層的軌道，該圖層上指標下方的那一幀會被選取（位置標記跳到該幀）。拖曳可選多幀，Shift+點選可選到所點選的幀，← / → 將選取範圍移動一幀（Shift：移動其末端）。Del 或 ⌫ 從該圖層刪除這些幀並閉合空隙；↶ / Ctrl+Z 恢復；Esc 取消選取範圍。
  • ▼ Ranges（範圍）：播放預覽，在範圍開始處輕按 Ctrl（時間標尺上出現一個 ▼），在結束處再按一次——播放不會中斷，因此可以在反白圖層上標記任意多個範圍，每個都有自己的顏色。拖曳 ▼ 可移動它（預覽顯示該幀）；點選 ▼ 可選取其範圍（Ctrl / Shift + 點選可多選，Esc 取消選取）；右鍵點選可刪除其範圍；Esc 放棄剛開始標記的範圍。選單列中的 ▼ 組：✂ Cut（剪掉選取的範圍，未選取則剪掉全部——選取範圍欄的 ✂ Cut 也會剪掉選取的範圍）、⏩ Speed up 2× - 10×（快進瀏覽渲染內容）、✕。無論焦點在哪裡（文字方塊除外），以及預覽面板的播放器正在播放時間軸片段時，輕按 Ctrl 都會生效。停留在時間軸上會顯示指標下方的時間；預覽下方的速度清單可按 0.125× - 8× 播放。
  • 剪開的片段仍是一個片段：開啟波紋時，在片段中間 ✂ Cut（或對幀按 Del），會把前後兩部分重新合併為一個片段——影片或聲音會生成一個新檔案（Video / Sound 素材中的 "<name>-join1"），圖片則只是變短；一次 ↶ 即可復原。變速、去背、文字 / 3D / 生成的片段，以及關閉波紋時的剪下，仍保持為兩個片段。✂ to new layer（剪到新圖層；選單列中的核取方塊）：✂ Cut、對幀按 Del 以及 Ctrl+K 拆分，會將剪下點之後的部分放到緊鄰上方的新圖層上（V1 的部分放到第一個影片圖層上）。
  • J / L 剪輯：V1 片段的 🎧 Sound 中有 J … s early（聲音先於畫面開始）和 L … s late（聲音在畫面結束後繼續）；相鄰片段在該處的聲音會被靜音。
  • 位置旁會顯示時間碼（HH:MM:SS:FF）；📤 Export 或 ⇄ Exchange 可設定其起始值和幀率。

🎨 顏色：色輪、曲線、HSL、示波器

  • 時間軸的 🎨（或片段 Colour 摺疊欄中的 🎨 more…）會為選取的片段開啟 Colour 對話方塊：Lift / Gamma / Gain 色輪（將圓點拖向某種顏色，滑桿用於調暗 / 調亮；雙擊使其歸中）、Curves（曲線：Master、R、G、B：點選新增點，拖曳移動點，雙擊刪除點）、HSL secondaries（HSL 二級調色：選取一個色相範圍並偏移、（去）飽和或提亮——適用於天空、膚色、植被）以及位置標記處畫面的 scopes（示波器：波形圖、RGB 分量圖、向量示波器、直方圖）。

📤 匯出

  • 選擇影片需要輸出的所有格式：MP4 H.264 / H.265、MOV ProRes 422 HQ / DNxHR HQ、WebM VP9、GIF、WAV / MP3——每種都可設定尺寸、reframe（重構圖：9:16、1:1、4:5、21:9：裁切中間、填充邊框或模糊填充）、幀率和品質。預設包可一次新增多種格式。⚙ Compile + export 透過一次編譯生成全部格式，放在 <project>.mp4 旁邊；Delivered 列出它們以供下載。

⇄ Exchange：XML、EDL、OTIO

  • Send（傳送）：將時間軸以 Final Cut Pro 7 XML、CMX3600 EDL（僅 V1）或 OpenTimelineIO 格式傳送到 DaVinci Resolve、Avid 或其他影片編輯軟體。Bring in（匯入）：匯入來自它們的 XML 或 EDL，會作為一個新的命名時間軸開啟；片段按檔名在本專案中查詢，缺失的片段會被列出。

📝 轉錄：按文字、停頓、口頭禪、場景切換進行剪輯（2.408.0）

  • 選取一個影片或聲音片段，然後點 📝。其中的文字會顯示出來（檔案會在本機上轉錄一次——在 Settings → Audio 中安裝語音轉文字）。點選文字可選取，Shift+點選可選取一段連續文字，也可在文字上拖曳；雙擊某個詞可跳到該處。
  • ✂ Cut them 刪除選取的文字並閉合空隙（其後的片段前移）；⇥ Keep only them 只保留這些文字。Remove pauses over … s 將每段超過該時長的靜音縮短到 0.3 s；Remove filler words 刪除 um、uh、erm、hmm 等口頭禪。↺ Undo 恢復上一次剪下。
  • ✂ Scene cuts 在鏡頭切換處拆分片段（靈敏度數值越低，能偵測到越柔和的變化）。

🎤 卡拉 OK：修正歌詞

  • ✎ Edit lyrics（編輯歌詞）：當歌曲沒有已儲存的歌詞時，文字方塊中顯示語音轉文字聽到的內容——正是卡拉 OK 顯示的內容——因此可以修正錯誤的詞（或貼上真正的歌詞）。Generate 會儲存歌詞並根據歌曲為其定時。
  • ⏱ Words & timing（文字與時間）：疊加層將顯示的每個詞及其開始和結束時間；▶ 播放該詞。修改某個詞或其時間後，Generate 會為這首歌保留這些修改（↺ 可復原）——直到其歌詞發生變化為止。
  • 🎤 Karaoke 是一個面板（2.410.0）：首次開啟時會停靠在預覽畫布右側，這樣你可以一邊播放歌曲一邊修正歌詞；◧ / ◨ / 其標題列可移動它（參見上文 🧰）。在 ⏱ Words & timing 中，正在演唱的詞會亮起，清單會跟隨預覽捲動；詞的時間是一個按鈕，點選可將預覽定位到該處；開始或結束時間旁的 ⤓ 會將其設為預覽目前所在的位置。👁 on canvas 在預覽上繪製修正後的歌詞（僅在畫布上——絕不會進入影片），因此修改會立即顯示；Generate 生成真正的疊加層。
  • 詞上的 ◀ ▶（2.433.0）按 Nudge（0.05 s）將其提前 / 推後；Shift+點選 = 較大的微移量（0.25 s）；Ctrl+點選 = 該詞及其後的所有詞；Shift+Ctrl+點選 = 這些詞全部按較大的微移量移動。微移量在清單上方的框中設定；任何詞都不會早於 0 s。預覽標記所在的那一行會亮起（其中所有詞）。
  • 💾 Save words 儲存修正，但不生成疊加層。影片面板的 ✎（位於 🎤 Karaoke 旁）會針對分鏡腳本上的歌曲開啟此對話方塊；儲存後，各場景的歌詞疊加層會用修正後的歌詞重新生成。

✨ 效果和 ◐ 調整圖層（2.409.0）

  • 影片片段的 Properties 中有 ✨ Effects：模糊、銳化、輝光、暗角、顆粒、crop（裁切：邊緣變為透明，按各邊的 %）、key（去背：綠幕 / 藍幕：顏色、多接近的顏色仍會被去除、柔和邊緣、溢色清理——其下方的圖層會透出來）以及 stabilise（防抖：在編譯時生效；畫布顯示原始拍攝畫面）。
  • 時間軸工具列上的 ◐ 會在位置標記處新增一個調整圖層：新頂層上的一個片段，只要它在時間軸上，其 🎨 Colour 和 ✨ Effects（模糊、銳化、輝光、暗角、顆粒）就會作用於其下方的所有圖層。可像圖片一樣修剪和移動它；其不透明度控制調整效果的混合程度。

⌨ 按鍵、標記、In / Out 匯出和幀（2.410.0）

  • Space 會暫停目前正在播放的任何預覽——畫布、即時預覽、Preview 面板中的影片——無論指標在哪裡，除非你正在文字方塊中輸入（聚焦的按鈕不算輸入）。暫停時再按 Space 會繼續播放；在畫布上輕按為播放，按住則為抓手。
  • 指標位於時間軸的圖層上時（不是畫布，畫布自己的 V / T / H / Z / M / B 鍵保持不變）：V ▸ Select，B ⇤ Ripple，N ⇹ Roll，Y ⇆ Slip，U ↔ Slide，F ▯ Frame（然後用 Del 刪除選取的幀）；I / O 在位置標記處設定標尺選取範圍的 In / Out；Ctrl+K 在位置標記處拆分（選取的片段，否則為反白圖層上其下方的片段）；↑ / ↓ 跳到上一個 / 下一個編輯點；Home / End 跳到開頭 / 結尾。
  • 標記：M（或選單列中的 ⚑）在位置標記處放置一個標記——標尺上的一面彩色小旗，以及貫穿各圖層的一條豎線。點選小旗可跳到該處，拖曳可移動它，雙擊（或在其上按 M）可設定名稱、顏色和備註，🗑 刪除它。Shift+M / Alt+M：下一個 / 上一個標記。📝 ✂ Scene cuts 配合 as markers 會在每次鏡頭切換處放置一個標記，而不是剪下。⇄ Exchange 會將標記寫入 XML、EDL 和 OTIO，並能讀回。
  • 📤 Export 的 Range（範圍）：整部影片，或 In / Out only——每種格式都只由標尺選取範圍生成（<project>_<format>_io），其時間碼和字幕也會相應移動。🖼 Export frame（或 Ctrl+Shift+E）將位置標記處的畫面儲存為 PNG，放在影片旁邊。

🅰 文字效果預設（2.411.0）

  • 文字圖層的 Properties 中有 Preset（預設）：由分層 PSD 文字效果製成的文字效果（應用程式內建 Arena Gold 3D、Trend Candy 3D）以及經典樣式（Gold、Chrome ...）。選擇一個後，文字就會用它繪製——包括其顏色、描邊、倒角、閃粉和厚度——邊輸入邊即時顯示：文字變化時先顯示快速版本，停止輸入片刻後顯示清晰版本。⚙ Compile 始終使用清晰版本。啟用預設時，圖層自身的陰影和描邊會關閉（由預設自行繪製）；選擇 (none) 即可恢復。
  • ＋ Import PSD text effects or a zip… 可新增你自己的預設——一次匯入多個 PSD，或一個包含它們的 zip（文字效果包：其中任何資料夾裡的每個 PSD 都會成為一個預設；其中的字型會放入工作室的字型資料夾；預覽圖和 macOS 副本會被忽略）。每個 PSD 需滿足：文字是帶圖層效果的智慧型物件（大多數「可編輯文字效果」PSD 都是如此）。其背景和裝飾會被忽略；預設與你的其他預設儲存在一起（🗑 可刪除你自己的預設）。PSD 使用的字型會在 Preset 下方的說明中註明——安裝該字型並將其選為圖層字型，即可獲得最接近的效果。
  • 影像編輯器中也有相同的預設：Type 工具的選項列和文字圖層的 Properties。
  • 如實說明侷限：倒角的輪廓等高線為近似處理；在沒有顯示卡的機器上，複雜的預設（幾十個副本）繪製快速版本大約需要一秒——在大多數機器上會更快。

⏯ J / K / L 穿梭播放、AV1、10 位和顯示卡（2.411.0）

  • 在時間軸面板中的任何位置（包括畫布，輸入文字時除外）：L 正向播放，再按一次為 2×、4×、8×；J 以同樣方式倒放（到開頭時停止）；K 停止。按住 K 再按 L / J 可前進 / 後退一幀。速度顯示在 ▶ 旁邊。在時間軸上 L 用於穿梭播放；在其他地方仍用於顯示 LLM token。
  • 📤 Export 提供 MP4 · AV1（同等品質下檔案最小；需較新的播放器）和 MP4 · H.265 10-bit（漸層更平滑），以及 smallest 預設包（AV1 1080 + 720）。
  • use the graphics card's encoder when it has one（顯示卡有編碼器時使用它）：當本機上 NVENC（NVIDIA）、Quick Sync（Intel）或 AMF（AMD）可用時，H.264 / H.265 / AV1 會用它們編碼——每種都會先用單幀測試；都不可用 = 使用普通的軟體編碼器。日誌會說明實際使用了哪一種。

⏱ 丟幀時間碼、範圍、片段標記、目標軌道、連結聲音、音訊效果、色相曲線、效果關鍵幀（2.412.0）

  • 丟幀時間碼：在 29.97 或 59.94 fps 下，📤 Export（以及 ⇄ Exchange）提供 drop-frame——時間碼會跳過某些幀號，以與實際時鐘保持一致（HH:MM:SS;FF）。它會寫入 MP4 / MOV、XML（DF）和 EDL（FCM: DROP FRAME）。
  • 標記範圍：標記的編輯器中有 length（長度；或用 ⟦ ⟧ 取標尺的 In / Out）；範圍是標尺上的一條色帶，拖曳其右端可改變長度。片段標記：Ctrl+Shift+M（或 Shift+點選 ⚑）在選取片段上位置標記處放置一個——片段上的一面小旗，在你修剪、滑移、加速或倒放該片段時始終停留在其所在的幀上。Shift+M / Alt+M 也會在片段標記和範圍端點處停下；⇄ XML / OTIO 會同時攜帶兩者。
  • ◎ Track targets（軌道目標）：圖層頭中的 ◎ 將該圖層設為目標——未選取片段時按 Ctrl+K，會在每個目標圖層上拆分位置標記下方的片段。
  • 🔗 Linked sound（連結聲音）：影片片段的 Properties → 🔗 Sound → ⤓ as its own clip 會將其聲音放到一個 "V1 sound" 圖層上，並保持連結；畫面則靜音播放。選單列中開啟 🔗 linked selection 時，兩者一起移動和修剪；關閉時各自獨立。⛓ Unlink 將兩者永久分開，↩ Sound back 刪除單獨的聲音片段。
  • 每個影片圖層（V2+）以及 🎬 變速片段上都可使用 J / L 剪輯（多出的聲音按片段的速度播放；倒放片段的聲音也是倒放的）。
  • 🎧 EQ（120 Hz 低架、一個可移動的中頻峰值、8 kHz 高架）、multiband（多段）壓縮器和 reverb（混響：small / room / hall）——用 🎧 before / after 試聽；編譯會渲染它們。
  • 🎨 Curves 提供 H/H（色相對色相：將一種顏色移向另一種顏色）和 H/S（色相對飽和度：增加或減少某一種顏色）——曲線兩端在紅色處循環相接。
  • ✨ 效果關鍵幀：◆ key here 在位置標記處儲存效果；有關鍵幀後，在沒有關鍵幀的位置移動滑桿會在該處生成一個關鍵幀。模糊、銳化、輝光、暗角、顆粒和裁切會在關鍵幀之間線性變化——畫布和編譯中均如此。

✅ 倒放 / 變速片段的編輯、智慧重構圖、穩定預覽、倒角輪廓（2.413.0）

  • 編輯工具（波紋、滾動、滑移、滑動）、邊緣手柄和 Ctrl+K 均可用於倒放和變速的 🎬 片段——精確到幀：修剪時恰好保留原有的幀；延長時按片段在該邊緣處的速度播放新增的源素材（變速曲線會在該處新增一個關鍵幀）。
  • 按轉錄編輯和場景切換也可用於變速片段——各部分按播放順序排列。
  • 📤 Export 的適配方式 follow（智慧重構圖）：生成 9:16 / 1:1 / 4:5 版本，其裁切框跟隨主體——優先人臉，其次人物，再次是醒目且運動的物體——沿平穩、平滑的路徑移動。
  • ✨ Stabilise 有 smooth（攝影機路徑的平穩程度）和 locked（完全沒有攝影機運動）。編譯時會先測量抖動（vidstab）。生成後，畫布會顯示穩定預覽（狀態顯示在控制項旁）；如果 ffmpeg 中沒有 vidstab，則使用 deshake，畫布顯示原始畫面。
  • ⇄ XML 會按 Final Cut 7 及其他編輯軟體的方式寫入加速 / 減速片段的入點 / 出點（按速度調整後的幀）——已用 OpenTimelineIO 的讀取器驗證；舊版 bitGen XML 仍可匯入。
  • 🅰 文字預設除了保留倒角的光澤等高線外，還會保留其輪廓等高線。2.411 內建的兩個預設是在此之前製作的——重新匯入它們的 PSD（＋ Import a PSD text effect…）即可獲得精確的輪廓。

✅ 巢狀序列、更完整的 XML、FCPXML、整個序列的轉錄（2.414.0）

  • ⧉ Nest（巢狀；選單列）：選擇另一個命名時間軸——它會被編譯成一個片段，放在位置標記處名為 "⧉ name" 的新圖層上，此後就是一個普通片段（可修剪、移動、調色、再次巢狀）。當該時間軸再次儲存時，片段的標記會變為 ↻ out of date：其 Properties 中有 ↻ Re-render（位置和修剪不變）和 ⧉ Open（切換到該時間軸）。時間軸不能巢狀到自身中，也不能巢狀到它已包含的時間軸中。
  • ⇄ XML 現在會攜帶位置 / 縮放 / 旋轉（Basic Motion）、不透明度和音量及其 ◆ 關鍵幀、💬 字幕（作為文字標題）以及調色：每個調過色的片段的調色效果會烘焙成匯出檔案旁的一個 .cube（exports/<name>_luts/），並在片段註釋中註明——在其他編輯軟體（Lumetri → Basic → Input LUT）、Resolve 或 Final Cut（Custom LUT）中將其作為片段的輸入 LUT 使用。bitGen 能精確讀回自己的調色。
  • ⇄ FCPXML 1.10（Final Cut Pro X）匯出和匯入：V1 = 主要故事情節，其他圖層 = 上方的連線通道，聲音圖層在下方；包括速度、移動、關鍵幀、標記、字幕和起始時間碼。
  • 📝 Transcript scope（轉錄範圍）：this clip、its whole layer 或 the whole sequence（V1、影片圖層和 🗣 voice 聲音圖層合為一段文字，按播放順序排列）。剪下會從說出這些詞的那個片段中切掉；對整個序列而言，其後的每個圖層也會一起前移。↺ 可復原。

✅ 軌道混音器、扭曲效果、轉場庫、顏色匹配（2.415.0）

  • 🎚 Mixer（混音器；選單列）：每條軌道（V1、每個影片圖層、每個聲音圖層）一個通道條，外加 master（主輸出）——最高 +6 dB 的推子、pan（聲像）、Mute / Solo，以及畫布播放時即時顯示的左 / 右電平表（−60 .. +6 dBFS；白色刻度保持峰值，紅色 = 超過 0 dB）。雙擊：恢復 0 dB / 居中。影片的聲像和混音方式與此相同。
  • ✨ Distort（扭曲；片段的 Effects）：lens（鏡頭：桶形 / 枕形）、mirror（鏡像：左 → 右、上 → 下、四向）、warp（變形：可調大小和速度的 wave，以及 twirl）。畫布和影片取樣的是完全相同的點。
  • 轉場：59 種——ffmpeg 提供的全部轉場（向四角擦除、柔和擦除、覆蓋、揭示、擠壓、光圈、開門、切片、風吹、縮放）。影片或圖片圖層的入場 / 出場會在畫布和影片中按其形狀繪製；溶解仍為溶解。
  • 🎨 🎯 Match（匹配）：選擇另一個片段——會設定本片段的 R / G / B 曲線，使其色調與該片段在影片中顯示的畫面相匹配。之後可微調曲線，或將其重設。

✅ 遮罩 + 追蹤、多機位、代理（2.416.0）

  • 🎨 ◯ Mask（遮罩；Colour 面板）：一個橢圓或方框，可設中心、大小、旋轉、feather（羽化）和 invert（反轉）——調色及其後的效果只作用於其內部（或外部）。面板開啟時，其輪廓會顯示在畫布上；調整圖層也有遮罩。
  • 🎯 Track（追蹤）：將位置標記放在遮罩位置正確的地方，🎯 會讓它跟隨該物體直到片段結尾——畫布和影片中均如此。跟丟（物體離開畫面）= 遮罩停在該處並給出提示。✕ track 刪除追蹤；移動已追蹤的遮罩會移動其整條路徑。
  • 🎥 Multi-camera（多機位）：在時間軸上勾選各機位（第一個 = 參考機位），選擇播放哪個機位的聲音，點 ⇆ Sync by sound。V1 成為節目軌：播放時按 1 - 9（或點選某個機位）即可即時切換；⇲ Flatten 將切換結果保留為片段。
  • 🪶 Proxies（代理）：會列出負載較重的片段（寬度超過 1920、HEVC / ProRes / DNx、位元速率超過 40 Mbit/s）——為它們生成 960 寬的代理，並勾選 play proxies on the canvas。影片始終使用原始素材。

✅ HDR、AAF、倒放片段的聲音、動態圖形範本（2.417.0）

  • 📤 HDR：10 位預設有一個 colour（顏色）選項——SDR、HDR10（PQ、BT.2020 + HDR10 後設資料）、HLG 或 Rec.2020 SDR。母版的白色位於 203 尼特，因此看起來與調色時一致。HDR pack 會同時新增兩者。時間軸上的 HDR 片段會經過色調對應後進入影片。

  • 🔊 倒放或變速的片段在畫布上也能聽到：其聲音會按影片的變速渲染一次，並同步播放。
  • 🧩 Motion graphics templates（動態圖形範本）：選擇一個，填寫其中的文字，點 ⤓ Insert at the playhead——自動適配畫面尺寸，保留移動和關鍵幀。內建 4 個；💾 Save as a template 會將勾選的圖片 / 文字圖層儲存下來，供所有專案使用。

✅ 即時播放：渲染條、⚡ Render、⏱、播放解析度（2.418.0）
