📏 Sketcher

用最快捷的方式进行 3D 建模：在地面或某个面上画一个形状，然后把它推或拉成实体。尺寸可以随时输入到 Measurements（测量）框（右下角）——无需点击该框，直接输入并按 Enter 即可。

工具（字母即快捷键，指针需位于面板上方）

  • 双击空白处（没有进行中的操作时）——取消所有选择，工具切换为 🔄 Orbit（环绕）；按 Space 返回 Select。
  • Space ➤ Select（指针）——已选中的对象以强调色着色，指针下方的对象显示为蓝色（2.650.0——平面图中同样如此）；点击只选中一个对象（一个面、一条线、一个房间、一扇门、一件家具……）；Ctrl+点击可添加更多对象（Ctrl+点击已选中的部分则将其移出选择）——拖动其中任意一个，它们会一起移动，按 Delete 则全部删除；Shift+点击可添加/移出面和线，Ctrl+A 全选。点击组中的一个面会选中整个组；双击组可进入组内编辑（其余部分变暗），按 Esc 退出。按 Delete 删除所选内容。
  • 用 Select 编辑（2.625.0）：
    • 面：面板显示 Extrude（挤出；+ 为向外，− 为向内 = 在物体上切割）和 Twist（扭转）。拖动该面即可用指针挤出它，与 Blender 类似；Ctrl+拖动使其绕法线旋转——刚挤出的面会相应扭转其挤出部分。输入距离（Measurements）可修改上一次挤出。
    • 边：拖动即可移动（Shift：沿单一轴向）。Shift+点击可选择更多边；Ctrl+点击可选择其所在面一周的所有边（边环）。面板：Length（长度）、Extrude edge（挤出边；由它生成一个新面——向上、从其所在面向外、沿红轴或绿轴）和 Fillet（圆角；半径和分段数——将两个面之间的边倒圆）。
    • 角点（顶点）：点击并拖动（Shift：沿单一轴向；会吸附到另一个角点上），或输入其 X / Y / Z 坐标。被弯折而不再平整的面会被拆分为三角形。
  • L ╱ Line（直线）——点击、点击……闭合的平面环会成为一个面。从面的一条边界画到另一条边界的直线会将该面分割为两半（然后可推/拉其中一半）。
  • R ▭ Rectangle（矩形）——两个对角点。在某个面上开始绘制时，矩形位于该面内。输入 3,2 表示 3 m × 2 m。
  • C ◯ Circle（圆）/ N ⬠ Polygon（多边形）——先定圆心，再定半径。可输入半径，或输入 36s 表示 36 条边。
  • P ⇧ Push/Pull（推/拉）——点击一个面，移动，再点击（或直接拖动）。可输入距离。单独的面会变成实体；拉动盒子顶面会让盒子变高；在面上画出的形状可向内推成凹槽，或向外拉成凸台；把凹槽底面推到另一侧即可形成通孔。推/拉刚结束时，输入新的距离即可修改。双击一个面 = 再次使用上一次的距离。
  • M ✥ Move（移动）——选中对象（或在其上按下），点击一个基点，再点击目标位置。按住 Ctrl = 复制。可输入距离，或输入 x,y,z。
  • Q ⟳ Rotate（旋转）——先选中，然后依次点击中心、起点和终点（绕竖直轴，步长 15°）。可输入角度。
  • S ⤡ Scale（缩放）——选中后点击一个点，然后远离/靠近中心移动。可输入缩放系数。
  • F ⧈ Offset（偏移）——点击一个面并在面内移动：得到一个向内偏移相应距离的环。偏移地板后把这个环向上拉 = 墙。
  • T 📏 Tape（卷尺）——两个点：显示它们之间的距离（以及在各轴向上的距离）。
  • B 🪣 Paint（油漆桶）——点击面进行上色（若为组：整个组）。Alt+点击可吸取某个面的颜色。颜色位于底部。
  • E ⌫ Eraser（橡皮擦）——点击或拖过线和面。删除与面相邻的线时，这些面会一并删除。
  • O 🔄 Orbit（环绕；指针为环绕光标）、H ✋ Pan（平移）——在任何工具下，中键环绕，右键平移，滚轮缩放（朝向指针位置）。Shift+Z = 全部显示。

建筑——房间、墙、门、窗、屋顶、灯光

建模工具下方的 Build（建筑）工具用于绘制始终可编辑的建筑：房间保留各自的墙、地板和天花板，房间移动时，门、窗和灯光会保持在房间中的原有位置。

  • U ⌂ Room（房间）——两个对角点（或输入 4,3——宽度、长度）：生成墙、地板和天花板。设置面板中的 Width（宽度）和 Length（长度）后，点击一次即可放置该尺寸的房间（0 = 用两个角点绘制）。选中房间的面板中同样有 Width 和 Length。房间角点会吸附到其他房间的角点和墙的中点。右侧面板用于设置下一个房间的墙高、墙厚、地板标高和天花板，以及 Offset from floor edge（距地板边缘的偏移）：沿地板（J）边缘绘制的房间或墙，其墙外侧面会从边缘向内缩进该距离（0 = 正好在边缘上）。
  • W ▮ Wall（墙）——点击、点击……绘制独立墙体。再次点击起点即可闭合成一个房间。双击或按 Esc 结束。可输入下一段的长度。
  • D 🚪 Door（门）——在墙上点击：单开门、双开门、玻璃推拉门、玻璃门或无门洞口。门的中点会吸附到墙的中点。输入 0.9,2.1 设置宽度和高度。
  • I 🪟 Window（窗）——在墙上点击：单扇、双扇或推拉窗，并设置 Elevation (height from floor)（离地高度）。输入 1.2,1.2。
  • J ▦ Floor（地板）——两个角点：一块没有墙的地板（木平台、庭院、某一楼层的楼板），高度和厚度按面板中的设置。
  • K ⌓ Ceiling（天花板）——点击一个房间：开启或关闭其天花板。房间面板中有 Ceiling：None、Flat（平顶，高度取墙顶的最低处）或 Follows the walls' slope（随墙坡度，在双坡山墙或单坡顶下向上倾斜）。
  • Y △ Roof（屋顶）——点击一个房间：为其加盖屋顶（双坡、四坡、单坡、平顶或 Follows the walls' slope——屋顶坐落在墙的倾斜顶部上；坡度和挑檐，或 Eaves width（檐口宽度），在面板中设置）。Shift+点击更多房间可将它们置于同一屋顶下，或使用 Roof the whole storey（为整层加盖屋顶）。可输入以度为单位的坡度。
  • X 💡 Light（灯光）——在面板中选择类型：downlight（嵌入式筒灯）、ceiling-mounted（吸顶灯）、pendant（吊灯）、chandelier（枝形吊灯）、spot（射灯）、wall light（壁灯）、floor lamp（落地灯）、table lamp（台灯）；以及颜色（暖白到冷白）和以流明为单位的亮度。点击会将灯放在指针下方房间的天花板上（会吸附到房间中心）；壁灯则安装在指针所指的墙上。
  • Photo style（照片风格，2.696.0）——✨ Photo 左侧的下拉列表：Sketcher 生成照片时使用的图像编辑风格（独立设置——提示词面板保持其自身的风格）；会保留上次使用的选项。
  • 屋面材料（2.695.0）——屋顶的 Covering（屋面）：预涂彩钢板（波纹板、肋形板、直立锁边板）、混凝土/陶土瓦、石板瓦、沥青瓦或聚碳酸酯板——在屋顶上显示其颜色和纹理；坡度低于其常规最小值时显示 ⚠（请以厂商资料为准）；其重量计入框架校核。
  • 🪵 Roof framing（屋顶框架，2.694.0）——选中屋顶 ▸ Roof framing：Rafters（椽子：截面尺寸、等级、间距、下檩条规则、天花搁栅及其支撑间隔；✔ / ✗ + ✔ Size them）或 Trusses（桁架：按间距布置）。用 🪵 Show framing（显示框架）绘制（屋顶变为透视显示）。
  • 🪵 Wall framing（墙体框架，2.693.0）——选中房间 ▸ Wall framing：Timber（木材）或 Light-gauge steel（轻钢），立柱尺寸/等级/间距、顶梁板、横撑排数、拉带斜撑、Frame this room's walls。立柱、梁板、门窗边立柱 + 短立柱、窗台横梁、横撑和角柱用 🪵 Show framing 绘制；房间的合计数量显示在面板中。立柱尺寸不做校核（AS 1684 的立柱表）。
  • 🏗 Floor systems + 🪵 lintels（楼地面系统 + 过梁，2.692.0）——选中一个房间：Floor system = 地基板、华夫格模壳板、加劲筏板、墩柱支撑悬空楼板或架空木地板（短桩、托梁、搁栅——尺寸、等级、间距；✔ / ✗ 校核，✔ Size them）。外墙上的门/窗：其 Lintel（过梁；Auto 或手动选择）。🪵 Show framing = 墙体透视显示。仅供参考——请核对 AS 1684 / 跨度表；楼板须由你的结构工程师负责（AS 2870）。
  • ⊣ Walls butt up（墙体对接，2.691.0）——新墙的端部会止于它所碰到的墙：端对端相接时，旧墙的端部会被修整以绕过转角（形成一个干净的转角）；落在某面墙的轴线上时（横穿房间的墙），新墙会被截到该墙的墙面处。Wall thickness（墙厚）会记住你上次设置的值（在工具、选中的墙或房间中设置）；大于 2 = 毫米（200 = 0.2 m）。
  • ⊕ Joined walls（连接墙，2.690.0）——使用 ▮ Wall 时，靠近另一面墙端部/转角的点会被吸附到其上（提示显示 ⊕ joined；按住 Shift = 自由放置）。在此相连的墙会保持连接：拖动其中一面，另一面的端部会跟随——墙随之伸长或缩短。
  • 🗄 Cupboards & shelving（橱柜与搁架，2.689.0）——🛋 Furniture ▸ Category Cupboards & shelving：嵌入式衣柜、步入式衣帽间（L 形/U 形）、布草柜/食品储藏柜/杂物柜、书架、搁架。🗄 Design / change… 打开其对话框（布局、尺寸、分格——挂衣、双层挂衣、层板、抽屉、鞋架——、柜门、拉手、颜色；实时正视图 + 平面图）；💾 Save as template 将你的设计保存下来，供所有项目使用（在列表中标为 ★）。在房间内点击 = 柜体背面靠向最近的墙，正面朝内；选中后：✎ Design…、↔ Fit the wall。
  • A 🛋 Furniture（家具，2.628.0）——家具库：选择 Category（类别：Living、Dining、Kitchen、Bedroom、Bathroom、Lights、Outside）和一件家具，在地板上点击即可放置（它会立在房间地板上）。R 将下一件旋转 90°，也可输入角度。使用 Select 时：可拖动它，按 R 旋转；其面板包含尺寸、转角、离地高度、颜色、⧉ Duplicate 和 🗑 Delete。3D models 类别列出项目中的 3D 模型（.glb / .obj——SolidCraft 生成的或导入的）：点击一次即可将其作为组导入。
  • Z 📷 Camera（摄像机，2.629.0）——点击摄像机所在位置，再点击它的朝向（视点高度和镜头在面板中设置）。选中后：👁 Look through（通过摄像机观察）、📷 Shot + depth + normal（三张图片存入项目的 Image 素材，其中拍摄图带照片效果）和 📍 360° location（从该处生成的全景图成为一个 Location——带有其 @tag，即提示词中的地点）。Select 可拖动它；其面板可设置转向、俯仰和名称。
  • V ▟ Stairs（楼梯）——点击楼梯底部，然后确定方向和长度（或直接输入）。高度和宽度在面板中设置。

材质（2.629.0）：颜色旁的 ▦ Materials ▾ 中有各种材质——砖、石材、混凝土、橡木和胡桃木地板、瓷砖、大理石、地毯、草地……均带纹理。选择一种后，用它为面、墙和地板上色（B）。房间面板中的 🪄 Furnish（布置家具）会为房间摆满家具（若有 LLM 在运行，则由 LLM 从家具库中挑选，否则使用该类房间的常规家具组合；输入 "a reading corner" 之类的描述会有帮助）；Ctrl+Z 可撤销。

房间共用墙。使用 Select 时，在一个房间上按下并拖动：当它的某面墙靠近另一房间的墙时，会吸附上去，两个房间之间便只有一面墙。这面墙上的门或窗会贯穿整面墙。角点也会对齐。按住 Shift 可保持直线拖动。

地板上的墙。使用 Select 时，在房间的某一面墙上按下并拖动：墙会沿垂直于自身的方向移动，房间随之拉伸。拖动过程中，地板边缘的吸附区域以橙色显示；在其中松开，墙的外侧面就会落在边缘上（并计入 Offset from floor edge）。拖动的房间也会以同样方式吸附到地板边缘。Shift = 不吸附。

斜墙。双击墙的顶部 = 在该处添加一个断点。上下拖动断点：墙顶会从两端角点向它倾斜（形成山墙端）。点击一条顶边（位于断点或角点之间）并拖动——或在面板中输入其两端的高度——即可使墙倾斜；移动一个角点时，相邻的墙会随之一起变化。选中断点或边后按 Delete 即可将其删除（墙恢复为水平/平直）。从正上方（Top 视图）按下则改为移动该墙。

手动调整门窗。点击已放置的门或窗：其两侧、顶部和底部（门除外）会显示小方块（夹点）。拖动侧边夹点调整宽度，拖动顶部夹点调整高度，拖动底部夹点调整离地高度。也可将窗户本身沿墙拖动或上下拖动。

开启门窗（2.631.0）：选中的门或窗有 Open (%)（开启百分比）——门扇向室内转动（勾选 Opens outward 则向外开），窗扇向外推开（勾选 Opens inward 则向内开），推拉窗则滑动一扇玻璃（The other pane slides 改为另一扇滑动）。Auto roof 和 Auto floor（Room 工具的面板中）会为每个新房间自动加上屋顶，以及墙下方一块 20 cm 的楼板；房间面板中有 Floor slab under the walls 和 Roof，可为该房间单独开关。View ▾ 列出所有摄像机（📷）——选择一个即可从该摄像机视角查看（环绕即可退出）。

摄像机（2.632.0）绘制在所有对象之上，因此房间内的摄像机可直接点击选中（而不会选中房间）。拖动即可移动；R 将其旋转 15°（Shift+R 反向旋转）。按 Esc 或双击空白处可取消所有选择——Esc 同时会退出当前工具，切换到 🔄 Orbit（2.647.0）。

🗂 Outline（大纲，2.639.0，工具栏上的 🗂 Outline 可显示/隐藏它，位于视图左侧）：建筑中的每个对象——Room groups（房间组）、Rooms ▸ Room 1 ▸ Wall 1 … Wall n、Floor 1、Ceiling 1、Skirting 1、Cornice 1、Floor slab 1、Door 1、Window 1 ……，然后是独立的 Walls、Roofs、Floors、Stairs、Lights、Furniture 和 Cameras。点击某一行即可选中；👁 隐藏/显示该对象（Ctrl+Z 可撤销，状态随模型一起保存）。＋ 新建房间组，房间上的 ⊞ 将其放入（或移出）组，组的 👁 隐藏/显示其所有房间，✎ 重命名，✕ 删除该组（其中的房间保留）。新房间自带踢脚线和顶角线（房间面板：Skirting / 高度、Cornice / 尺寸，以及它们的颜色）。拖动墙：墙沿垂直于自身轴线的方向移动——相邻的墙随之拉长或缩短，地板、天花板、踢脚线和顶角线也会跟随；Alt+拖动可自由移动；Shift+点击选中整个房间（随后拖动即可移动房间）。

各部件的独立面板（2.640.0）：点击墙、地板、天花板、踢脚线或顶角线（在视图中或其 🗂 Outline 行中），面板就只显示该部件——墙：Length（长度；矩形房间会保持其形状）、Height（高度，仅此墙）、Thickness（厚度）、其独立的 Inside 颜色、👁；地板：On、Colour、Level、楼板；天花板：None / Flat / Follows the walls、Colour、Height；踢脚线 / 顶角线：On、Profile、Height / Size、Colour。⌂ 返回房间设置；对部件按 Delete 会将其关闭（墙被隐藏）——房间保留。

轮廓（2.640.0）：踢脚线、顶角线、门框、窗框和窗台都从一个图片下拉列表中选取轮廓（每项以其截面图显示）：先是内置轮廓，然后是项目自有的轮廓。踢脚线沿房间四周布置，转角处斜接，并在门框处断开；门框（门套线）环绕门的两面，窗框环绕窗的室内一侧，窗台位于窗下。✎ Profiles… 用于绘制你自己的轮廓：点击 = 在最近的边上添加一个点，拖动 = 移动该点，Delete / 右键点击 = 删除该点（1 mm 网格，Shift = 自由），Width / Height 可缩放轮廓，＋ New 复制当前显示的轮廓，💾 Save 将其保存在项目中。

旋转环（2.633.0）：选中的摄像机或家具会显示三个环——蓝色环使其转向（偏航），红色环使其俯仰，绿色环使其翻滚。沿环拖动即可按 5° 步长旋转（按住 Shift 可自由旋转）；Ctrl+Z 可撤销。也可在面板中输入相应数值：摄像机的 Turn (yaw)、Tilt (pitch) 和 Roll；家具的 Turn (yaw)、Pitch 和 Roll。摄像机的 Lens（镜头）可选择预设——Fisheye (8 mm)、Ultra wide (14 mm)、Wide angle (24 mm)、35 mm、50 mm (normal)、85 mm (portrait)、135 mm、200 mm (telephoto)——或输入 Focal length（焦距，mm，全画幅）或 Field of view（视野，°）：两者相互联动。鱼眼提供最宽的视野，但不会绘制鱼眼畸变曲线本身。Zoom extents（缩放至全部）也会把摄像机纳入视野。

选中摄像机（2.641.0）：点击摄像机即可选中——它会高亮显示（周围没有选框）并显示移动箭头（红色 X、绿色 Y、蓝色 Z）。拖动摄像机可在其当前高度上移动，拖动某个箭头则只沿该轴移动（蓝色 = 上/下；步长 1 cm，Shift = 自由）。双击摄像机显示旋转环（转向/俯仰/翻滚），再次双击切换回箭头（或使用其面板中的 ✥ Move / ⟳ Rotate）。点击任何其他对象则改为选中该对象。通过摄像机观察（2.643.0，👁 Look through）：其面板中的 ✥ Move / ⟳ Rotate 会在你面前显示控件——拖动它，摄像机和视图会一起移动或旋转。Esc 取消选择摄像机。

可将门或窗沿其所在墙拖动（或拖到另一面墙上）；也可拖动灯、楼梯或地板。点击任何建筑构件，面板就会显示其设置——房间的尺寸、墙高和墙厚、内墙面、地板和天花板的颜色，以及所有外墙的颜色；⟳ 90°、⧉ Duplicate（在旁边生成一个共用墙的副本）、△ Roof。Delete 删除所选内容；E Eraser 点击即可删除；B Paint 可为房间的墙、地板、天花板、门或屋顶上色。

🌙 Night（夜间）会调暗太阳和天空，让灯光照亮房间（白天灯光是关闭的——这里的灯光会穿透墙壁，因此白天它也会照亮室外）。⌂ Cut-away（剖切）隐藏所有屋顶和天花板，以便从上方查看室内。

推断——指针吸附的位置

  • 标记及其文字表示该点所在的位置：Endpoint（端点）、Midpoint（中点）、Origin（原点）、On Edge（在边上）、On Face（在面上）、On Ground（在地面上）。
  • 从上一个点起，当你处于红/绿/蓝轴上时会显示一条虚线。按住 Shift 可锁定该轴，或按 → 锁定红轴、← 锁定绿轴、↑ 锁定蓝轴（↓ 解除锁定）。
  • 推/拉会吸附到指针所在的角点、边或另一个面的高度。
  • 长度可输入为 1.5（m）、150cm、1500mm、5'、10"。

工具栏

  • ☰ File ▾（文件）——New、Open、Save（Ctrl+S）、Save as、Rename，导入项目中的 3D 模型或本机文件（.pp3d、.glb、.gltf、.obj），Export，发送到图像编辑器/时间线/其他位置，Delete、Maximize、Close。
  • 名称和 💾——模型保存在项目中，每次更改后片刻即自动保存。↶ ↷（Ctrl+Z / Ctrl+Y）。
  • 📐 Plan（平面图；或 View ▾ 📐 Floorplan）——平面图：以应用的主题色垂直俯视显示（2.649.0），一次显示一层（用列表选择楼层）。墙以实心剖切显示，门带门扇和开启弧线，窗带玻璃和窗台，楼梯显示每级踏步和 UP 标记，家具显示轮廓和名称，灯光显示为圆圈加十字，并标注每个房间的名称、宽 × 长和面积。所有工具都可以像在 3D 中一样在平面图上绘制；点击可选中符号；Orbit 会旋转平面图（保持平面）。再次点击 📐 或切换到其他视图：返回 3D 视图。
  • 材质（2.651.0）：墙的面板有 Inside（内侧）和 Outside（外侧），窗有 Frame（窗框）和 Glass（玻璃），地板、天花板、踢脚线、顶角线、屋顶和楼梯也各有自己的选项——每一项都会打开材质选择器：一种颜色、一种内置材质，或一张图片（来自 🖼 Refs 面板、项目图片或文件；保存在项目中；Size = 一张图覆盖的米数，Turn ° = 旋转角度）。油漆桶只为你点击的那一侧墙面上色（Shift+点击：该侧的所有墙）。
  • ⛰ Terrain（地形，2.653.0，Alt+G——G 是 Group）：地面。第一次点击会在建筑周围生成一块地面（略低于其最低楼层）。在其面板中选择按下时执行的操作：⬆ Raise（抬高）/ ⬇ Lower（降低）（拖动；按住 Shift 反向）、≈ Smooth（平滑）、▬ Flatten（压平；Alt+点击吸取高度）——Brush size（笔刷大小）、Strength（强度）、[ / ]；〰 Contour（等高线）：输入或设置 Elevation（高程），点击、点击……（回到起点即闭合，双击/Enter 结束）——地面会按这些线塑形（每条线保持其高度，线之间平滑过渡）；点击一条线即可选中（其高程、是否闭合、Delete）。此外还有 🖼 Heightmap picture…（高度图；黑 = Lowest，白 = Highest，图片上方 = 北）、⌂ Level under the rooms（在房间下方找平，在边距范围内平滑过渡）、⊙ Centre on the building（以建筑为中心）、Width / Length / Detail、Material、等高线间距、土方侧面、▬ Flatten all（全部压平）、🗑 Remove the ground（移除地面）。📐 平面图会绘制其等高线。
  • ✂ Cut / fill（挖填方，2.656.0，位于 ⛰ Terrain 中）：在地面上点击场地平台的各个角点，回到第一个点（或双击/Enter）结束——平台内部在其标高处找平（取地面平均标高，或手动输入），以 1 : n 的放坡回接到原地面，可选挖填方/仅挖方/仅填方；挖方和填方量以 m³ 显示。点击平台即可选中（标高、放坡、⟳ Apply again、🗑 Forget / Delete = 删除其轮廓，保留地面）。
  • 🏊 Pool（泳池，2.657.0，位于 Ground 下）：两个角点（或输入 8,4）——或选择 Shape: Free shape，点出其各个角点。可设置浅水端/深水端、池边瓷砖、木平台或两者兼有、标高；在 ⛰ 地面上时会切入地面，并将周围地面找平。➤ Select 选中它：尺寸、深度、⇄ 深水端、池边、材质、内衬、水、Delete。
  • 🛣 Driveway（车道，2.659.0，位于 Ground 下）：沿路线点击各点，双击/Enter 结束。其节点（□）和控制柄（○）会显示出来：拖动控制柄可弯曲曲线（Alt：仅一侧），拖动节点可移动它，Delete 删除所点击的节点。➤ Select 选中它：宽度、路面、路缘石、贴地/位于某一标高、〰 Smooth、Delete。
  • 移除单面墙 / 内墙或外墙（2.660.0）：在墙上使用 ⌫ Eraser（或按 Delete，或在其面板中点击 🗑 Take this wall out）只移除这一面墙——地板和天花板保留；共用墙会从两个房间中同时移除。Shift+Eraser = 整个房间；房间的 ↺ Put back 可将其恢复。墙的面板：Interior / exterior（Auto：两侧都有房间 = 内墙）——内墙的外侧面使用其内侧颜色；平面图中内墙的填充色较浅。
  • 🧱 Wall types（墙体类型，2.661.0，位于工具栏中）：模型的墙体类型及其由外到内的构造层（砖、空气层、框架 + 保温棉、保温层、石膏板、抹灰、外挂板……）——可修改某层的种类/厚度，↑ ↓ ✕，＋ Add a layer；各层总厚度即墙厚。Use it for（应用于）选中的墙、房间的墙、所有外墙/内墙。墙体按该厚度构建，并以最外层着色；各层接缝显示在墙顶和平面图上。墙的面板：Wall type。
  • 方形墙端 + 从转角拉出墙（2.662.0）：每面墙的端部都是方正的；其转角和自由端是独立的构件。➤ Select：将指针指向外转角或墙端——它会高亮——然后从它的某一侧向外拖动：即朝该方向生成一面新墙（从顶部拖动、从上方看时：任意方向），高度/厚度与原墙相同，并沿用其墙体类型。
  • 分割墙 + 草图平面（2.663.0）：双击墙（从上方、在平面图中或在 3D 中双击其墙面）即可将其分割；每一段都可以单独选中、删除或向外拖出（新墙会将其与房间连接）。Wall 工具可在房间墙体的任意位置捕捉到它。点击转角/墙端：设置其 Width（墩柱）和超出端部的 Length。用 Select 点击的面即为草图平面（Line / Rectangle / Circle / Polygon 在其中绘制；✕ / Esc 结束；2.687.0：不再在其上绘制网格）；⊥ Look at 使视图正对它。2.688.0：点击墙的端部构件 = 选中整面墙；双击它 = 沿墙推/拉墙的端部；Ctrl+拖动 = 保持水平/竖直；✨ Photo 只会提及模型中实际包含的内容。
  • 🛤 Road（道路，2.673.0）：Ground ▸ 🛤 Road——选择 Dirt road、Street、Road、One-way、Avenue 或 Highway，沿路线点击，双击/Enter 结束。道路会贴合地面；若对该道路类型而言过陡：在面板中使用 ⛏ Cut the ground 或 🚇 Tunnel / bridge。路口会自动生成红绿灯、停车/让行标志、人行横道和路名牌。Alt+点击道路可拖动其节点。
  • 天沟轮廓（2.671.0）：选中屋顶——Gutters 列出 Quad、Half round、OG 和 Square line；Gutter profile 以图片形式显示它们（以及你自己的轮廓）；✎ Gutter profiles… 打开天沟的轮廓编辑器（左侧为封檐板）——像踢脚线一样用节点和曲线绘制，💾 Save 后屋顶的天沟就会使用它。
  • 贝塞尔轮廓（2.670.0）：在 ✎ New / edit profiles… 中，弧线是带两个节点的曲线；点击节点或线段即可选中，可拖动节点和曲线的控制柄，双击线段可添加节点，右键点击可选择 Convert to curve / Convert to line / Delete node。
  • 檐口、封檐板、天沟（2.668.0）：Roof 面板中的檐口图片——Simple（简单）、Open（外露椽尾）、Boxed（平底檐口板）、Closed（沿坡面封板）；Fascia + barge boards（封檐板 + 山墙封檐板，可设高度）；Gutters quad / half round，带 Downpipes（落水管）；选中屋顶的封檐板/檐底板和天沟颜色。
  • 🗂 Objects panel（对象面板，2.667.0）：Shapes（形状）——你绘制的每个形状（点击即可选中，拖动某个面可推/拉它——组的面也可以）；Construction（辅助）——Planes（平面：📌 保留草图平面，＋ ground / front / side；点击某个平面可再次在其中绘制，⊥ 使视图正对它）和 Construction lines（辅助线：使用 📏 Tape measure 时在第二次点击时按住 Ctrl——各工具会吸附到辅助线上）；双击任意行的名称（或按 F2）可重命名。
  • △ Roof types（屋顶类型，2.666.0）：Roof 面板以图片显示每种类型——双坡、四坡、单坡（skillion）、荷兰式山墙（Dutch gable）、截角山墙、复折式（gambrel）、孟莎式（mansard）、盐盒式（saltbox）、金字塔式、蝶形、平顶、随墙——每种都有各自的设置（坡度、下段坡度、折点、屋脊位置、用 Flip 切换高侧）。
  • 📄 Building plans（建筑图纸，2.665.0）：工具栏上的 📄 Plans——每层一张平面图、四个立面图以及屋顶/总平面图，按比例输出到 A4 - A1，可全部放在一张图纸上，或每页一个视图；尺寸以 mm 标注，并含标高、房间名称/面积和图签。💾 Save PDF 会将其保存到项目的 pdf 文件夹（以及你的下载文件夹）。
  • 🧍 Mannequin model（人台模型，2.664.0）：🛋 Furniture ▸ People ▸ mannequin (model)——一个经过建模的女性人台，高度与人物相同（作者 dimasalcalde 和 zahers，来自 CGTrader——见 Settings ▸ About）。其文件以单独的 zip 提供；没有该文件时会绘制站立的人形。
  • ✨ Photo（照片，2.652.0）：生成当前视图的真实照片——编辑模型会收到干净的渲染图、其深度图，以及一张标注了你的材质图片和背景图片的拼板（并附加提示词框中的文字）；照片会存入项目图片，若图像编辑器已打开也会发送到其中。能接收两张图片的模型则会收到不含拼板的输入。
  • 🖼 Background（背景）：模型后面的一张背景图（填满视图，不会被拉伸），或围绕场景的一张 360° 天空全景图（可旋转）——或者不使用（采用主题背景）。
  • Esc——无工具、无选择、🔄 Orbit——适用于 3D 视图、平面图和摄像机视图（正在绘制的墙会保留）。在 Orbit 中，Esc = ➤ Select。Esc 永远不会让最大化的 Sketcher 停靠回去（⇲ Dock 才会）。
  • 缩放：Shift + 右键拖动——向前（向上）放大，向后（向下）缩小，以按下的点为中心（平面图中同样适用；滚轮用法不变）。⊡（位于 ⤢ 旁边）缩放到所选内容——面、房间、墙、门、家具、摄像机……；未选中任何内容 = 显示全部。
  • View ▾ Iso / Top / Front / Right / Back / Left、Persp / Parallel（透视/平行）、⤢ 全部显示、面样式（着色 + 边线、着色、单色、X 光、线框）、☀ 阴影。
  • ▣ Group（G）将所选内容编组；选中组时则将其炸开（解组）。
  • 🌙 Night 和 ⌂ Cut-away（见“建筑”部分）。
  • 🖼 → Image editor——按你所见（白天或夜间）生成视图图片。🎞 → Timeline——将模型作为 3D 图层发送。
  • ➜ Send ▾：将视图图片发送到图像编辑器（可带或不带背景），作为时间线上的 3D 图层发送（再次发送时其图层会更新），或发送到 Blender、Unreal。
  • ⤓ Export ▾：导出 .glb（可带或不带灯光——glTF 灯光，Blender 和 Unreal 可导入）或 .obj 到项目的 3D 模型中；导出 .glb、.obj 或 .stl（毫米单位，用于 3D 打印）到本机。⤒ Import ▾：将项目中的 3D 模型作为组导入。

⛶ Maximize（最大化，位于其标题栏）会让面板填满整个 bitGen 窗口中标题栏与状态栏之间的区域（两者均保留）；此时按钮变为 ⇲ Dock（停靠）——点击它或按 Esc（没有其他进行中的操作时）即可恢复。旁边的 ✕ 关闭面板。最大化期间其他所有面板都会关闭；⇲ Dock 会重新打开原先那些面板（2.628.0）。面板使用 bitGen 的主题色（其 3D 视图的背景、网格和选区也是如此）。
