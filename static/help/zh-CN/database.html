🗄 数据库

用于一个项目、所有项目或你自己服务器上的 MySQL / MariaDB 数据库——根据你的描述，由 AI 设计表、字段和视图。顶部栏的 🗄 按钮可打开和关闭此停靠栏。

存放位置

  • 📁 此项目——bitGen 为项目运行自己的 MariaDB 服务器，数据位于项目的 db 文件夹中，随项目一起移动。
  • 🌐 全局——所有项目共用一个 MariaDB 服务器，数据位于应用的 db 文件夹中。
  • 🖧 你的服务器——任何 MySQL 或 MariaDB 服务器（⚙ 你的服务器…：主机、端口、用户、密码、数据库）。密码在本机加密保存。

bitGen 自己的服务器只在本机（127.0.0.1）监听，需要时自动启动（也可手动 ▶ / ⏹），bitGen 关闭时停止。首次需要 MariaDB 本身：本机没有时会弹出下载 / 取消框（MariaDB，GPL-2.0，来自 archive.mariadb.org，放入应用的 mariadb 文件夹）。在 Mac 上请用 Homebrew 安装（brew install mariadb）——bitGen 会找到它。

✨ 设计——由 AI 建表

  • 描述用途：“一家小店：客户、有库存的商品、带明细的订单，以及按月销售额和最佳客户的视图”。
  • ✨ 设计表：提示词停靠栏的 LLM 编写 SQL——带字段和类型的表、键、表之间的关联、索引和视图。它能看到已有的表，所以之后可以继续要求（“添加供应商”）。
  • 先显示 SQL。阅读、按需修改，然后 ▶ 运行。逐条运行，遇到第一个错误即停止。设计永远不会删除表或数据。
  • 也可以在提示词停靠栏说：“为我的店创建一个包含客户和订单的数据库”——停靠栏会打开并带有设计。

表、数据和 SQL

  • 左侧：表（▦）和视图（👁）及其字段——🔑 主键，🔗 关联到其他表。
  • 点击一个即可查看 📋 数据——前 200 行。
  • ⌨ SQL 运行你输入的任何 SQL（多条语句，每条以 ; 结尾）并显示结果。
  • ＋ 新建创建数据库，🗑 删除当前显示的数据库（会先询问）。
