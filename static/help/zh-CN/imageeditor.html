图像编辑器

编辑器的布局、工具和快捷键。

✅ View ▸ Dockers；折叠和关闭面板组（2.514.0）

  • 面板组标签栏开头的 ▾ 可将该组折叠为只显示标签；点击某个标签即可重新展开。
  • ✕ 关闭该组。View ▸ Dockers 列出图像编辑器的所有面板（已显示的带勾选标记），另有 All Dockers 可将它们全部恢复。
  • 应用的侧边面板可通过其标题栏中的 ▾ 折叠为一条细窄的标题条。
  • 🖌 Edit theme mode（编辑主题模式）：拖动元素的控制柄可调整其大小，在元素内部拖动可移动它，也可以隐藏它或修改其文字。退出时会询问是否保存主题。

✅ Pen 钢笔工具 P（2.421.0）

  • Pen：点击 = 角点锚点，拖动 = 平滑锚点（两侧控制柄对称），点击第一个锚点 = 闭合路径。Alt = 尖角点，Shift = 以 45° 为步进，Ctrl = 临时切换为 Direct Selection，Enter / Esc = 保持路径开放。在已选路径上，指向线段时添加锚点，指向锚点时删除锚点（Auto Add/Delete）。
  • Freeform Pen：徒手绘制；Curve Fit（px）决定贝塞尔曲线贴合笔迹的紧密程度。在起点附近结束即闭合路径。
  • Add / Delete Anchor Point、Convert Point（点击：曲线 ⇄ 角点；拖动锚点：拉出新的控制柄；拖动控制柄：转为尖角点）。Shift+P 在这些工具之间循环切换。指针在编辑器上方时 P 是 Pen；在其他位置它仍用于显示 / 隐藏提示词面板。
  • Mode：Shape 绘制形状图层（用前景色填充，用背景色按 W 宽度描边），Path 绘制 Work Path（工作路径）。▣ ⊕ ⊖ ⊗ ⊘：New Layer、Combine、Subtract Front Shape、Intersect、Exclude。

✅ Path Selection / Direct Selection A（2.421.0）

  • Path Selection：点击一个组件（按 Shift 加选），拖动可移动，Alt-拖动可复制，Delete 删除；其运算方式在选项栏中设置；⧉ Merge Components（结果为普通轮廓）；⟳ Transform…（缩放、旋转、翻转）。
  • Direct Selection：操作锚点和控制柄——Shift 加选，框选可选中多个，方向键微移（Shift ×10），Delete 删除，Corner / Smooth。点击形状图层的轮廓即可编辑它；一旦移动锚点，形状图层就会变为路径。

✅ 自定形状 U（2.421.0）

  • Custom Shape 工具：心形、星形、爆炸形、箭头、V 形、加号、叉号、对勾、闪电、对话气泡、水滴、月亮、房子、云朵、圆环、边框——拖动绘制（Shift 保持比例）。Edit ▸ Define Custom Shape… 将所选路径添加为自定形状（在选取器中右键点击你自己添加的形状即可将其删除）。
  • Shape 工具（矩形、椭圆、多边形、直线）具有相同的运算按钮：除 New Layer 外，其他选项都会添加到当前的形状图层中。

✅ Paths 面板（2.421.0）

  • 位于 Layers 和 History 旁边：显示 Work Path、已保存的路径，以及当前图层的 Shape Path 和 Vector Mask。点击 = 选中；Ctrl-点击 = 载入为选区（Shift 添加，Alt 减去）。双击 Work Path = 保存它；双击已保存的路径 = 重命名。
  • ● 用前景色填充 · ○ 用画笔描边 · ⬚ 载入为选区 · ⟲ 从选区生成工作路径 · ◇ 矢量蒙版 · ＋ 新建 · ⧉ 复制 · ☰ 更多（保存、SVG、自定形状、形状图层）· 🗑 删除。Alt-点击 ● ○ ⬚ ⟲ 可打开它们的选项。

✅ 矢量蒙版（2.421.0）

  • Layer ▸ Vector Mask：Reveal All、Hide All、Current Path、Disable / Enable、Rasterize（栅格化到像素蒙版中）、Delete。其缩略图位于图层蒙版缩略图旁边：点击 = 编辑其路径，Shift-点击 = 关闭 / 开启。
  • 属性：Density、Feather、Invert、Link。裁剪、画布大小、图像大小和旋转会让所有路径随图片一起变换；PSD 会保留矢量蒙版和路径形状图层；File ▸ Export Path as SVG… / Place SVG as Shape Layer…。

✅ 智能对象（2.422.0）

  • Layer ▸ Smart Objects: Convert to Smart Object：将图层或图层组放入其中（仍可编辑）；智能对象（▣）根据其内容重新绘制，因此缩放 / 旋转 / 变形都不会损失画质。
  • Edit Contents（双击缩略图）：打开其内部内容并显示一条横幅——✔ Done 更新该智能对象及其所有副本，✕ Cancel 则保持原样。New Smart Object via Copy = 内容相互独立的副本。Replace Contents…、Export Contents…、Convert to Layers、Rasterize。

✅ 智能滤镜（2.422.0）

  • 对智能对象使用的 Filter / Adjustment 会以条目形式“添加”到图层下方：👁 开 / 关，双击 = 打开其设置，右键点击 = 不透明度，▲ 调整顺序，✕ 删除。
  • filter mask（滤镜蒙版，位于 Smart Filters 行上）：点击它后进行涂抹——涂黑的地方会隐藏滤镜效果；Shift-点击可将其关闭。

✅ Skew、Distort、Perspective、Warp（2.422.0）

  • Edit ▸ Transform: Skew / Distort / Perspective / Warp（斜切 / 扭曲 / 透视 / 变形），或在智能对象上按 Ctrl+T；可在选项栏中切换模式。Warp：拖动网格点或内部任意位置；预设可设置 Bend %。Enter 应用，Esc 取消。

✅ Puppet Warp 操控变形（2.422.0）

  • Edit ▸ Puppet Warp：点击放置图钉，拖动图钉使画面弯曲，Alt-点击 / Delete 删除图钉；Density、Show Mesh。在智能对象上会作为智能滤镜应用。

✅ Content-Aware Scale 内容识别缩放（2.422.0）

  • Edit ▸ Content-Aware Scale…（Alt+Shift+Ctrl+C）：设置宽度 / 高度 %，不重要的像素会被去除（或加倍）；Protect: the selection（保护选区）；带实时预览。

✅ Liquify 液化（2.422.0）

  • Filter ▸ Liquify…（Shift+Ctrl+X）：W 推移，R 重建，C 旋转扭曲（Alt 反向），S 褶皱，B 膨胀，F / D 冻结 / 解冻；用 [ ] 调整大小，压力，Restore All。在智能对象上会作为智能滤镜应用。

✅ Select and Mask 选择并遮住（2.423.0）

  • Select ▸ Select and Mask…（Alt+Ctrl+R）：Quick Selection W、Refine Edge R（用于头发等区域）、Brush B（Alt 减去）；多种视图；Radius / Smart Radius、Smooth、Feather、Contrast、Shift Edge；Decontaminate Colors；Output To 可选 Selection / Layer Mask / New Layer / New Layer with Layer Mask。

✅ Magnetic Lasso、Quick Selection、Sky（2.423.0）

  • Magnetic Lasso（L）：沿边缘移动——它会自动吸附；点击设置一个点，Backspace 撤回一个点，双击 / Enter 闭合。Width、Contrast、Frequency。
  • Quick Selection（W）：涂抹——选区会扩展到边缘；Alt 减去；Tolerance、Auto-Enhance。Select ▸ Sky。

✅ 通道和存储的选区（2.423.0）

  • Channels 标签页：RGB / Red / Green / Blue（点击 = 查看该通道，Ctrl+2 … 5；Ctrl-点击 = 将其明度载入为选区）以及 Alpha 通道——Select ▸ Save Selection… / Load Selection…；⬚ ◫ ＋ 🗑。

✅ Patch、Content-Aware Move / Fill、Red Eye（2.423.0）

  • J：Spot Healing（Content-Aware / Proximity Match）、Healing Brush（融合：纹理取自源点，光影取自当前位置）、Patch（圈出区域，拖到干净的纹理上）、Content-Aware Move（拖动选区：Move / Extend）、Red Eye（点击瞳孔）。
  • Edit ▸ Content-Aware Fill… 以及 Edit ▸ Fill… 中的 Content-Aware——不使用 AI：完全根据图片自身的内容进行填充。

✅ Mixer Brush、Background / Magic Eraser（2.423.0）

  • Mixer Brush（B）：Wet、Load、Mix，每次描边后 Clean。Background Eraser（E）：Continuous / Once、Tolerance、Protect Foreground Color。Magic Eraser（E）：点击即清除该颜色（Tolerance、Contiguous）。

✅ PDF 文件：打开、编辑、保存（2.424.0）

  • Save PDF… / Save as New PDF…（2.435.0）：保存对话框中的 Embed fonts 会让每一行以各自的字体写入并嵌入（只嵌入用到的字符）——字体取自本机已安装的字体或安装目录下的 fonts 文件夹；任何文字系统都保持为真实文本。
  • File ▸ Open PDF…（或直接拖入 .pdf 文件）、Open PDF from Project…：显示 Pages 页面栏；每一页打开后为一个不含文字的 Background 图层 + 每行一个文字图层（字体、字号、颜色、宽度均已匹配）。
  • 可使用所有工具进行编辑；每一页都保留各自的图层和撤销记录（在另一张图片上也可以——File ▸ PDF Pages）。
  • 💾 Save PDF：在原文件中替换已修改的页面（保存到项目中的副本，同时也会下载一份）；Save as New…。未修改的页面保持矢量；文字会成为真实、可选中的 PDF 文本（Helvetica / Times / Courier）；这些字体无法书写的内容会合并到图片中。

✅ 矢量线条：曲线工具、Shape tool、Outline Pen（2.425.0）

  • F5（再按一次 = 下一个工具）：Bézier（点击 = 尖突节点，拖动 = 平滑节点，拖动时按 C / S，Ctrl = 15°，点击第一个节点 = 闭合，双击 / Enter / Space = 完成，Esc = 放弃），Freehand、2-Point Line、Polyline、3-Point Curve、B-Spline、Node Pen。从当前线条的开放端点开始绘制即可接续该线条。
  • F10 Shape tool：选取 / 拖动节点、控制柄、线段；双击 = 添加 / 删除节点；C S Y = 尖突 / 平滑 / 对称；连接、断开、转为直线 / 曲线、反转方向、闭合、提取、自动闭合、减少节点。
  • F12 Outline Pen：宽度、颜色、虚线、转角、线端、位置、箭头、置于填充之后、随对象缩放。Ctrl+Q Convert to Curves。
  • Layer ▸ Vector Line: Convert to Path… / Make from Path…（Paths 面板中的 〰）：线条会变为一条记住其轮廓设置的路径，并可原样还原。SVG 和 PSD 都会保留它们。

✅ Curvature Pen、Rubber Band、路径对齐 / 分布（2.425.0）

  • Curvature Pen（P）：点击放置点——曲线会穿过这些点；双击某个点 = 在角点 / 平滑点之间切换；拖动可移动；Enter 结束。Pen 的 Rubber Band 选项。Path Selection（A）：对齐 / 分布所选组件（相对于彼此或相对于画布）。

✅ Character 与 Paragraph 面板、段落文字、样式（2.426.0）

  • Character（位于 Color 旁边）：字体、字形样式、字号、行距、字距微调、字距、垂直 / 水平缩放、基线偏移、颜色、Faux Bold / Italic、All Caps、Small Caps、Superscript / Subscript、Underline / Strikethrough。
  • Paragraph：对齐方式，两端对齐时末行左对齐 / 居中 / 右对齐 / 全部对齐，缩进（左、右、首行），段前 / 段后间距，Hyphenate。Paragraph text：用 Type 工具（T）拖出文本框——文字会在框内自动换行；Layer ▸ Type: Convert to Paragraph / Point Text。
  • Character / Paragraph Styles：＋ 根据当前文字新建，点击 = 应用，⌫ Clear Override，⟲ Redefine（所有使用该样式的文字随之更新），🗑。

✅ Actions 与 Batch（2.427.0）

  • Actions 标签页（位于 History 旁边，Alt+F9）：● 录制（菜单命令及其对话框中的设置、滤镜、Layers 面板中的操作），■ 停止，▶ 播放；☑ 开启 / 关闭某个步骤，▢ 在该步骤的对话框处暂停；▲ ▼ 🗑；双击 = 重新录制某个步骤 / 修改动作的名称和功能键；☰ Insert Stop、Insert Menu Item、Duplicate、Button Mode、Load / Save（.json）、Reset。
  • File ▸ Automate: Batch…：对选定的文件或文件夹执行某个动作——结果可保存到项目的 batch 文件夹、图像图库、下载或保留原样；PNG / JPEG；遇到错误时停止或记录到日志；生成一份报告。

✅ 绘图工具（2.428.0）

  • F6（再按一次 = 下一个工具）：Rectangle（圆角半径；圆角 / 扇形角 / 倒角）、3-Point Rectangle、Ellipse（饼形 / 弧形）、3-Point Ellipse、Polygon、Star、Complex Star、Spiral、Graph Paper、Common Shapes。Ctrl = 正方形 / 正圆，Shift = 从中心绘制。形状一直保持可调，直到用 F10 编辑节点或按 Ctrl+Q。
  • Artistic Media（位于 F5 中）：Preset、Calligraphic、Pressure、Sprayer。
  • F8：Parallel、Horizontal / Vertical 和 Angular Dimensions、3-Point Callout、Connector（直线 / 直角 / 圆角——会跟随所连接的对象移动）。

✅ 面板（2.429.0）

  • Window ▸ Dockers：Transform（Alt+F7：位置、旋转、缩放与镜像、大小、倾斜——可围绕 9 个锚点之一，可生成副本），Shaping（焊接、修剪、相交、简化、前减后 / 后减前、边界），Align and Distribute（Shift+Ctrl+A），Object Properties（Alt+Enter：填充（含渐变）、轮廓、透明度）。按住 Ctrl 点击图层可选中多个。

✅ 文档、调色板、⊠ 透明、自动填充（2.430.0）

  • Documents：每次 New / Open 都会创建一个独立的文档——第一个以标签页形式停靠，之后的文档在各自的窗口中浮动（Window ▸ Arrange ▸ Open Documents as Tabs 可将它们全部停靠）。将窗口拖到标签栏上即可停靠，将标签拖离标签栏即可浮动；Ctrl+W Close，Alt+Ctrl+W Close All，Ctrl+Tab 切换到下一个文档；Tile / Cascade / Consolidate All to Tabs。
  • 右侧的 Colour palette（调色板）：对于曲线 / 形状 / 文字，点击 = 填充，右键点击 = 轮廓；对于像素，点击 = 前景色，右键点击 = 背景色。⊠ = 无颜色 / 透明前景色（画笔会画出透明效果）。
  • Auto-fill：闭合的曲线或新建的形状会用最后选取的颜色填充（曲线工具栏上的 ▨ 可将其关闭）。

✅ 生成的图片直接放到画布上（2.431.0）

  • 编辑器打开时，提示词面板会生成 🖼 Image（→ ▦ canvas），它生成的每张图片都会作为新图层放到最前面的文档上，图层以提示词命名（若没有打开的文档，则作为新文档打开）。关闭编辑器后，提示词面板会恢复到之前的模式。

✅ 面板列本身就是一个可停靠面板（2.454.0）

  • ⇱ 可让任意标签组浮动；按住其标题拖到面板列上方——一条橙色线会显示它将停靠的位置。
  • 拖动面板列的左边缘可调整其宽度；顺序和宽度都会被保存。

✅ 框架：内容已锁定，右键点击进行编辑（2.453.0）

  • 内容锁定在其框架中：Move 工具及其控制柄作用于框架；内容会随框架一起移动 / 缩放 / 旋转。
  • 右键点击 ▸ Edit Frame Contents / Finish Editing Frame / Extract Contents / Lock Contents to Frame。

✅ Move 工具的控制柄（2.452.0）

  • 点击 = 缩放控制柄（Shift = 等比例，Alt = 从中心缩放）；双击 = 旋转控制柄（拖动角点进行旋转，Shift 以 15° 为步进；拖动边进行倾斜）。
  • 选项栏中的变换选项：角度、⟲90 ⟳90、翻转、W % x H %。
  • 旋转后文字仍可编辑；形状仍保持矢量。

✅ 从提示词面板进行 Edit / Generate，Del（2.451.0）

  • ✨ AI ▸ Edit：提示词面板切换到 🖼 Image + Qwen Image 2.1 edit，其按钮显示为 ✏ Edit。Generate：✨ Generate 会生成到所选图层的选区中。
  • Del 删除当前图层（有选区时：清除选区内的内容）。

✅ Warp 网格 + 分割线、Liquify 新增功能（2.450.0）

  • Warp：Grid（Default / 3 x 3 / 4 x 4 / 5 x 5 / Custom 列 x 行）；Split Warp Crosswise / Vertically / Horizontally——点击要分割的位置；Alt-点击分割线可将其删除。
  • Liquify：Smooth（E）、Push Left（O）。
  • Face-Aware Liquify：用 Face 工具（A）定位面部；13 个滑块可调整眼睛、鼻子、嘴巴和脸型。

✅ 逐字符设置文字样式（2.449.0）

  • 输入文字时：先选中若干字符，然后使用选项栏（字体、B、I、字号、字距、颜色）或 Character 面板——只有这些字符会改变。
  • 未选中任何字符 = 作用于整个图层。在已设置样式的一段文字中输入，会沿用该段的样式。所有字符共用一条基线，每行的高度取决于该行中最大的字符。
  • Layer ▸ Type: Clear Character Overrides。

✅ Content-Aware Fill 工作区（2.448.0）

  • Edit ▸ Content-Aware Fill…（需要有选区）：取样区域以绿色显示——Auto、Rectangular 或 Custom（🖌 Sampling Brush + / −，Alt）。
  • 实时 Preview；Colour Adaptation 可选 None / Default / High / Very High。
  • Output To 可选 Current Layer / New Layer / Duplicate Layer；只占一步撤销。

✅ 画板（2.447.0）

  • Layer ▸ New ▸ Artboard…（尺寸、背景、将所选图层放入其中）、Artboard 工具（再按一次 V）、Artboard from Group。
  • 画板中的图层只在画板内部显示；移动画板会带动这些图层；Properties：X / Y / W / H、背景、⇱ Fit。
  • File ▸ Export ▸ Artboards to Files…：每个画板导出一个 PNG。

✅ 网格按钮、Grids & Guides 设置（2.445.0）

  • ⚙ ▸ Grids & Guides：网格间距、每隔 n 条线一条主网格线、线条或点状、网格颜色 + 强度、参考线颜色、吸附距离。

✅ 从提示词面板进行 ✨ Edit / Generate、⚙ 设置（2.444.0）

  • ✨ AI ▸ Edit：提示词面板的风格 = Qwen Image 2.1 edit，其按钮 = ✏ Edit——在那里输入编辑指令。
  • ✨ AI ▸ Generate：提示词面板的 ✨ Generate 会渲染到所选图层的选区中；✔ Apply 将结果融合到该图层。
  • ⚙（菜单栏右侧）/ Edit ▸ Preferences…（Ctrl+,）：编辑器的设置。

✅ 框架：形状内的图层（2.442.0）

  • Layer ▸ Frame ▸ Place Inside Frame…（或将图层拖到闭合形状所在行的中间）：这些图层只在形状内部显示，并在 Layers 中以树状结构列在该形状下方。
  • 移动 / 旋转 / 缩放框架——其内容会随之变化（Lock Contents to Frame）。
  • Edit Frame Contents（用 Move 工具双击框架）——单独编辑其中的内容；✓ Finish Editing Frame。Extract Contents 将内容取出。
  • 当前图层为闭合形状时使用 ✨ Generate：生成的图片会放在形状内部。

  • FLUX 3 Klein（蒸馏版，16 步）、FLUX 3 Klein base（50 步，cfg 3.5）和 FLUX 3 Klein edit（最多 4 张参考图）图像风格。需要 ComfyUI 0.41.0+。
