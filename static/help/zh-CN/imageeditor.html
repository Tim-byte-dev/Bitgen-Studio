🟧 Blender 技能：✨ 用 AI 建模和 🧰 Blender 工具（2.855.0）

  • 🟧 ▾ 菜单（以及 文件 ▸ 🟧）中有 ✨ 用 AI 建模…：说明要做什么（例如“带把手的陶瓷咖啡杯”），选择一个技能或保持自动，然后 ✍ 编写脚本——提示词停靠窗的 LLM 借助匹配的 Blender 技能表编写 Blender 脚本。运行前会先显示脚本，你可以阅读并修改。bitGen 会检查它：只用 Blender 自带模块，不读写文件，不联网，不运行程序。
  • ▶ 在副本上运行 在打开的场景（或空场景）的副本上，以无窗口方式运行你的 Blender——结果是项目 blender/scenes 文件夹中的一个新场景，绝不改动原文件。Blender 报错时，LLM 会收到错误并修复脚本（最多三次）。你会看到预览、生成的内容以及 QA 检查的警告；🟧 作为 Blender 图层打开 即可打开。
  • 🧰 Blender 工具… 在打开场景的副本上运行技能自带的工具：📉 LOD、🗺 UV 打包、🔥 烘焙贴图、📤 为游戏引擎导出（Unreal、Unity、Godot、Roblox、网页）、🎨 卡通风格、🌇 时间段、🌧 天气、🔄 转台、✅ QA 检查——各有自己的设置。
  • 这些技能需要 Blender 5.2 或更新版本；版本过旧（或没有）时会提示并给出 ⬇ 下载（blender.org）。技能表和脚本来自 EL4CTEO 的 blender-skills（MIT），已在 设置 ▸ 关于 中致谢。

🛒 网站商店：商品目录、购物车和结账（2.850.0）

  • 🌐 建网站 ▸ 🛒 商店为 PHP + MySQL 网站加上商店。勾选它也会选中 PHP + MySQL 和 🔐 管理区，因为商品、订单和客户都在管理数据库（myadmin）里。页眉会加上商店和购物车（显示里面有几件）。
  • shop.php，商品目录：显示上架商品的图片和价格（特价显示在原价旁边）、分类，以及按名称、描述或 SKU 搜索。推荐商品排在前面。
  • product.php：图片、描述、选项（有各自价格的规格；缺货的不能选）和数量。除非商品允许预订，否则放进购物车的数量不会超过库存。

  • order.php：每个订单自己的页面，只能用买家邮件里的专用链接打开。显示明细、合计、状态和付款方式。
  • 在 /admin/ ▸ 设置：currency、tax_rate、prices_include_tax、pay_bank + bank_details、pay_pickup + pickup_note、order_email（新订单通知谁）和 order_prefix。商品、分类、优惠券、配送方式和订单也都在 /admin/。旧的 myadmin 数据库会自动加上新列。
