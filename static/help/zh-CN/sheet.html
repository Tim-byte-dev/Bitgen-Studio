▦ 电子表格

在 bitGen 中处理表格、求和与清单——一个由多张工作表组成的工作簿,公式会在你输入时自动重新计算。顶部栏的 ▦ 按钮用于打开和关闭停靠窗。 工作簿保存在项目的 sheets 文件夹中(.bgs 文件);正在输入的内容也会保存在浏览器中,所以关闭停靠窗不会丢失任何内容。

输入

  • 单击单元格并输入。Enter 确认并向下移动,Tab 向右移动,Esc 撤销输入。F2 或双击可修改单元格中的内容。
  • 方向键移动;Shift + 方向键(或拖动)选择区域;Ctrl + 方向键跳到数据末端;Home 回到 A 列,Page Up / Down 移动 20 行;Ctrl+A 全选;Delete 清空所选单元格。
  • 数字按你输入的方式被识别:$1.50 是 1.5,显示为货币;25% 是 0.25,显示为百分比;17/11/2026(日在前)或 2026-11-17 是日期。
  • 网格上方的 ƒx 栏显示单元格中真正的内容(公式,而不是结果)——也可以在那里输入。

公式

  • 以 = 开头:=B2*C2、=SUM(D2:D20)、=IF(D2>100,"big","small")。+ - * / ^,& 连接文本,= <> < > <= >= 用于比较。
  • 输入公式时单击单元格(或拖过一个区域)即可插入其地址。
  • 复制或填充公式时,$A$1 保持引用不变;A1 会随之移动。
  • 其他工作表:=Sheet2!A1 或 ='My costs'!B4。整列和整行:=SUM(B:B)、=SUM(3:3)。
  • ƒ▾ 列出函数:求和与计数(SUM、AVERAGE、MEDIAN、MIN、MAX、COUNT、COUNTA、COUNTBLANK、SUMIF(S)、COUNTIF(S)、AVERAGEIF)、数学(ROUND、ROUNDUP、ROUNDDOWN、INT、ABS、SQRT、POWER、MOD、PRODUCT)、逻辑(IF、IFS、IFERROR、AND、OR、NOT)、文本(LEN、TRIM、UPPER、LOWER、LEFT、RIGHT、MID、CONCAT、TEXT、VALUE)、日期(TODAY、NOW、DATE、YEAR、MONTH、DAY)和查找(VLOOKUP、XLOOKUP、INDEX、MATCH)。
  • 错误会显示在单元格中:#DIV/0!(除以 0)、#REF!(已删除的单元格)、#NAME?(不认识的函数)、#CYCLE!(需要自身结果的公式)。

填充、复制、移动

  • 所选单元格角上的小方块是填充柄:向下或横向拖动即可复制——公式会移动其引用,两个及以上相连的数字或日期会延续序列(1、2 → 3、4、5)。
  • Ctrl+C / Ctrl+X / Ctrl+V 复制、剪切和粘贴——在表内,公式随粘贴位置移动;从其他程序复制的表格(以制表符分隔的文本)会粘贴到单元格中。
  • Ctrl+Z / Ctrl+Y 撤销和重做。
  • 右键单击单元格可插入 / 删除行和列——所有公式都会跟随它们所指向的单元格。拖动列字母或行号的边缘可调整大小。

外观 - ▤ 设置单元格格式 (Ctrl+1)

  • 工具栏的 ▤ 格式…、Ctrl+1 或右键单击单元格可打开 设置单元格格式。在这里更改的项目会应用到所有所选单元格(各单元格的其他格式保持不变);按一次 Ctrl+Z 即可撤销。
  • 数字:常规、数值(小数位数、千位分隔符、负数的显示方式 - 负号、红色、括号)、货币($、A$、€、£、¥、฿ …)、会计专用(符号在单元格边缘、小数点对齐、零显示为短横线)、日期、时间、百分比、分数、科学记数、文本(按输入原样显示 - 0012 保留前导零)、特殊(邮编、ABN、电话号码)以及 自定义 - 输入任意格式代码:0 # ? 数字位、, 千位分隔、%、d m y h s 和 AM/PM、[h] 超过 24 的小时数、[Red] 颜色、"文本",以及最多四节 正数;负数;零;文本 或 [>=1000] 之类的条件。示例会在你选择时显示活动单元格。
  • 对齐:左 / 居中 / 右(带缩进)、填充、两端对齐、跨列居中(不合并即可让标题跨多列)、分散对齐;靠上 / 居中 / 靠下;自动换行(行会变高以容纳内容)、缩小字体填充、合并单元格、文字方向,以及 方向 - 拖动刻度盘或输入角度(-90 到 90),或让文字竖排。
  • 字体:字体(包括此电脑上的字体)、常规 / 倾斜 / 加粗、字号(字号变大时行会变高)、下划线(单、双、会计用)、颜色、删除线、上标、下标。
  • 边框:选择线条(13 种样式)和颜色,然后点预置(无、外边框、内部)、边框按钮,或点击预览中的边 - 对角线也可以。再点一次即可去掉。
  • 填充:调色板中的颜色(或任意颜色)、双色渐变(横向、纵向、斜向、从中心)或带颜色的图案。
  • 保护:锁定 和 隐藏 在工作表受保护后才生效 - 勾选 按确定时保护此工作表,或右键单击工作表标签 ▸ 🔒 保护工作表。之后锁定的单元格不能更改(所有单元格默认锁定 - 对需要他人填写的单元格取消锁定),隐藏单元格的公式不会显示;🔓 撤销工作表保护 可解除。
  • 工具栏上有常用项:数字格式 列表、.0← / .00→ 减少 / 增加一位小数、B I U、文字和填充颜色(⊘ = 无填充)、左 / 居中 / 右、自动换行、边框 ▾ 和 ⊞ 合并。数字太宽放不下时显示 ##### - 请加宽该列。

Excel 文件、图表和 ✨ 仪表板

  • ⤒ 导入 可打开 Excel 工作簿 (.xlsx) 或 CSV 文件:所有工作表、值、公式、数字格式、字体、填充、边框、合并单元格、列宽和冻结窗格。使用 bitGen 尚不支持的函数的公式会显示文件保存时的结果。⤓ 导出 ▾ 可将工作簿保存为 .xlsx(下载,并保存在项目的 sheets 文件夹中),或将此工作表保存为 CSV。
  • 📊 图表 ▾ 为所选单元格创建图表(柱形、条形、折线、面积、饼图、圆环、散点)——第一行为系列名称,第一列为类别。拖动可移动,拖动角可调整大小,双击可更改标题、类型或数据,Delete 删除。图表会随上方插入的行移动,并保存在工作簿中(.xlsx 中保存的是数据,而不是图表)。
  • ✨ 仪表板——LLM(提示词停靠窗的)查看数据的列——名称、值的类型、几个示例和合计,而不是每一行——并规划一个仪表板;也可以输入你想看的内容(如"按地区和月份的销售额")。bitGen 会在新的第一张工作表上搭建它:磁贴中的关键数字、带表格和图表的细分、随时间的趋势——全部是实时公式,会随数据更新——并把数据格式化为表格(标题、隔行底纹、数字格式、列宽、筛选、标题冻结)。选择 Excel 或 CSV 文件 可从文件开始。取消勾选 使用 LLM(或 LLM 没有回应时),会根据数据本身的形态来规划。按一次 Ctrl+Z 即可全部撤销。

✨ 单元格中的 AI

  • ✨ AI ▾ ▸ ✍ 编写公式…——说出要计算什么(如"Region 为 North 的 Amount 合计")。LLM(提示词停靠窗的)会得到表格的列——标题、值的类型、几个值——而不是每一行,并以公式作答。bitGen 在填入前先计算:你能看到结果,可以修改,然后按 填入。针对单行的公式会提供 向下填充表格各行。
  • 💡 解释此公式(单元格的右键菜单中也有)——公式读取的每个单元格和范围及其当前内容,然后是 LLM 的通俗解释。
  • 🪄 按示例填充(Ctrl+E)——在新列的一两个单元格中输入应有的内容,然后按 Ctrl+E:bitGen 会尽量自己找出规则(其他单元格中的词、@ , - 等符号之前 / 之后的部分、拼接、大写 / 小写 / 首字母大写、首字母缩写)并填充空行——无需 LLM。没有这类规则适用时(求和、查找…),由 LLM 编写公式,只有当它能得出每一个示例时才使用;都不行时,由 LLM 填入值并说明这是它的推测。按一次 Ctrl+Z 即可撤销填充。
  • ƒ▾ 中的新函数:PROPER、FIND、SEARCH、SUBSTITUTE、REPLACE、REPT、EXACT、TEXTJOIN、AVERAGEIFS、MAXIFS、MINIFS、SUMPRODUCT、LARGE、SMALL、RANK、ROWS、COLUMNS、CEILING、FLOOR、WEEKDAY、HOUR、MINUTE、EDATE、EOMONTH、DATEDIF、CHOOSE、IFNA、ISERROR、ISNA、ISBLANK、ISNUMBER、ISTEXT、SWITCH。

表格

  • A→Z / Z→A 按活动单元格所在的列对其周围的表格排序。第一行标题保持在顶部,同一行的单元格(包括其公式)保持在一起,空单元格排在最后。若已选择区域,则只对该区域排序。
  • ⏷ 筛选在每个标题上加一个 ▾——勾选要显示的值;其余的行会被隐藏(不会被删除)。再按一次显示所有行。
  • ❄ 冻结在滚动时保持活动单元格上方的行和左侧的列可见。
  • Σ 对活动单元格上方(或左侧)的数字求和。
