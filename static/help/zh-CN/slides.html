🎞 幻灯片

bitGen 中的演示文稿——带有标题、要点、图片和形状的幻灯片，全屏放映。顶部栏的 🎞 按钮打开和关闭停靠窗（⛶ 将其放大）。演示文稿保存在项目的 slides 文件夹中（.bgk 文件）；正在做的内容也会保存在浏览器中，所以关闭停靠窗不会丢失任何内容。

幻灯片

  • 左侧列表显示每张幻灯片。单击一张进行编辑；上下拖动以移动；右键单击可在其后新建幻灯片（选择版式）、复制、在演示中隐藏、上移 / 下移、删除。
  • ＋ 幻灯片 ▾（或 Ctrl+M）在这一张之后添加幻灯片——选择其版式：标题幻灯片、标题和内容、两栏内容、节标题、带标题的图片、仅标题、空白。▤ 版式 ▾ 更改这张幻灯片的版式——文字会移入新版式的框中。
  • 🎨 主题 ▾ 为整个演示文稿设置背景、颜色和字体。Bg 为一张幻灯片设置自己的背景（↺ = 恢复主题背景）。

文字、形状和图片

  • 空框会说明要放什么（“Click to add a title”）。双击一个框（或选中后按 Enter）并输入；按 Esc 或在框外单击即完成。每一行是一个段落；在带项目符号的框中每行都有一个符号。
  • 🅃 文本 添加文本框（双击幻灯片空白处也可以）。⬚ 形状 ▾：矩形、圆角矩形、椭圆、三角形、菱形、箭头、星形、线条——双击形状可在其中输入文字。
  • 🖼 图片、拖放到幻灯片上的图片，或复制的图片 Ctrl+V。在“带标题的图片”幻灯片上会填入图片框。右键 ▸ 适应 / 填满框。
  • 单击选中，Shift / Ctrl+单击加选，或在空白处拖一个框框选。拖动以移动——与幻灯片中心、边缘或其他项目对齐时会显示粉色线（Alt = 不吸附，Shift = 直线）。白色方块调整大小（Shift 保持形状；图片除非按住 Shift 否则保持形状）。方向键微移（Shift = 10 px）。
  • 工具栏：字体、字号、B I U、颜色、左 / 中 / 右、⇕ 上 / 中 / 下、•≡ 项目符号；形状的填充、线条及其粗细；⇡ 置于顶层，⇣ 置于底层；🗑 删除。Ctrl+D 复制一份，Ctrl+C / X / V 复制、剪切和粘贴（也可在幻灯片和演示文稿之间），Ctrl+A 全选，Ctrl+Z / Ctrl+Y 撤销 / 重做。
  • 演讲者备注写在幻灯片下方的框中。

表格、图表和品牌主题

  • ▦ 表格 把一个 4 × 3 的表格放进幻灯片的空内容框（没有则放在中间）并打开编辑器：输入单元格，＋ / − 行和列，📋 从电子表格粘贴（从 ▦ 电子表格或 Excel 复制的单元格），标题行、镶边行、标题颜色（↺ = 主题的强调色）和字号。✔ 应用可一步撤销。
  • 📊 图表 ▾：柱形、条形、折线、面积、饼图或圆环图，带示例数字——在编辑器中填写类别（第一列向下）、系列（第一行向右）和数字、标题与图例；这里也能从电子表格粘贴。图表使用主题的两种强调色。
  • 双击表格或图表（或右键 ▸ ✎ 编辑…）即可再次修改。⤓ PowerPoint 写出真正的 PowerPoint 表格和图表（可在其中编辑），⤒ 打开 PowerPoint 会读回它们，⤓ PDF 会绘制它们。
  • 🎨 主题 ▾ ▸ 🎨 品牌主题…：你的品牌的背景、标题、正文、强调色 1、强调色 2 和标题 / 正文字体，带实时预览。🖼 从标志… 从标志中取出颜色（浅色或深色背景；单击色块设为强调色 1，Shift+单击设为强调色 2）。✔ 用于此演示文稿，或 💾 保存品牌——保存的品牌在每个项目的 主题 ▾ 中列出（✎ 修改，🗑 删除）。即使没有保存的品牌，演示文稿也会保留其品牌颜色。

✨ AI 制作幻灯片

  • ✨ AI ▾ 制作幻灯片…：写下幻灯片的主题，和 / 或粘贴文字、笔记或大纲（或 📄 选择 .txt / .md 文件）——提示词停靠栏的 LLM 会规划幻灯片：一张标题幻灯片，然后是要点简短的幻灯片、两栏和章节幻灯片，以及演讲者备注。选择幻灯片数量，新的演示文稿或在这张幻灯片之后。
  • 🖼 带图片：部分幻灯片会成为图片幻灯片，每个图片框会得到一张用提示词停靠栏中选择的图像风格生成的图片——一次一张，完成一张就放进它的框里（期间可以继续工作；Ctrl+Z 可撤回图片）。生成期间同一菜单中有 ■ 停止生成图片。
  • 按原样使用大纲：不用 LLM——# 标题是演示文稿的标题，其他标题或普通行各成一张幻灯片，- 或 1. 行是它的要点，> 行是演讲者备注。
  • 对当前显示的幻灯片：✍ 重写这张幻灯片、✂ 缩短、✓ 修正文字（只改拼写和语法）和🎤 根据幻灯片写演讲者备注——每个都可一步撤销。
  • 🖼 为空框生成图片：每个空的图片框都会得到一张根据其幻灯片文字生成的图片。
  • 在提示词停靠栏中：“make slides about bees”、“create a 6 slide presentation on solar power with pictures”——第一行之后的各行就是用来制作的文字。

放映

  • ▶ 放映（F5）从第一张开始，▶ 从此处（Shift+F5）从这一张开始——全屏。下一张：→ ↓ 空格 Enter Page Down 或单击；上一张：← ↑ Backspace Page Up 或右键；Home / End；输入数字后按 Enter 跳到该张；B / W 黑屏 / 白屏；Esc 结束。隐藏的幻灯片会跳过。
  • 工具栏上的切换：这张幻灯片的出现方式——无、淡入、推入、擦除、缩放。

演讲者视图

  • 🎤 演讲者视图（Alt+F5）：这个屏幕显示当前幻灯片、下一张、你的演讲者备注（A− / A+ 调整大小）、计时器（⏸ 暂停，↺ 从 0 重新开始）、时间和幻灯片编号；第二个窗口——观众窗口——只显示幻灯片。把它移到投影仪或第二个屏幕上，双击（或按 F11）即可全屏。
  • 两个窗口中可用相同的按键：→ / 空格 / 单击 = 下一张，← = 上一张，数字 + Enter，B = 给观众黑屏，Esc 结束并关闭观众窗口。工具栏上有 ⬛ 和 🖥 观众（再次打开）。

旋转、项目中的图片

  • 选中的项目上方有一个圆形控点：拖动它即可旋转项目（Shift = 每次 15°；会吸附到 0°、90°、180°、270°）。旋转后的项目，其控点沿项目自身的边调整大小。
  • 🖼 图片 ▾：来自这台电脑…、来自图库…或来自素材…——从项目的图片中挑选（带搜索）。

文件

  • 📄 新建 ▾——选择主题以及 16:9 或 4:3。📂 打开 ▾ 列出本项目的演示文稿。💾 保存（Ctrl+S）以框中的名称保存。
  • ⤓ PowerPoint 保存为 .pptx——会下载并保存在 slides 文件夹中：每张幻灯片的背景、文字（字体、字号、颜色、项目符号）、形状、图片和演讲者备注。
  • ⤒ 打开 PowerPoint（或把 .pptx 拖到幻灯片上）把 PowerPoint 文件作为演示文稿打开：幻灯片、文字（字体、字号、颜色、项目符号）、形状、图片、组合、背景、演讲者备注、隐藏的幻灯片和切换效果；PowerPoint 存在版式中的位置也会从那里读取。表格、图表和 SmartArt 会被省略（工具栏会说明数量）。💾 保存会把它保存在这里。
  • ⤓ PDF ▾：幻灯片（每张一页）或幻灯片 + 演讲者备注（备注在每张幻灯片下方）——下载并保存在 slides 文件夹中。隐藏的幻灯片会被省略。
