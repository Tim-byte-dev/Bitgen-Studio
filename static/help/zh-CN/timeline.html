✅ 任意设置均可设关键帧（2.516.0）

  • 片段某项设置旁的 ◇ = 在播放头处为它设一个关键帧（◆ = 此处已有关键帧；点击可删除，Alt+点击 = 删除全部）。设过关键帧后，在任意位置修改它都会在该处自动设关键帧。
  • 颜色（曝光……色相、LUT 混合、色轮亮度、HSL 范围）、镜头、变形、抠像器、✒ 蒙版羽化 / 扩展 / 不透明度、文字大小 / 描边、⏱ 时间效果。
  • 📈 Graph Editor（图表编辑器）会列出所有设了关键帧的设置。⚙ Compile（编译）的绘制结果与之相同。

✅ 抠出主体、移除主体、解算摄像机（2.515.0）

  • 🧍 Cut out（抠出；位于视频片段的 Properties 中）：用 ✚ 点击主体，用 ✖ 点击非主体部分，或用 ▭ 拖出一个框，然后点 ▶ Cut out。主体会在整个片段中被跟踪（SAM 2、AI 抠图或内置方式）。边缘优化：吸附、羽化、收缩、平滑。在视频图层上，use it（使用）= 主体周围变为透明（画布和编译均生效）。
  • 🩹 Remove（移除）：将抠出的内容（或该图层的 ✒ 蒙版）从每一帧中去除。背景取自前后的帧，始终看不到的部分则自动补画。先在图像编辑器中补好一张参考帧会有帮助。↺ Original 可撤销。
  • 📷 3D camera track（3D 摄像机跟踪）：先 ▶ Solve，再用 📷 Pick points 选点，然后用 📌 Place 将图层平贴在这些点上、立在上面或朝向摄像机。🧊 3D camera 会跟随解算结果。
  • Ctrl+Shift+Alt+E：带对话框的主题编辑模式（Settings 保持打开，以便设置样式）。Ctrl+S 保存主题并退出。

✅ 时间线的画幅尺寸栏；Load UE project（2.513.0）

  • Frame（画幅；Timeline 顶部的栏）：宽 × 高、一个 Preset（预设：Auto = V1 视频的尺寸，4K、Full HD、HD、竖屏、方形、4:5、21:9、电影……）以及输入时保持不变的 Aspect（宽高比）。V1 会被适配到画幅内并居中；编译结果与之一致。
  • 同一栏上的 ☐ CAD toolbar 用于显示 CAD 工具栏（其 ⌬ 按钮被隐藏）。
  • 🎮 Load UE project（应用的菜单栏）：选择项目文件夹，按 Select。bitGen Bridge 插件会被装入，所需的插件会被启用，Unreal 会随该项目重新启动。

✅ Lottie（JSON）导出（2.512.0）

  • 📤 Export → ⤓ Lottie (JSON)：将图片图层和文字图层导出为 <project>_lottie.json，与影片放在一起。
  • 移动、缩放、旋转和淡入淡出保留为动画图层（缓动和定格会保留，混合模式也会保留）。带效果、蒙版、3D、父级或表达式的图层以逐帧方式导出。
  • 视频图层和轨道遮罩不会导出，并会列出其名称。

✅ 可变羽化、数据、模板字段（2.511.0）

  • ✒ Variable mask feather（可变蒙版羽化）：用 Mask Pen 按 Shift+拖动某个蒙版点 = 为该点单独设羽化值（以一个圆环显示）；边缘在各点的羽化值之间平滑过渡。
  • 📋 Data（数据）：将 CSV / JSON 导入为一个带“当前行”的数据集；在文字中使用 {{set.column}}，在 ƒx 中使用 data("set", "column", row)，还可用 📋 Data → keys（每隔若干秒切换一行）。
  • 📋 Template fields（模板字段）：带标签公开文字颜色、不透明度、缩放、x、y、旋转；在同一个列表中统一编辑；🧩 模板在拖入时会提供这些字段。

✅ 3D 空间中的 2D 图层（2.510.0）

  • Properties 中的 🧊 3D layer（3D 图层）：一张带深度 z、x / y 旋转、可投射 / 接收阴影的卡片（均可设关键帧）。
  • 🎥 3D camera（3D 摄像机）：位置、目标点、缩放，均可设关键帧；🧊 Orbit（Shift+O）拖动 = 环绕，按住 Shift = 推拉，按住 Alt = 平移。
  • Depth of field（景深：焦点、光圈），以及一盏 light（灯光），其阴影会从卡片投射到后方的卡片上。
  • 卡片按图层顺序堆叠。编译结果与画布一致，包括 3D 视频图层。

✅ 运动草图、摆动器、平滑器（2.509.0）

  • ✍ Motion sketch（运动草图；Shift+K，或 〰 Motion → ✍ Sketch）：按下并移动。时间线开始播放，图层跟随指针移动；松开即停止。可设速度 %、平滑 px。
  • ≈ Wiggler（摆动器）：为某个属性添加随机运动。可设每秒次数、幅度、平滑或锯齿、位置 x / y 分开处理、种子。
  • ⌇ Smoother（平滑器）：将某个属性的关键帧在 ± 若干帧范围内取平均，再在容差范围内精简。
  • 结果都是普通关键帧，可在图表编辑器中编辑，编译时也会按它们播放。

✅ 音频 → 关键帧、波形和频谱图层（2.508.0）

  • 任意图层 Properties 中的 ♪ Audio → keys：选择单个片段的声音或全部声音；响度、低音、中音或高音；一个属性（不透明度、缩放、x、y、旋转、生成器 / 光线的数值）从安静到响亮的取值范围；平滑；然后点 ♪ Make keys。
  • 🌫 Waveform（波形）：使用 🌫 工具按 Alt+点击。波浪 / 线条 / 柱状、跨度、增益、颜色。
  • 🌫 Spectrum（频谱）：Alt+Shift+点击。柱状 / 线条 / 圆形、频段数、增益、间隙、底限、从低到高的颜色。
  • ƒx audio()、audio("bass")、audio("mid")、audio("treble")：该时刻的混音电平，0..1。编译结果与画布一致。

✅ 操控钉点和网格变形（2.507.0）

  • 在选中的图层上使用 📌 Puppet（操控；Shift+W）：点击 = 添加一个钉点，拖动钉点 = 图层弯曲而其他钉点保持不动，Alt+点击 = 删除钉点。
  • 📌 Warp 中的 ◇ key here 会为每个钉点设关键帧；此后每次拖动都会在播放头处设关键帧，钉点在关键帧之间平滑过渡。
  • ⌗ Mesh warp（网格变形）：由列 × 行个点组成的网格，用 📌 工具拖动这些点；平滑曲线会穿过它们。
  • 衰减（钉点的影响范围）、细节；编译结果与画布一致，包括视频图层。

✅ 粒子和光线（2.506.0）

  • ✨ Particles（粒子）：使用 🌫 Generator 工具按 Shift+点击。点 / 线 / 盒形发射器；发射速率、寿命、预滚动；速度、方向、扩散、重力、风；圆点 / 圆形 / 方形 / 星形 / 火花；随粒子寿命变化的大小、颜色和不透明度。
  • 任意图层上的 ☀ Light rays（光线）：图层的明亮部分从一个光源点向外拖出光束（长度、强度、阈值、色调、仅显示光线），并可超出图层边缘。
  • 每项设置都可设关键帧（◇）并可用于 ƒx。编译结果与画布一致。带光线的视频图层会由页面整体烘焙，并保留其声音。

✅ 生成器和扭曲（2.505.0）

  • 🌫 Generator tool（生成器工具）：点击 = 一个 Fractal Noise（分形噪波）图层（基本 / 湍流；缩放、复杂度、会自行变化的演化、颜色），拖动 = 一个 Gradient Ramp（渐变：线性 / 径向）。
  • 任意图层上的 〰 Distort（扭曲）：Turbulent displace（湍流置换：数量、大小、演化），或来自另一个图层的 Displacement map（置换贴图：按亮度，或红色 ↔ / 绿色 ↕）。
  • 每项设置都可设关键帧（◇）并可用于 ƒx；编译结果与画布一致，包括视频图层。

✅ 贝塞尔蒙版（2.498.0）

✅ 表达式（2.497.0）

预览画布

  • 将视频、图片或声音拖放到画布上：每一个都会放到位置标记处的一个新图层上，位于你松开的位置。拖放到空时间线上的视频会进入 V1。
  • ➤ Move V（自 2.648.0 起为指针图标）：点击图层以选中，拖动以移动，拖动角点以缩放，拖动圆形手柄以旋转。Shift 以 15° 为步长旋转，或沿单一轴向移动。V1 始终填满画幅。
  • T Text T：点击添加文字图层；文字内容、字体、大小、颜色、描边和阴影在 Layers 面板中设置。
  • ⬚ Select M：拖出一个框。🖌 Mask B：涂抹要修改的区域（Alt 为擦除）。羽化会柔化边缘。
  • ✋ Hand H 或按住 Space 可平移；🔍 Zoom Z 用于缩放（Alt-点击或 Ctrl + 滚轮为缩小）；⤢ 适合窗口；⊡ 缩放到选中的图层。在画布任意位置 Shift + 右键拖动：向前（向上）放大，向后（向下）缩小，以按下的点为中心。
  • 播放：画布下方的 ▶，或在画布上轻按 Space。🔁 循环播放标尺选区或整条时间线。
  • 图层名称：在 Layers 列表中双击名称并输入（Enter 确认，Esc 取消），对选中的图层按 F2，或使用其属性顶部的 Name 框。点击时间线轨道上的图层名称也可以重命名。

✨ Fill：在选区内生成

  • 选择或用蒙版圈出一个区域，写下那里应有的内容，然后选择 Image 或 Video，再点 ✨ Generate。
  • Image（图片）根据位置标记处的帧重绘该区域（使用图像编辑器的 inpaint 风格），并将结果放到一个新的图片图层上，通过羽化蒙版融入场景。持续时间为标尺选区的长度，没有选区则为 3 s。
  • Video（视频）先做同样的处理，再用视频模型将这张图片按你设定的秒数做成动画，并放到一个带相同柔边蒙版的新视频图层上。

关键帧

  • 选中一个图层，将位置标记放在动画开始处，点击 ◇ Key：位置、缩放、旋转、不透明度（以及文字图层的颜色）会保存在该处，在片段上显示为 ◆。
  • 移动标记并修改图层：会在该处生成第二个关键帧。画布和 Compile 会在两者之间补间。
  • ◀ ▶ 在关键帧之间跳转；关键帧上的菜单用于设置它如何过渡到下一个关键帧：linear、ease in、ease out、ease in+out、hold。✕◆ 删除关键帧。点击时间线上的 ◆ 可编辑它。

红色位置标记

🎥 摄像机路径（2.399.0）

⤳ 路径图层：沿你绘制的路径移动的主体

  • ＋ Path layer（时间线栏）会创建一个路径图层并选中 ⤳ Path 工具（P）：点击画布放置路径的点，拖动点可移动它，Alt-点击某个点可删除它（Esc / Enter = 完成）。绿点是起点，红点是终点；虚线框显示主体在位置标记处的位置和大小。
  • 该图层的面板（在 🧰 Tools & Properties 中）：沿路径移动的是什么（一只金毛寻回犬、一辆红色老爷车、一位穿黄色雨衣的女士……），它是动物、人还是车辆，Start 和 Length，它在起点和终点处的 Size（占画面高度的 %，越小 = 越远），步调，朝向，图片和视频风格，以及绿幕的抠除方式。
  • ✨ Generate——In place + follow path（原地 + 沿路径；任意视频模型）：先生成它在绿幕前的图片，再生成它原地行走 / 行驶的视频，抠除绿幕，然后图层的片段用 ◆ 关键帧使其沿路径移动——在路径折返处镜像翻转（侧视），或随路径转向（俯视），路径比视频长时循环播放。移动点或修改尺寸后，⟲ Place again 会重建片段。Along the path (Wan ATI)（一种 Wan 2.1 风格 + Wan2_1-I2V-ATI-14B 模型）：主体被放在路径起点，由模型让它自己沿路径行进——生成一个全画幅片段。
  • Cut out（抠出）：AI 抠图（BiRefNet——适合毛发、头发和柔和边缘；需点一次 ⬇ Install AI matte，约 1.5 GB）或色度键（无需安装）。每个路径图层都是独立的透明视频，场景由它们组合而成——编译也会保留其透明度。

  • ▯ Frame（帧；F）：点击某个图层的轨道，该图层上指针下方的那一帧会被选中（位置标记跳到该帧）。拖动可选多帧，Shift+点击可选到所点击的帧，← / → 将选区移动一帧（Shift：移动其末端）。Del 或 ⌫ 从该图层删除这些帧并闭合空隙；↶ / Ctrl+Z 恢复；Esc 取消选区。
  • ▼ Ranges（范围）：播放预览，在范围开始处轻按 Ctrl（时间标尺上出现一个 ▼），在结束处再按一次——播放不会中断，因此可以在高亮图层上标记任意多个范围，每个都有自己的颜色。拖动 ▼ 可移动它（预览显示该帧）；点击 ▼ 可选取其范围（Ctrl / Shift + 点击可多选，Esc 取消选取）；右键点击可删除其范围；Esc 放弃刚开始标记的范围。菜单栏中的 ▼ 组：✂ Cut（剪掉选取的范围，未选取则剪掉全部——选区栏的 ✂ Cut 也会剪掉选取的范围）、⏩ Speed up 2× - 10×（快进浏览渲染内容）、✕。无论焦点在哪里（文本框除外），以及预览面板的播放器正在播放时间线片段时，轻按 Ctrl 都会生效。悬停在时间线上会显示指针下方的时间；预览下方的速度列表可按 0.125× - 8× 播放。
  • 剪开的片段仍是一个片段：开启波纹时，在片段中间 ✂ Cut（或对帧按 Del），会把前后两部分重新合并为一个片段——视频或声音会生成一个新文件（Video / Sound 素材中的 "<name>-join1"），图片则只是变短；一次 ↶ 即可撤销。变速、抠像、文字 / 3D / 生成的片段，以及关闭波纹时的剪切，仍保持为两个片段。✂ to new layer（剪到新图层；菜单栏中的复选框）：✂ Cut、对帧按 Del 以及 Ctrl+K 拆分，会将剪切点之后的部分放到紧邻上方的新图层上（V1 的部分放到第一个视频图层上）。
  • J / L 剪辑：V1 片段的 🎧 Sound 中有 J … s early（声音先于画面开始）和 L … s late（声音在画面结束后继续）；相邻片段在该处的声音会被静音。
  • 位置旁会显示时间码（HH:MM:SS:FF）；📤 Export 或 ⇄ Exchange 可设置其起始值和帧率。

🎨 颜色：色轮、曲线、HSL、示波器

  • 时间线的 🎨（或片段 Colour 折叠栏中的 🎨 more…）会为选中的片段打开 Colour 对话框：Lift / Gamma / Gain 色轮（将圆点拖向某种颜色，滑块用于调暗 / 调亮；双击使其归中）、Curves（曲线：Master、R、G、B：点击添加点，拖动移动点，双击删除点）、HSL secondaries（HSL 二级调色：选取一个色相范围并偏移、（去）饱和或提亮——适用于天空、肤色、植被）以及位置标记处画面的 scopes（示波器：波形图、RGB 分量图、矢量示波器、直方图）。

📤 导出

  • 选择影片需要输出的所有格式：MP4 H.264 / H.265、MOV ProRes 422 HQ / DNxHR HQ、WebM VP9、GIF、WAV / MP3——每种都可设置尺寸、reframe（重构图：9:16、1:1、4:5、21:9：裁切中间、填充边框或模糊填充）、帧率和质量。预设包可一次添加多种格式。⚙ Compile + export 通过一次编译生成全部格式，放在 <project>.mp4 旁边；Delivered 列出它们以供下载。

⇄ Exchange：XML、EDL、OTIO

  • Send（发送）：将时间线以 Final Cut Pro 7 XML、CMX3600 EDL（仅 V1）或 OpenTimelineIO 格式发送到 DaVinci Resolve、Avid 或其他视频编辑软件。Bring in（导入）：导入来自它们的 XML 或 EDL，会作为一个新的命名时间线打开；片段按文件名在本项目中查找，缺失的片段会被列出。

📝 转录：按文字、停顿、口头禅、场景切换进行剪辑（2.408.0）

  • 选中一个视频或声音片段，然后点 📝。其中的文字会显示出来（文件会在本机上转录一次——在 Settings → Audio 中安装语音转文字）。点击文字可选中，Shift+点击可选中一段连续文字，也可在文字上拖动；双击某个词可跳到该处。
  • ✂ Cut them 删除选中的文字并闭合空隙（其后的片段前移）；⇥ Keep only them 只保留这些文字。Remove pauses over … s 将每段超过该时长的静音缩短到 0.3 s；Remove filler words 删除 um、uh、erm、hmm 等口头禅。↺ Undo 恢复上一次剪切。
  • ✂ Scene cuts 在镜头切换处拆分片段（灵敏度数值越低，能检测到越柔和的变化）。

🎤 卡拉 OK：修正歌词

  • ✎ Edit lyrics（编辑歌词）：当歌曲没有已保存的歌词时，文本框中显示语音转文字听到的内容——正是卡拉 OK 显示的内容——因此可以修正错误的词（或粘贴真正的歌词）。Generate 会保存歌词并根据歌曲为其定时。
  • ⏱ Words & timing（文字与时间）：叠加层将显示的每个词及其开始和结束时间；▶ 播放该词。修改某个词或其时间后，Generate 会为这首歌保留这些修改（↺ 可撤销）——直到其歌词发生变化为止。
  • 🎤 Karaoke 是一个面板（2.410.0）：首次打开时会停靠在预览画布右侧，这样你可以一边播放歌曲一边修正歌词；◧ / ◨ / 其标题栏可移动它（参见上文 🧰）。在 ⏱ Words & timing 中，正在演唱的词会高亮，列表会跟随预览滚动；词的时间是一个按钮，点击可将预览定位到该处；开始或结束时间旁的 ⤓ 会将其设为预览当前所在的位置。👁 on canvas 在预览上绘制修正后的歌词（仅在画布上——绝不会进入影片），因此修改会立即显示；Generate 生成真正的叠加层。
  • 词上的 ◀ ▶（2.433.0）按 Nudge（0.05 s）将其提前 / 推后；Shift+点击 = 较大的微移量（0.25 s）；Ctrl+点击 = 该词及其后的所有词；Shift+Ctrl+点击 = 这些词全部按较大的微移量移动。微移量在列表上方的框中设置；任何词都不会早于 0 s。预览标记所在的那一行会高亮（其中所有词）。
  • 💾 Save words 保存修正，但不生成叠加层。视频面板的 ✎（位于 🎤 Karaoke 旁）会针对故事板上的歌曲打开此对话框；保存后，各场景的歌词叠加层会用修正后的歌词重新生成。

✨ 效果和 ◐ 调整图层（2.409.0）

  • 视频片段的 Properties 中有 ✨ Effects：模糊、锐化、辉光、暗角、颗粒、crop（裁切：边缘变为透明，按各边的 %）、key（抠像：绿幕 / 蓝幕：颜色、多接近的颜色仍会被抠除、柔和边缘、溢色清理——其下方的图层会透出来）以及 stabilise（防抖：在编译时生效；画布显示原始拍摄画面）。
  • 时间线工具栏上的 ◐ 会在位置标记处添加一个调整图层：新顶层上的一个片段，只要它在时间线上，其 🎨 Colour 和 ✨ Effects（模糊、锐化、辉光、暗角、颗粒）就会作用于其下方的所有图层。可像图片一样修剪和移动它；其不透明度控制调整效果的混合程度。

⌨ 按键、标记、In / Out 导出和帧（2.410.0）

  • Space 会暂停当前正在播放的任何预览——画布、实时预览、Preview 面板中的视频——无论指针在哪里，除非你正在文本框中输入（聚焦的按钮不算输入）。暂停时再按 Space 会继续播放；在画布上轻按为播放，按住则为抓手。
  • 指针位于时间线的图层上时（不是画布，画布自己的 V / T / H / Z / M / B 键保持不变）：V ▸ Select，B ⇤ Ripple，N ⇹ Roll，Y ⇆ Slip，U ↔ Slide，F ▯ Frame（然后用 Del 删除选中的帧）；I / O 在位置标记处设置标尺选区的 In / Out；Ctrl+K 在位置标记处拆分（选中的片段，否则为高亮图层上其下方的片段）；↑ / ↓ 跳到上一个 / 下一个编辑点；Home / End 跳到开头 / 结尾。
  • 标记：M（或菜单栏中的 ⚑）在位置标记处放置一个标记——标尺上的一面彩色小旗，以及贯穿各图层的一条竖线。点击小旗可跳到该处，拖动可移动它，双击（或在其上按 M）可设置名称、颜色和备注，🗑 删除它。Shift+M / Alt+M：下一个 / 上一个标记。📝 ✂ Scene cuts 配合 as markers 会在每次镜头切换处放置一个标记，而不是剪切。⇄ Exchange 会将标记写入 XML、EDL 和 OTIO，并能读回。
  • 📤 Export 的 Range（范围）：整部影片，或 In / Out only——每种格式都只由标尺选区生成（<project>_<format>_io），其时间码和字幕也会相应移动。🖼 Export frame（或 Ctrl+Shift+E）将位置标记处的画面保存为 PNG，放在影片旁边。

🅰 文字效果预设（2.411.0）

  • 文字图层的 Properties 中有 Preset（预设）：由分层 PSD 文字效果制成的文字效果（应用自带 Arena Gold 3D、Trend Candy 3D）以及经典样式（Gold、Chrome ...）。选择一个后，文字就会用它绘制——包括其颜色、描边、倒角、闪粉和厚度——边输入边实时显示：文字变化时先显示快速版本，停止输入片刻后显示清晰版本。⚙ Compile 始终使用清晰版本。启用预设时，图层自身的阴影和描边会关闭（由预设自行绘制）；选择 (none) 即可恢复。
  • ＋ Import PSD text effects or a zip… 可添加你自己的预设——一次导入多个 PSD，或一个包含它们的 zip（文字效果包：其中任何文件夹里的每个 PSD 都会成为一个预设；其中的字体会放入工作室的字体文件夹；预览图和 macOS 副本会被忽略）。每个 PSD 需满足：文字是带图层效果的智能对象（大多数“可编辑文字效果”PSD 都是如此）。其背景和装饰会被忽略；预设与你的其他预设保存在一起（🗑 可删除你自己的预设）。PSD 使用的字体会在 Preset 下方的说明中注明——安装该字体并将其选为图层字体，即可获得最接近的效果。
  • 图像编辑器中也有相同的预设：Type 工具的选项栏和文字图层的 Properties。
  • 如实说明局限：倒角的轮廓等高线为近似处理；在没有显卡的机器上，复杂的预设（几十个副本）绘制快速版本大约需要一秒——在大多数机器上会更快。

⏯ J / K / L 穿梭播放、AV1、10 位和显卡（2.411.0）

  • 在时间线面板中的任何位置（包括画布，输入文字时除外）：L 正向播放，再按一次为 2×、4×、8×；J 以同样方式倒放（到开头时停止）；K 停止。按住 K 再按 L / J 可前进 / 后退一帧。速度显示在 ▶ 旁边。在时间线上 L 用于穿梭播放；在其他地方仍用于显示 LLM token。
  • 📤 Export 提供 MP4 · AV1（同等质量下文件最小；需较新的播放器）和 MP4 · H.265 10-bit（渐变更平滑），以及 smallest 预设包（AV1 1080 + 720）。
  • use the graphics card's encoder when it has one（显卡有编码器时使用它）：当本机上 NVENC（NVIDIA）、Quick Sync（Intel）或 AMF（AMD）可用时，H.264 / H.265 / AV1 会用它们编码——每种都会先用单帧测试；都不可用 = 使用普通的软件编码器。日志会说明实际使用了哪一种。

⏱ 丢帧时间码、范围、片段标记、目标轨道、链接声音、音频效果、色相曲线、效果关键帧（2.412.0）

  • 丢帧时间码：在 29.97 或 59.94 fps 下，📤 Export（以及 ⇄ Exchange）提供 drop-frame——时间码会跳过某些帧号，以与实际时钟保持一致（HH:MM:SS;FF）。它会写入 MP4 / MOV、XML（DF）和 EDL（FCM: DROP FRAME）。
  • 标记范围：标记的编辑器中有 length（长度；或用 ⟦ ⟧ 取标尺的 In / Out）；范围是标尺上的一条色带，拖动其右端可改变长度。片段标记：Ctrl+Shift+M（或 Shift+点击 ⚑）在选中片段上位置标记处放置一个——片段上的一面小旗，在你修剪、滑移、加速或倒放该片段时始终停留在其所在的帧上。Shift+M / Alt+M 也会在片段标记和范围端点处停下；⇄ XML / OTIO 会同时携带两者。
  • ◎ Track targets（轨道目标）：图层头中的 ◎ 将该图层设为目标——未选中片段时按 Ctrl+K，会在每个目标图层上拆分位置标记下方的片段。
  • 🔗 Linked sound（链接声音）：视频片段的 Properties → 🔗 Sound → ⤓ as its own clip 会将其声音放到一个 "V1 sound" 图层上，并保持链接；画面则静音播放。菜单栏中开启 🔗 linked selection 时，两者一起移动和修剪；关闭时各自独立。⛓ Unlink 将两者永久分开，↩ Sound back 删除单独的声音片段。
  • 每个视频图层（V2+）以及 🎬 变速片段上都可使用 J / L 剪辑（多出的声音按片段的速度播放；倒放片段的声音也是倒放的）。
  • 🎧 EQ（120 Hz 低架、一个可移动的中频峰值、8 kHz 高架）、multiband（多段）压缩器和 reverb（混响：small / room / hall）——用 🎧 before / after 试听；编译会渲染它们。
  • 🎨 Curves 提供 H/H（色相对色相：将一种颜色移向另一种颜色）和 H/S（色相对饱和度：增加或减少某一种颜色）——曲线两端在红色处循环相接。
  • ✨ 效果关键帧：◆ key here 在位置标记处保存效果；有关键帧后，在没有关键帧的位置移动滑块会在该处生成一个关键帧。模糊、锐化、辉光、暗角、颗粒和裁切会在关键帧之间线性变化——画布和编译中均如此。
  • 📤 MOV · ProRes 4444 (alpha)——未绘制内容的地方为透明（V1 的空隙、透明图片）：时间线会在黑底和白底上各额外编译一次，两者的差值即为 alpha。MP4 · H.264 10-bit（High 10）。显卡选项在 Linux 上还会尝试 VAAPI。

✅ 倒放 / 变速片段的编辑、智能重构图、稳定预览、倒角轮廓（2.413.0）

  • 编辑工具（波纹、滚动、滑移、滑动）、边缘手柄和 Ctrl+K 均可用于倒放和变速的 🎬 片段——精确到帧：修剪时恰好保留原有的帧；延长时按片段在该边缘处的速度播放新增的源素材（变速曲线会在该处添加一个关键帧）。
  • 按转录编辑和场景切换也可用于变速片段——各部分按播放顺序排列。
  • 📤 Export 的适配方式 follow（智能重构图）：生成 9:16 / 1:1 / 4:5 版本，其裁切框跟随主体——优先人脸，其次人物，再次是醒目且运动的物体——沿平稳、平滑的路径移动。
  • ✨ Stabilise 有 smooth（摄像机路径的平稳程度）和 locked（完全没有摄像机运动）。编译时会先测量抖动（vidstab）。生成后，画布会显示稳定预览（状态显示在控件旁）；如果 ffmpeg 中没有 vidstab，则使用 deshake，画布显示原始画面。
  • ⇄ XML 会按 Final Cut 7 及其他编辑软件的方式写入加速 / 减速片段的入点 / 出点（按速度调整后的帧）——已用 OpenTimelineIO 的读取器验证；旧版 bitGen XML 仍可导入。

✅ 嵌套序列、更完整的 XML、FCPXML、整个序列的转录（2.414.0）

  • ⧉ Nest（嵌套；菜单栏）：选择另一个命名时间线——它会被编译成一个片段，放在位置标记处名为 "⧉ name" 的新图层上，此后就是一个普通片段（可修剪、移动、调色、再次嵌套）。当该时间线再次保存时，片段的标记会变为 ↻ out of date：其 Properties 中有 ↻ Re-render（位置和修剪不变）和 ⧉ Open（切换到该时间线）。时间线不能嵌套到自身中，也不能嵌套到它已包含的时间线中。
  • ⇄ XML 现在会携带位置 / 缩放 / 旋转（Basic Motion）、不透明度和音量及其 ◆ 关键帧、💬 字幕（作为文字标题）以及调色：每个调过色的片段的调色效果会烘焙成导出文件旁的一个 .cube（exports/<name>_luts/），并在片段注释中注明——在其他编辑软件（Lumetri → Basic → Input LUT）、Resolve 或 Final Cut（Custom LUT）中将其作为片段的输入 LUT 使用。bitGen 能精确读回自己的调色。

  • 📝 Transcript scope（转录范围）：this clip、its whole layer 或 the whole sequence（V1、视频图层和 🗣 voice 声音图层合为一段文字，按播放顺序排列）。剪切会从说出这些词的那个片段中切掉；对整个序列而言，其后的每个图层也会一起前移。↺ 可撤销。

✅ 轨道混音器、扭曲效果、转场库、颜色匹配（2.415.0）

  • 🎚 Mixer（混音器；菜单栏）：每条轨道（V1、每个视频图层、每个声音图层）一个通道条，外加 master（主输出）——最高 +6 dB 的推子、pan（声像）、Mute / Solo，以及画布播放时实时显示的左 / 右电平表（−60 .. +6 dBFS；白色刻度保持峰值，红色 = 超过 0 dB）。双击：恢复 0 dB / 居中。影片的声像和混音方式与此相同。
  • ✨ Distort（扭曲；片段的 Effects）：lens（镜头：桶形 / 枕形）、mirror（镜像：左 → 右、上 → 下、四向）、warp（变形：可调大小和速度的 wave，以及 twirl）。画布和影片采样的是完全相同的点。
  • 转场：59 种——ffmpeg 提供的全部转场（向四角擦除、柔和擦除、覆盖、揭示、挤压、光圈、开门、切片、风吹、缩放）。视频或图片图层的入场 / 出场会在画布和影片中按其形状绘制；溶解仍为溶解。
  • 🎨 🎯 Match（匹配）：选择另一个片段——会设置本片段的 R / G / B 曲线，使其色调与该片段在影片中显示的画面相匹配。之后可微调曲线，或将其重置。

✅ 蒙版 + 跟踪、多机位、代理（2.416.0）

  • 🎨 ◯ Mask（蒙版；Colour 面板）：一个椭圆或方框，可设中心、大小、旋转、feather（羽化）和 invert（反转）——调色及其后的效果只作用于其内部（或外部）。面板打开时，其轮廓会显示在画布上；调整图层也有蒙版。
  • 🎯 Track（跟踪）：将位置标记放在蒙版位置正确的地方，🎯 会让它跟随该物体直到片段结尾——画布和影片中均如此。跟丢（物体离开画面）= 蒙版停在该处并给出提示。✕ track 删除跟踪；移动已跟踪的蒙版会移动其整条路径。
  • 🎥 Multi-camera（多机位）：在时间线上勾选各机位（第一个 = 参考机位），选择播放哪个机位的声音，点 ⇆ Sync by sound。V1 成为节目轨：播放时按 1 - 9（或点击某个机位）即可实时切换；⇲ Flatten 将切换结果保留为片段。
  • 🪶 Proxies（代理）：会列出负载较重的片段（宽度超过 1920、HEVC / ProRes / DNx、码率超过 40 Mbit/s）——为它们生成 960 宽的代理，并勾选 play proxies on the canvas。影片始终使用原始素材。

✅ HDR、AAF、倒放片段的声音、动态图形模板（2.417.0）

  • 📤 HDR：10 位预设有一个 colour（颜色）选项——SDR、HDR10（PQ、BT.2020 + HDR10 元数据）、HLG 或 Rec.2020 SDR。母版的白色位于 203 尼特，因此看起来与调色时一致。HDR pack 会同时添加两者。时间线上的 HDR 片段会经过色调映射后进入影片。
  • ⇄ AAF（Exchange）：供 Avid Media Composer / Pro Tools 使用的剪辑——画面轨、单声道声音轨、空隙、时间码，并链接媒体。不透明度、音量、移动和调色保留在 FCP 7 XML 中。
  • 🔊 倒放或变速的片段在画布上也能听到：其声音会按影片的变速渲染一次，并同步播放。
  • 🧩 Motion graphics templates（动态图形模板）：选择一个，填写其中的文字，点 ⤓ Insert at the playhead——自动适配画面尺寸，保留移动和关键帧。内置 4 个；💾 Save as a template 会将勾选的图片 / 文字图层保存下来，供所有项目使用。

✅ 实时播放：渲染条、⚡ Render、⏱、播放分辨率（2.418.0）

  • 标尺下方的渲染条：无颜色 = 可实时播放，黄色 = 可能丢帧，红色 = 负载过重（或已丢帧），绿色 = 已渲染。将鼠标悬停在某一段上可查看原因。
  • ⚡ Render：将影片一次编译到项目缓存中——播放绿色段时显示的就是它，精确且全速。编辑只会使其所在的那一段重新变红。Shift+点击 ⚡：关闭 / 开启预览。
  • ▶ 旁边的 ⏱ 统计自按下 ▶ 以来迟到的帧数；Full / ½ / ¼ 在播放时以较小的画面处理片段的效果。

✅ 统一的提示词面板、⊖ 负面提示词面板（2.419.0）

  • 每个工具（✨ AI edit、✨ Fill、路径主体、✨ AI scene、3DREAL 风格、角色、环境、VR 世界）都使用提示词面板中的文本——会有一行显示将要使用的内容；点击即可在该处编辑。
  • 2（或状态栏中的 Negative）显示负面提示词面板：画面中不得出现的内容。它会随每次生成一起发送；其状态行会说明模型是否使用它（SDXL / Pony / Illustrious、LTX、Wan、cfg > 1 时的 H3——FLUX / Qwen / Z-Image 不使用）。LLM 输出的 "Negative:" 行会填入该面板。
