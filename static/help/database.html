🗄 Database

A MySQL / MariaDB database for a project, for every project, or on your own server - with the AI designing the tables, the fields and the views from what you describe. The 🗄 button on the top bar opens and closes the docker.

Where it lives

  • 📁 This project - bitGen runs its own MariaDB server for the project, its data in the project's db folder. It goes with the project.
  • 🌐 Global - one MariaDB server for every project, its data in the app's db folder.
  • 🖧 Your server - any MySQL or MariaDB server (⚙ Your server…: host, port, user, password, database). The password is kept encrypted on this computer.

bitGen's own servers listen on this computer only (127.0.0.1), start by themselves when they are needed (▶ / ⏹ by hand) and stop when bitGen closes. The first time, MariaDB itself is needed: when it is not on this computer a Download / Cancel box offers it (MariaDB, GPL-2.0, from archive.mariadb.org, into the app's mariadb folder). On a Mac install it with Homebrew (brew install mariadb) - bitGen finds it.

✨ Design - the AI makes the tables

  • Describe what it is for: "a small shop: customers, products with stock, orders with their lines, and views for sales by month and the best customers".
  • ✨ Design the tables: the prompt docker's LLM writes the SQL - the tables with their fields and types, keys, links between tables, indexes and the views. It sees the tables already there, so you can ask for more later ("add suppliers").
  • The SQL is shown first. Read it, change it if you like, then ▶ Run. It runs statement by statement and the first error stops it. A design never deletes tables or data.
  • Or say it in the prompt docker: "create a database for my shop with customers and orders" - the docker opens with the design in it.

Tables, data and SQL

  • On the left: the tables (▦) and views (👁) with their fields - 🔑 the key, 🔗 a link to another table.
  • Click one for 📋 Data - its first 200 rows.
  • ⌨ SQL runs any SQL you type (several statements, each ending with ;) and shows the results.
  • ＋ New makes a database, 🗑 deletes the one shown (asked first).
