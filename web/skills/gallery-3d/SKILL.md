# 3D model gallery (bg-model)
Files: css/bg-model.css, js/bg-model.js, js/vendor/three-m3d.min.js (three.js, MIT, LICENSE-three.txt beside it).
Markup: div.bg-model[data-src="media/x.glb"] (also .gltf, .obj) [data-caption] [data-rotate="0" = still]. Several in a .bg-grid make a gallery.
Put the models in media/. The script must load after js/vendor/three-m3d.min.js.
