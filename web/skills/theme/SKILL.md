# Theme and buttons (bg-theme)
Files: css/bg-theme.css, js/bg-theme.js. Change the look by changing the CSS variables in :root (--bg-accent, --bg-ink, --bg-bg, --bg-soft,
--bg-line, --bg-radius, --bg-font, --bg-head, --bg-max, --bg-gap).
Classes: .bg-btn (and .bg-btn.ghost), .bg-card, .bg-dim, .bg-form (labels holding inputs), .bg-input, .bg-note (.err).
A button with data-bg-theme-toggle switches light / dark.
