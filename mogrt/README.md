# 🧩 Motion graphics templates (2.417.0)

`<id>.json` + `<id>/` (its pictures) are the BUILT-IN templates (Lower third, Title card, End card, Corner tag).
Templates you save from a timeline (🧩 → Save as a template) land in `user/` and every project sees them.
The format is `static/mogrt.js` (a template = the picture / text layers as designed, every text an editable field).
